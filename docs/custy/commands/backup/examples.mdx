## Overview

The following examples demonstrate the most common ways to create backup copies
of Custy's template files.

<Section
    title="Recommended Workflow"
>

Although backup operations can be executed at any time, they are most useful
before making changes to project templates.

Typical situations include:

- Updating commit message templates.
- Modifying tag message templates.
- Testing alternative template formats.
- Experimenting with release workflows.
- Performing project maintenance.

</Section>

---

<InfoBox
    variant="tip"
    title="Create Backups Before Editing"
>

It is generally easier to create a backup before making changes than trying to
recover a previous version afterward.

Creating backups regularly helps preserve a history of template revisions.

</InfoBox>
