## Overview

Custy reads project settings from `.config/custy/config.toml`. Changelog-related
settings are separated by responsibility so teams can adjust collection and
presentation behavior independently.

<Section
    title="Example Configuration"
>

<Terminal title=".config/custy/config.toml" language="toml">

{`[tool.custy.cli.changelog]
force_generation = false

[tool.custy.changelog.core]
ignore_merge_commits = true
ignore_types = ["chore"]

[tool.custy.changelog.pending_commit]
enabled = true
generation = "regenerate"
placement = "before"

[tool.custy.changelog.render]
group_by_scope = true
deduplicate = true
show_compare_link = true`}

</Terminal>

</Section>

<InfoBox
    variant="warning"
    title="Change one behavior at a time"
>

The changelog configuration is intentionally detailed. Make a small change,
regenerate, and inspect the Markdown diff before adjusting another group.

</InfoBox>
