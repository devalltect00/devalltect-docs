## Overview

Start with normal generation for established project configuration. Use dry-run
or an explicit override when reviewing a new repository or changing generation
behavior.

<InfoBox
    variant="tip"
    title="Preview configuration changes"
>

Run the dry-run form after changing changelog configuration, then inspect the
normal `CHANGELOG.md` diff before committing it.

</InfoBox>

<InfoBox
    variant="warning"
    title="Forced generation is broader"
>

`--force` can rebuild more existing content than a normal incremental run.
Review the complete artifact rather than only the newest release section.

</InfoBox>
