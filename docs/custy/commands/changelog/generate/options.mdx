## Overview

The direct command exposes two changelog-specific overrides. All other
generation behavior comes from project configuration and Custy's defaults.

---

<Section
    title="Available Options"
>

<CommandOption
    options={[
        {
            name: "--commit-msg-file",
            shorthand: "-cmsg",
            description: "Override the commit-message template used for pending-commit parsing and classification. The path must point to an existing file.",
            defaultValue: ".config/custy/templates/commit-message.txt",
            example: "--commit-msg-file templates/release-message.txt",
        },
        {
            name: "--force / --no-force",
            shorthand: "-f / -F",
            description: "Enable or disable forced changelog regeneration for this invocation.",
            defaultValue: "false unless configured otherwise",
            example: "--force",
        },
    ]}
/>

</Section>

<InfoBox

    title="Resolution order"
>

An explicit CLI value takes precedence over project configuration. Project
configuration takes precedence over Custy's built-in default.
