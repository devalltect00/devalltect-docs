## Overview

After evaluating every configured cleanup rule, Custy reports the outcome of
the cleanup operation.

Depending on the repository state and your configuration, the command may
remove one or more branches, skip cleanup entirely, or report that no eligible
branches were found.

<Section
    title="Successful Cleanup"
>

When one or more branches satisfy every configured cleanup rule, Custy removes
those branches and displays a summary of the completed operation.

Protected branches remain untouched regardless of the configured filters.

</Section>

---

<Section
    title="No Matching Branches"
>

If no branches satisfy the configured cleanup rules, Custy completes normally
without removing any branches.

This indicates that no branch matched the configured filters rather than a
failure of the command.

</Section>

---

<Section
    title="Dry Run Output"
>

When using the global `--dry-run` option, Custy evaluates every configured
cleanup rule but does not delete any branches.

The reported output allows you to verify the cleanup behavior before modifying
your repository.

</Section>

---

<Section
    title="Workflow Execution"
>

Branch Cleanup is executed publicly with `custy cleanup branches`. Its internal
profile name is not accepted by the current public Run argument.

</Section>

---

<InfoBox
    variant="tip"
    title="Successful Execution Doesn't Always Remove Branches"
>

A successful Branch Cleanup operation does not necessarily delete branches.

If no branches satisfy the configured cleanup rules, Custy simply reports that
there was nothing to remove.

</InfoBox>
