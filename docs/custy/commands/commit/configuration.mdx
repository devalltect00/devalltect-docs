## Overview

The direct command resolves values from `.config/custy/config.toml` when a CLI
override is absent.

<Section
    title="Example Configuration"
>

<Terminal title=".config/custy/config.toml" language="toml">

{`[tool.custy.cli.templates.file]
commit_message = ".config/custy/templates/commit-message.txt"

[tool.custy.cli.templates.directory]
backups_commit = ".config/custy/templates/backups/commit"

[tool.custy.cli.execution]
auto_stage = false
stage_mode = "all"
force_commit = false
check_cz = false

[tool.custy.commit.validation]
provider = "auto"
require_tool = false`}

</Terminal>

</Section>

See the complete [behavior matrix](../../configuration/commit-validation) for

<InfoBox
    variant="tip"
    title="Keep shared behavior in configuration"
>

CLI values override project configuration for that invocation. Keep shared team
behavior in TOML and reserve CLI overrides for deliberate one-time changes.

</InfoBox>
