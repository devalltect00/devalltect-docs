## Overview

Preview the complete profile before allowing it to edit files, stage changes,
and create local Git history.

<InfoBox
    variant="tip"
    title="Start with dry-run"
>

Use `custy --dry-run commit` when working in a new repository or after changing
commit configuration.

</InfoBox>

<InfoBox
    variant="warning"
    title="Empty commits are deliberate exceptions"
>

Do not use `--allow-empty-commit` to bypass an unrelated validation, staging,
or configuration error.

</InfoBox>
