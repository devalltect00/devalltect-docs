## Overview

Command-line values override project configuration for the current invocation.
Review staging and empty-commit options carefully because they directly affect
the final Git commit.

<CommandOption

    {

      description: "Select all, update, none, or manual staging behavior.",
      example: "--stage-mode update",
    },
    {
      name: "--allow-empty-commit / --no-allow-empty-commit",
      shorthand: "-aec / -Aec",
      description:
        "Allow or reject commit creation when no normal changes are available.",
      example: "--allow-empty-commit",
    },
    {
      name: "--strategy",
      description:
        "Resolve release artifacts with semver, pep440, date, gitcount, or commitizen.",
      example: "--strategy semver",
    },
    {
      name: "--backup-commit-dir",
      shorthand: "-bcd",

    {
