## Overview

Command-line values override project configuration for the current invocation.
Review staging and empty-commit options carefully because they directly affect
the final Git commit.

<CommandOption
    options={[
        {
            name: "--commit-msg-file",
            shorthand: "-cmsg",

        {

            example: "--auto-stage",
        },
        {
            name: "--stage-mode",
            shorthand: "-sm",
            description: "Select all, update, none, or manual staging behavior.",
            example: "--stage-mode update",
        },
        {
            name: "--allow-empty-commit / --no-allow-empty-commit",
            shorthand: "-aec / -Aec",

            example: "--allow-empty-commit",
        },
        {
            name: "--strategy",

        {
            name: "--backup-commit-dir",

<InfoBox
    variant="warning"
    title="Current adapter limitation"
>

The CLI accepts `--check-cz`, but the current command-to-workflow adapter does
not propagate that value into the workflow engine. Treat it as unavailable until
the Custy implementation is updated and verified.

</InfoBox>
