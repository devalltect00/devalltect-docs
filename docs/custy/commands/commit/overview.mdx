## Overview

`custy commit` is not a thin wrapper around `git commit`. It resolves and runs
the public `commit` profile, which prepares a version, generates and opens
configured artifacts, applies the version, updates the changelog, backs up and
cleans message templates, stages files, and finally creates the commit.

<InfoBox
    variant="danger"
    title="Broad working-tree effects"
>

This command can edit project files, update `CHANGELOG.md`, stage changes, and
create Git history. Inspect the [workflow](./workflow), use dry-run first, and
run it only in the intended repository.

</InfoBox>
