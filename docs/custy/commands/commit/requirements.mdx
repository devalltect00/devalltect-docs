## Overview

The commit profile reads and writes several project resources before creating
Git history. Verify every required path and understand the working tree first.

<InfoBox
    variant="warning"
    title="Staging is part of the profile"
>

The commit profile contains an explicit staging step. The resolved stage mode
controls whether all changes or only tracked modifications are staged. Do not
assume the command will use only files that were staged beforehand.

</InfoBox>

---

<InfoBox
    variant="note"
    title="Remote access is not required"
>

`custy commit` stops after local commit creation. Use `custy push` or an
appropriate public Run profile when reviewed synchronization is also needed.

</InfoBox>
