## Overview

A Linux container does not automatically inherit Windows Git Credential
Manager or another host login session. Custy can optionally supply a GitHub or
GitLab personal access token after normal Git helpers have had the first chance
to authenticate.

<InfoBox variant="success" title="Local credentials stay local">

With the recommended `container_only = true`, local Custy execution uses normal
Git authentication only. The external fallback can activate inside Docker.

</InfoBox>

<InfoBox variant="warning" title="Exact public hosts only">

Managed fallback supports exact `github.com` and `gitlab.com` HTTPS hosts. SSH,
self-hosted instances, and lookalike domains remain on native Git behavior.
