## Guided setup

<Terminal>{`custy configure credentials`}</Terminal>

The wizard asks for provider, source, non-secret username, and source metadata.
File mode requests the PAT with hidden input and confirmation.

<Section title="Focused Commands">

<PropertyTable items={[{property: "set", type: "Mutating", defaultValue: "—", description: "Enable GitHub or GitLab. File mode prompts for the token; environment mode stores only a variable name."}, {property: "status", type: "Read-only", defaultValue: "—", description: "Show policy and source availability without displaying token values."}, {property: "test", type: "Read-only network", defaultValue: "--remote origin", description: "Run git ls-remote with the active policy. Dry-run does not read credentials or contact the remote."}, {property: "remove", type: "Mutating", defaultValue: "Preserve file", description: "Disable a provider. Add --delete-file only when the external token file should also be removed."}]} />

</Section>

<InfoBox variant="danger" title="There is no --token option">

Custy intentionally accepts a file-backed token only through a hidden prompt.
Do not put a PAT in a shell argument, repository URL, message file, or TOML.

</InfoBox>

<Section title="Global Dry-Run"><Terminal>{`custy --dry-run configure credentials status
custy --dry-run configure credentials test --remote origin`}</Terminal>

Dry-run never opens token files, reads token environment values, contacts a
remote, writes TOML, or creates/deletes an external credential file.

</Section>
