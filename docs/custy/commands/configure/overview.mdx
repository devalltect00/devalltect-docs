## Overview

`custy configure` contains setup operations that need safer interaction than
manual TOML editing. The current command family configures optional GitHub and
GitLab HTTPS token fallback for container pushes.

<InfoBox variant="warning" title="Configuration stores policy, not secrets">

The project file may contain provider names, usernames, external filenames,
and environment-variable names. Token values remain outside the project.

</InfoBox>
