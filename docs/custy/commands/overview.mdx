## Overview

Custy provides focused commands for individual operations and a `run` command
for supported multi-step pipeline profiles. Choose a command based on the result
you need, then review its requirements and side effects before execution.

<InfoBox
    variant="warning"
    title="Public commands only"
>

The documentation describes commands accepted by the current public CLI.
Internal profile names are implementation details and are not documented as
valid `custy run` arguments.

</InfoBox>

<Section
    title="Direct Commands and Pipeline Profiles"
>

A direct command performs one focused responsibility. For example,
`custy changelog generate` generates the changelog and `custy push` synchronizes
selected Git references.

The `custy run` command coordinates registered public profiles. The currently
accepted profile names are:

- `commit`
- `tag`
- `push`
- `dev`
- `release`
- `full`

Profiles may combine validation, file editing, version changes, changelog
generation, backups, cleanup, staging, commits, tags, pushes, or workflow
finalization. Each profile page will show its resolved sequence and side effects.

</Section>

<Section
    title="Global Options"
>

Global options such as dry-run, debug output, and log-level selection belong to
the root `custy` command. Their exact effect can vary by operation, so each
command page explains whether an action is previewed, skipped, or still requires
care.

</Section>
