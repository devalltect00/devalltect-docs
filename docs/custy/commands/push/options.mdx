## Overview

Some options are accepted by the CLI but are not reliably propagated into the
workflow engine. Treat dry-run output as the current destination truth.

<CommandOption

<InfoBox

    title="Verify actual destinations"

Because several selection flags are not currently wired into the workflow
engine, use dry-run and read every resolved destination before allowing a normal
push. This documentation will be updated when the Custy adapter is fixed.
