## Overview

Custy reports operations per resolved remote. Read the remote name and role for
every message because different destinations can produce different results.

Output can include the current branch, remote role, dry-run intent, HEAD and tag
results, backup warnings, or an actionable validation error.

<Section
    title="Verify Remote State"
>

<Terminal>

{`git status -sb
git ls-remote --heads origin
git ls-remote --tags origin`}

</Terminal>

Replace `origin` with the destination reported by the workflow.

</Section>

---

<InfoBox
    variant="warning"
    title="Verify each destination independently"
>

A success for one remote does not prove that every configured destination was
processed successfully.

</InfoBox>
