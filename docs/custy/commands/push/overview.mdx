## Overview

The push profile performs repository and pre-push validation, initializes
workflow state, pushes the current `HEAD` to each resolved main remote, and can
also push a selected tag. Backup synchronization is optional and subject to
branch-safety rules.

<InfoBox
    variant="danger"
    title="External side effect"
>

Pushing changes shared repository state. Confirm the branch, commit, tag,
remotes, credentials, and branch-protection expectations before normal
execution. Use dry-run first.

</InfoBox>
