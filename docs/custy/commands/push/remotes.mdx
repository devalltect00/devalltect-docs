## Overview

The workflow engine assigns remotes a main or backup role. The role controls
when the destination is processed and which safety rules apply.

<Section
    title="Branch Safety"
>

Backup push is intentionally skipped for configured non-critical branch
prefixes such as feature, CI, or sandbox work.

</Section>

---

<InfoBox
    variant="warning"
    title="CLI and engine are not fully connected"
>

Although the direct command exposes `--remote` and `--all-remote`, those values
are not currently mapped to the engine's main-remotes list. Treat the interactive
fallback and dry-run report as the current source of actual destination truth.

</InfoBox>
