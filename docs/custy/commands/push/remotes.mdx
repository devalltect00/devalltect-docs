## Overview

The workflow engine assigns remotes a main or backup role. The role controls
when the destination is processed and which safety rules apply.

<Section
    title="Branch Safety"
>

Backup push is intentionally skipped for configured non-critical branch
prefixes such as feature, CI, or sandbox work.

</Section>

---

<InfoBox variant="info" title="Selection priority">

`--remote` wins first, followed by `all_remote = true`, then
`tool.custy.git.push_to`. When a main group is selected, `sync_backup = true`
adds configured backups if the branch is eligible.

</InfoBox>
