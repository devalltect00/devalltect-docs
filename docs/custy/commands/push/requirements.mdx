## Overview

Push changes shared repository state. Verify the exact references and
destinations before normal execution.

---

    title="Push Requirements"

<RequirementGrid
    items={[
        {title: "Reviewed HEAD", level: "required", children: "Confirm the current branch and the exact HEAD commit that will be synchronized."},
        {title: "Reachable Main Remote", level: "required", children: "At least one intended main remote must exist and be reachable."},
        {title: "Git Authentication", level: "required", children: "Configure SSH or supported Git credentials outside Custy."},

        {title: "Local Tag", level: "optional", children: "A requested tag must exist locally and point to the intended commit."},
