## Overview

Use root dry-run before allowing an external operation. The direct and Run
forms select the same profile, but current adapter limitations still apply.

<Section
    title="Direct Command and Run Profile"
>

`custy run push` selects the same public push profile but does not expose the
direct command's full remote and tag option surface.

<InfoBox
    variant="warning"
    title="Remote selection limitation"
>

The current adapter does not reliably propagate `--remote`, `--all-remote`, or
`--skip-tag` into the workflow engine. Until Custy is corrected, do not use those
flags as proof of which remotes or tags will be affected.

</InfoBox>

</Section>
