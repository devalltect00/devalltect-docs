## Overview

The profile validates repository state before resolving and processing each
eligible destination. A standalone `custy push` or `custy run push` does not
initialize a release workflow, calculate a new version, or ask for release
confirmation.

<InfoBox
    variant="info"
    title="Fail-fast behavior"
>

A failed main push raises an error and stops normal progress. Check the reported
remote, authentication, network, branch protection, and rejected history before
retrying.

When an interactive terminal is unavailable, the recommended credential policy
prevents Git from waiting indefinitely for input. Configure an external file or
environment token before running a non-interactive container push.

</InfoBox>

---

<Section
    title="Retry Safety"
>

After a failure, inspect the remote response and determine which earlier
destinations already succeeded. Do not assume every remote remains unchanged.

</Section>
