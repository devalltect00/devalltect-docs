## Overview

You may provide more than one of the six public names. Custy's resolver expands
every selected profile, removes duplicate step names, and sorts the result using
the global pipeline order.

<Section
    title="Normalization Behavior"
>

Input order does not force an unsafe execution order. For example,
`commit tag push` becomes one coherent flow with shared validation and
preparation stages executed once, followed by ordered commit, tag, and push
stages.

</Section>

---

<InfoBox
    variant="warning"
    title="Composition can be broader than expected"
>

Combining profiles takes the union of their stages. Review the equivalent
built-in `release` profile before constructing `commit tag push`; the built-in
profile is usually clearer for team automation.

</InfoBox>

---

<InfoBox
    variant="note"
    title="Only public names are accepted"
>

Profiles such as `validate` or `changelog` cannot be added to a public custom
sequence until the Custy argument enum explicitly exposes them.

</InfoBox>
