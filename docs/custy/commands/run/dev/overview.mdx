## Overview

Use the Dev profile for reviewed day-to-day work that should end with a local
commit and remote push. It prepares a version for artifact generation but, in
the current registered profile, does **not** include the `apply_version_step`.

<InfoBox
    variant="warning"
    title="Push destination limitation"
>

The profile ends with push. Current remote-selection adapter limitations still
apply, so preview and confirm the actual destination before normal execution.

</InfoBox>
