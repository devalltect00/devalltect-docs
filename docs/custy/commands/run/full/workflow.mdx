## Overview

Full runs every Release stage first and invokes workflow finalization only after
remote publication.

<InfoBox
    variant="warning"
    title="Finalization runs after push"
>

A finalization failure can occur after remote publication has succeeded. Inspect
local and remote state before retrying; rerunning the whole profile may duplicate
or conflict with completed release work.

</InfoBox>

---

<Section
    title="Retry Boundary"
>

When finalization fails, verify files, commit, tag, and every remote first. Retry
only the appropriate recovery action rather than repeating the entire release.

</Section>
