## Overview

`custy run` exposes a combined option surface so selected profiles can receive
commit, tag, and push inputs.

<InfoBox
    variant="warning"
    title="Current adapter limitations"
>

Some non-push inputs still have adapter limitations: `bump` and `skip_check`
are not reliably propagated to the workflow engine. `check_cz` is propagated
as a strict Commitizen override. Push
selection inputs are propagated; still verify consequential destinations with
dry-run.

</InfoBox>

<InfoBox variant="note" title="Commit validation provider">

For reusable behavior across Run profiles, configure
[`tool.custy.commit.validation`](../../configuration/commit-validation).

</InfoBox>
