## Overview

The public Run argument currently accepts exactly six names:

- `commit`
- `tag`
- `push`
- `dev`
- `release`
- `full`

<InfoBox
    variant="danger"
    title="Ignore the broader help list"
>

Current CLI help text advertises additional internal names such as `validate`,
`changelog`, backup, cleanup, and workflow steps. The typed public argument does
not accept those values. This documentation intentionally covers only the six
actually accepted names.

</InfoBox>
