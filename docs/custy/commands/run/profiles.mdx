## Overview

Each accepted name expands to an intentional ordered stage list. Choose the
smallest profile that reaches the required outcome.

<InfoBox
    variant="info"
    title="Profile names are not raw steps"
>

Each name expands to a complete intentional flow. `commit`, for example,
contains validation, version, artifact, changelog, backup, cleanup, staging, and
commit stages.

</InfoBox>

Internal profiles remain available to Custy's resolver and other commands but
are not accepted by the current typed public Run argument.
