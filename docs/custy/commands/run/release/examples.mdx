## Overview

Use an approved explicit version and preview the full release before normal
execution.

<InfoBox
    variant="danger"
    title="Release publishes Git history"
>

Confirm the version, artifacts, commit message, tag message, and actual remotes
before allowing the profile to run normally.

</InfoBox>

<CommandExample
    examples={[
        {title: "Preview the configured release", command: "custy --dry-run run release", description: "Inspect every release stage and resolved remote without normal mutations."},
        {title: "Use an approved version", command: "custy run release --strategy semver --tag v2.0.0", description: "Run the release profile with an explicit SemVer tag."},
        {title: "Create a pre-release", command: "custy run release --strategy pep440 --tag 2.0.0rc1 --pre rc", description: "Prepare and publish a release candidate."},
        {title: "Synchronize an eligible backup", command: "custy run release --tag v2.0.0 --sync-backup", description: "Request backup synchronization after main-remote publication.", notes: "Confirm actual resolved remotes because CLI remote selection is not fully propagated."},
