## Overview

Release is the standard all-in-one public profile for preparing and publishing a
versioned release. It includes commit, tag, and push side effects but does not
invoke the additional finalization step used by Full.

<InfoBox
    variant="danger"
    title="Production-affecting workflow"
>

This profile edits files, creates Git history and a tag, and communicates with
remotes. Use an approved version, run dry-run, and review every artifact and
destination before normal execution.

</InfoBox>
