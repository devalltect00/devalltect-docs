## Overview

The selected profile determines which files, Git references, and remotes can be
affected. Combined profiles take the union of those effects.

<InfoBox
    variant="danger"
    title="Dry-run is the starting point"
>

Use `custy --dry-run run PROFILE` before normal execution. Dry-run replaces
normal mutations in supported stages, but validation, discovery, local reads,
and remote resolution can still occur.

</InfoBox>
