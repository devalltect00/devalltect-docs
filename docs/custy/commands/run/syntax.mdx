## Overview

Run accepts one or more names from the six public profiles. Custy expands,
deduplicates, and globally orders their registered stages.

<InfoBox
    variant="danger"
    title="Rejected names"
>

Forms such as `custy run validate`, `custy run changelog`, `custy run init`,
`custy run apply_version`, and `custy run cleanup_backups` are not supported by
the current public argument enum.

</InfoBox>
