## Overview

Project configuration keeps release strategy and tag-related file locations
consistent across contributors. CLI values remain available for one-time
overrides.

<Section
    title="Example Configuration"
>

<Terminal title=".config/custy/config.toml" language="toml">

{`[tool.custy.cli.templates.file]
tag_message = ".config/custy/templates/tag-message.txt"

[tool.custy.cli.templates.directory]
backups_tag = ".config/custy/templates/backups/tag"

[tool.custy.cli.paths]
version_file = "auto"

[tool.custy.cli.versioning]
strategy = "semver"`}

</Terminal>

</Section>

<InfoBox
    variant="tip"
    title="Use shared release inputs"
>

Command-line values take precedence for one invocation. Keep the project-wide
strategy and file locations in configuration so every contributor resolves the
same release inputs.

</InfoBox>
