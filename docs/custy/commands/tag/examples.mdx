## Overview

Prefer an explicit approved version for manual releases, then use dry-run to
inspect how Custy resolves the tag and related artifacts.

<InfoBox
    variant="tip"
    title="Confirm the exact tag"
>

Check the prefix, pre-release format, target commit, and annotation before normal
execution.

</InfoBox>

<CommandExample
  examples={[
    {
      title: "Use configured strategy",
      command: "custy tag",
      description: "Resolve the next tag from project settings and repository state.",
    },
    {
      title: "Create an approved SemVer tag",
      command: "custy tag --strategy semver --tag v1.4.0",
      description: "Use an explicit version while retaining the SemVer strategy.",
    },
    {
      title: "Create an explicit release-candidate tag",
      command: "custy tag --strategy semver --tag v1.4.0-rc.1",
      description:
        "Use an approved SemVer lifecycle tag without automatic version generation.",
    },
    {
      title: "Use an explicit annotation",
      command: 'custy tag --tag v1.4.0 --tag-message "Release v1.4.0"',
      description: "Override the annotated tag message.",
    },
    {
      title: "Preview the selected tag",
      command: "custy --dry-run tag --tag v1.4.0",
      description: "Inspect preparation and the intended tag before creation.",
    },
  ]}
