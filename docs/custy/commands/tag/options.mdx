## Overview

Use an explicit tag for an already approved release. Several advertised
adapter fields are documented below with their current limitation.

---

<InfoBox
    variant="warning"
    title="Current adapter limitations"
>

The CLI accepts `--bump` and `--skip-checks`, but the current command-to-workflow
adapter uses different internal field names and does not propagate these values
reliably. Prefer an explicit `--tag` and do not depend on `--skip-checks` until
the Custy implementation is corrected and verified.

</InfoBox>
