## Overview

The tag profile validates the repository, resolves a version, prepares and opens
tag-related artifacts, applies the version, backs up the tag message, cleans old
backups, and creates the Git tag.

<InfoBox
    variant="danger"
    title="Creates Git history"
>

Normal execution can update project files and create a local tag. Confirm the
target version and existing tags before running it. Use dry-run before a release
and do not force a tag merely to bypass an unexplained validation failure.

</InfoBox>
