## Overview

A Git tag identifies a specific repository state. Confirm the intended version,
target commit, and existing tag history before creating it.

<InfoBox
    variant="warning"
    title="Local operation first"
>

`custy tag` creates a local tag. It does not automatically publish it. Review
the tag and its target commit before using `custy push`.

</InfoBox>
