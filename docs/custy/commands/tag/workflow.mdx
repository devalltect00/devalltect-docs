## Overview

The tag profile prepares release state before creating a permanent local Git
reference. Required failures stop later stages.

<InfoBox
    variant="note"
    title="Publishing is separate"
>

The tag profile does not push. Publishing is deliberately separated so the
local tag and its target can be inspected first.

</InfoBox>

---

<Section
    title="Failure Behavior"
>

If a stage fails, inspect project files, message backups, and local tags before
retrying. A later-stage failure may occur after version files were already
updated.

</Section>
