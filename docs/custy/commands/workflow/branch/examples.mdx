## Overview

These forms explain the declared interface. They are not a recommendation to
use the blocked command in release automation.

<InfoBox
    variant="danger"
    title="Documentation examples only"

Do not add this command to release automation while the current step-name
mismatch remains. Use these forms only to understand or test the interface in a
safe environment after the application is corrected.
