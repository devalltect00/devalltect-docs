## Overview

These options are documented for interface completeness. They do not repair the
known pipeline-construction blocker.

<Section
    title="Configuration Resolution"
>

Configuration is resolved from `[tool.custy.cli.workflow]` for `enforce`,
`check_transition`, and `sync_backup`. Execution and logging defaults come from
their normal Custy configuration tables.

</Section>

---

<InfoBox
    variant="danger"
    title="Options do not remove the blocker"
>

The Custy application must correct the step-name mismatch before these inputs
can be treated as an operational workflow.

</InfoBox>
