## Overview

The intended output includes resolved source and target boundaries, validation
decisions, enforcement results, dry-run diagnostics, and backup synchronization
status.

<InfoBox
    variant="danger"
    title="Current likely result"
>

With the current source mismatch, execution can report an unknown or unregistered
`finalize` step while building the pipeline. That error means no transition
result should be trusted or interpreted as successful validation.

</InfoBox>

---

<Section
    title="Diagnostic Boundary"
>

Debug output may help confirm argument resolution, but it cannot repair a
missing registry name. The Custy implementation must use the registered
`finalize_step` name or register the requested alias.

</Section>
