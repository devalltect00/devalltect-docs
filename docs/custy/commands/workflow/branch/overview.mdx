## Overview

The intended command can validate a transition without enforcement or apply
configured policy enforcement using explicit branch and tag boundaries.

<InfoBox
    variant="danger"
    title="Known pipeline-construction issue"
>

In the current source, this command requests `finalize`; the registered step is
`finalize_step`. Execution may stop before transition behavior begins. The pages
in this section document the accepted interface and intended workflow, not a
production-readiness guarantee.

</InfoBox>
