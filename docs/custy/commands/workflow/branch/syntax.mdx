## Overview

These forms document the accepted interface. They do not bypass the current
pipeline-construction blocker.

---

<InfoBox
    variant="warning"
    title="Option uses an underscore"
>

The current declared long option is `--check_transition`, not
`--check-transition`. Use `-ct` if a shell or team convention makes the
underscore form inconvenient.

</InfoBox>
