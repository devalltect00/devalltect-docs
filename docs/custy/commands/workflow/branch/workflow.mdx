## Overview

The intended flow resolves settings and builds a policy pipeline before
validation or enforcement. Current execution can stop during pipeline building.

<InfoBox
    variant="danger"
    title="Current stop point"
>

The command requests a step named `finalize`, but registration uses
`finalize_step`. Pipeline building can fail at that point, before policy
validation or enforcement executes.

</InfoBox>

---

<Section
    title="Operational Meaning"
>

Until the registry name is corrected and end-to-end behavior is validated, no
later transition validation, enforcement, or backup result should be assumed.

</Section>
