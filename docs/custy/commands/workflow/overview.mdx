## Overview

The `custy workflow` command group is an experimental interface for validating
and enforcing branch and version transitions.

<InfoBox
    variant="danger"
    title="Not production-ready"
>

The current command builds a pipeline step named `finalize`, while Custy's step
registry exposes `finalize_step`. This source-level mismatch can prevent pipeline
construction. Do not rely on this command for release governance until Custy is
fixed and the workflow is validated end to end.

</InfoBox>
