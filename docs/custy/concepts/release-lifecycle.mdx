## Overview

The Release profile coordinates Custy's complete versioned publication path.
It validates the repository, prepares a release version and messages, generates
and reviews artifacts, applies the version, updates the changelog, creates a
commit and tag, and pushes the result.

<InfoBox
    variant="warning"
    title="Release is consequential"
>

Normal execution can modify project files, stage changes, create local Git
history, create a tag, and update remotes. Preview the entire profile with
`custy --dry-run run release` and review every resolved destination first.

</InfoBox>

<InfoBox
    variant="danger"
    title="A failed release can be partially complete"
>

The pipeline does not roll every earlier effect back when a later stage fails.
Before retrying, inspect edited files, the Git index, the latest commit, local
tags, and every resolved remote. Repeating the whole profile without checking
state can duplicate work or fail for a different reason.

</InfoBox>

<Section
    title="Release and Full Have Different Boundaries"
>

The registered Release profile ends after push. The Full profile runs the same
release path and then invokes an additional experimental workflow-finalization
step. Choose Full only when that finalization is intentionally required and its
current limitation is acceptable.

<Terminal title="Review before publication" language="bash">

{`# Inspect current repository state
git status --short
git remote -v

# Resolve and preview the release

custy --dry-run run release

# Run normally only after the preview is understood

custy run release`}

</Terminal>

</Section>
