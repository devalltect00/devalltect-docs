<InfoBox variant="danger" title="Do not rely on these switches">

The resolver creates an `AdvancedConfig` model, but the active generator and
processing pipeline do not consume these fields. Enabling them currently does
not provide a stable documented output contract.

</InfoBox>

<Section title="Use stable alternatives">

- Write explicit Conventional Commit types instead of relying on inference.
- Use `changelog.breaking.keywords` for active breaking detection.
- Use documented rendering fields and edit the project Jinja template for
  intentional formatting changes.

</Section>
