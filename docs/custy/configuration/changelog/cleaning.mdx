<Terminal title="Generated cleaning rules" language="toml">

{`[tool.custy.changelog.cleaning]
remove_separators = ["---"]
remove_headers = false
remove_hash_lines = false
remove_release_summary = false
remove_metadata = false
remove_keywords = [
  "Changelog:",
  "- *(Nothing yet)* — See tag message for full context.",
  "- _(Nothing yet)_",
]`}

</Terminal>

<InfoBox variant="warning" title="Keyword matching is case-sensitive">

Use exact phrases and change one cleaning rule at a time. Broad removals can
produce valid Markdown that silently loses useful release context.

</InfoBox>
