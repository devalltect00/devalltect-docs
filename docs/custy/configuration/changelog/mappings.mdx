## Scope Mapping

Every key is a raw commit scope; every value is the displayed scope. Unmapped
scopes retain their original name.

Unknown types use the value assigned to `other`.

<InfoBox variant="note" title="Mappings do not rewrite Git history">

They affect changelog classification and presentation only. Original commit
messages remain unchanged.

</InfoBox>
