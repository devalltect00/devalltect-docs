<Terminal title="Narrow policy" language="toml">

{`[tool.custy.cli.cleanup.branch]
include_prefixes = ["release/", "feature/"]
merge_status = "merged"
max_age = "30d"

# Use before instead of max_age, never both.
# before = "2026-07-01"`}

</Terminal>

<InfoBox variant="danger" title="max_age and before are mutually exclusive">

Custy rejects configuration that resolves both filters. Start with empty
prefixes, add the narrowest useful prefixes, and preview eligible branches.

</InfoBox>

<Section title="Protected Branches">

The active cleanup workflow protects important branches such as `main`,
`master`, and `develop`, even when other filters match. Protection is a final
safety layer, not a replacement for careful prefix selection.

</Section>
