<InfoBox variant="info" title="Projects without version metadata are valid">

If automatic detection finds no supported version target, Custy can still
start, initialize configuration, and use Git-tag-only versioning. It does not
invent a Python file in Node.js or generic projects. Configure an explicit
target only when the project owns a different version file.

</InfoBox>

<InfoBox variant="warning" title="This is not project_source">

`project.project_source` identifies the main source directory. `version_file`
identifies one metadata file inside the project. Either value can remain
`auto`, and each explicit override is validated independently.

</InfoBox>
