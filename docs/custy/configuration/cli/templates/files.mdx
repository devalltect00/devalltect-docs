<InfoBox variant="warning" title="Preserve the changelog context contract">

You may redesign the Jinja layout, but keep its documented `context` API.
Generate and review the `CHANGELOG.md` diff after every structural edit.

</InfoBox>

<InfoBox variant="info" title="Reviewed message files are preserved">

The artifact step keeps a non-empty `commit_message` or `tag_message` file
unchanged, then opens it for review. Generated release text is used only when
the configured message file is empty or missing in a custom pipeline. Generated
fallbacks resolve the project name from `pyproject.toml` or `package.json`, with
the project-directory name as a generic fallback.

</InfoBox>
