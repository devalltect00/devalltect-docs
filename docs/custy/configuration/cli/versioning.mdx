<Terminal title="Semantic versions" language="toml">

{`[tool.custy.cli.versioning]
strategy = "semver"
bump = "auto"`}

</Terminal>

<Terminal title="Date-based tags" language="toml">

{`[tool.custy.cli.versioning]
strategy = "date"
date_format = "%Y.%m.%d"`}

</Terminal>

<InfoBox variant="note" title="Generated strategy disables detection fallback">

Because `strategy = "semver"` is present, it wins over automatic project
detection. Remove or comment it only when you intentionally want detection.

</InfoBox>
