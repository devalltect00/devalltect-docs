<Terminal title="Service-level strategy" language="toml">

{`[tool.custy.git]
main_remotes = ["origin"]
backup_remotes = ["mirror"]
push_to = "all"

# Present in the generated file but currently reserved.
auto_push = true`}

</Terminal>

<InfoBox variant="warning" title="Explicit remote input wins">

`--remote` selects one destination before any group setting is considered.
Without it, `all_remote = true` selects both configured groups; otherwise
`push_to` selects main, backup, or all.

</InfoBox>

<InfoBox variant="danger" title="auto_push is not an active guarantee">

Do not assume `auto_push = true` causes commit or tag commands to contact a
remote. Use the documented push command or run profile and review its plan.

</InfoBox>
