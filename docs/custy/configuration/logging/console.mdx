## Properties

<PropertyTable
    items={[
        {property: "level", type: "DEBUG | INFO | WARNING | ERROR | CRITICAL", defaultValue: "INFO", description: "Console threshold used when no explicit global log level or debug mode overrides it."},
        {property: "markup", type: "Boolean", defaultValue: "true", description: "Allow Rich markup tags in console messages."},
        {property: "rich_tracebacks", type: "Boolean", defaultValue: "true", description: "Render enhanced exception tracebacks with Rich."},
        {property: "show_time", type: "Boolean", defaultValue: "false", description: "Show a timestamp column in console records."},
        {property: "show_level", type: "Boolean", defaultValue: "false", description: "Show the log-level column. Runtime debug mode enables it."},

<Terminal title="Generated console logging" language="toml">

{`[tool.custy.logging]
level = "INFO"
markup = true
rich_tracebacks = true
show_time = false
show_level = false
console_format = "%(message)s"`}

</Terminal>

<InfoBox variant="note" title="Runtime overrides">

An explicit global log-level option overrides `level`. Debug mode forces the
effective console level to `DEBUG` and enables level display for that process.

</InfoBox>
