<Terminal title="Generated file logging" language="toml">

{`[tool.custy.logging.file]
level = "DEBUG"
log_dir = "logs"
log_file = "custy.log"
max_bytes = "10MB"
backup_count = 5
file_format = "%(asctime)s | %(levelname)s | %(name)s | %(message)s"`}

</Terminal>

<InfoBox variant="warning" title="Ensure the destination is writable">

Logging creates `log_dir` during setup. Automated or containerized environments
must allow writes there. Ignore the directory in version control when logs
should remain local.

</InfoBox>

<Section title="Rotation Example">

With the generated values, `custy.log` rotates after roughly 10 MB and keeps
up to five numbered historical files in addition to the active log.

</Section>
