## Overview

`custy init` creates a project-owned TOML file from Custy's packaged source.
The active documentation mirrors that file's hierarchy, while grouping deeply
nested tables into navigable sections.

<InfoBox variant="tip" title="Start broad, then move to properties">

Use this page to choose a namespace. Use the namespace pages for explanations
and examples, or open [All Properties](./reference) when you already know a
full TOML path.

</InfoBox>

<Section title="Status Language Used in This Guide">

- **Active** — the current resolver or service consumes the property.
- **Optional** — supported by active code but commented out or omitted from
  the generated file.
- **Mismatch** — generated and active names or shapes do not currently align.
- **Loaded only** — parsed into a model, but the active renderer or pipeline
  does not yet use it.
- **Experimental** — evolving behavior that should not be treated as stable.
- **Reserved** — generated or described, but not consumed by the current
  active command flow.

</Section>
