<InfoBox variant="info" title="Automatic source selection">

For Python markers, Custy prefers `app/`, then `src/`. For Node.js and generic
repositories, it prefers `src/`, then `app/`. If neither directory exists,
the project root is valid. Detection occurs at command runtime, so a
Docusaurus, React, PHP, or other repository does not need an `app/` directory
just to start Custy.

</InfoBox>

<InfoBox variant="warning" title="Explicit paths remain strict">

An explicit value is an intentional override. Custy reports a configuration
error if that path is missing or is not a directory. Switch back to `auto` or
correct the path instead of creating a placeholder `app/` directory.

</InfoBox>
