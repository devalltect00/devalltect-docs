## Overview

Most command resolvers use the same priority, but support is implemented per
property. A key appearing in the generated file is not sufficient evidence
that every command consumes it.

<InfoBox variant="warning" title="Known cross-cutting mismatch">

The generated execution key is `cli.execution.skip_checks`; current direct
Git-operation and `custy run` resolvers look up `cli.execution.skip_check`.
Use the command's explicit skip-check option until the source and template are
aligned.

</InfoBox>
