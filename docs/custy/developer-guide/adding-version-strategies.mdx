## Overview

Custy currently provides SemVer, PEP 440, Commitizen, date, and Git-count
generation. Each strategy returns the next tag string, but active selection is
implemented explicitly in `WorkflowEngine.prepare_version_tag()` rather than
through a strategy factory.

<InfoBox variant="tip" title="Explicit tags bypass generation">

When the workflow receives a direct tag value, it uses that value before
examining the selected strategy. A new strategy must preserve this priority.

</InfoBox>

<Section title="Implement the Protocol">

<Terminal title="Strategy shape" language="python">

{`from app.core.git_ops.tag_strategy.base import TagStrategy


class BuildNumberStrategy:
    """Generate a tag from a validated build number."""

    def __init__(self, build_number: int) -> None:
        """Store the positive build number used for generation."""
        if build_number < 1:
            raise ValueError("build_number must be positive")
        self.build_number = build_number

    def get_next_tag(self) -> str:
        """Return the next build-number tag."""
        return f"vbuild.{self.build_number}"`}

</Terminal>

`TagStrategy` is a structural `Protocol`, so a concrete class does not need to
inherit it explicitly. The class must still satisfy the documented
`get_next_tag() -> str` behavior and report invalid inputs or unavailable
dependencies clearly.

</Section>

<Section title="Testing Checklist">

- Construct the strategy with default and explicit supported values.
- Verify the exact returned tag format at important boundaries.
- Mock the clock, Git service, environment, or subprocess dependency rather
  than relying on a contributor machine.
- Verify malformed prior tags, invalid input, missing tools, and command
  failures produce intentional exceptions.
- Verify `WorkflowEngine.prepare_version_tag()` selects the new strategy and
  still gives an explicit tag higher priority.
- Verify Typer accepts the new `StrategyChoices` value in every supported
  command path.
- Add integration coverage when the generated tag affects file updates,
  changelog content, commit messages, or tag creation.

</Section>

---

<InfoBox variant="warning" title="Generation and synchronization are separate">

A strategy decides the next tag. Version-file synchronization and ecosystem
conversion are separate responsibilities. Do not add project-file writes to a
strategy merely because its result is later applied to Python or another
ecosystem.

</InfoBox>
