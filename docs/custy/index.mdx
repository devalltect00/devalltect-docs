## Overview

Custy is a configurable developer-productivity CLI for managing repeatable Git
and release work. It brings project validation, version updates, changelog
generation, backups, cleanup, commits, tags, pushes, and multi-step pipelines
into one consistent interface.

<InfoBox
    variant="info"
    title="Documentation status"
>

The English command reference covers the current public CLI. Internal pipeline
profiles are not presented as public commands unless the installed CLI exposes
them, and known implementation limitations are identified on the affected pages.
The [Documentation Status](./custy/reference/documentation-status) page explains
the release baseline, review date, and how to compare another installed version.

</InfoBox>

<Section
    title="Choose the Smallest Suitable Operation"
>

- Use a direct command when you need one focused operation.
- Use `custy run dev`, `custy run release`, or `custy run full` when you need a
  coordinated pipeline.
- Review the documented side effects before running a profile that can edit
  files, create Git history, or communicate with remotes.
- Use dry-run support where the selected command or workflow provides it.

The `custy workflow` command group is experimental. Its documentation is kept
separate from the stable pipeline profiles and clearly identifies current
limitations.

</Section>
