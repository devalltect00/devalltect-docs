## Overview

Dev is a deliberate daily-development profile. It validates and reviews the
commit message, stages selected changes, creates a commit, and pushes branch
`HEAD`. It does not prepare release state, generate release artifacts or a
changelog, create a tag, or push a tag.

<Terminal title="Preview before normal execution" language="bash">

{`custy --dry-run run dev
custy run dev`}

</Terminal>

<InfoBox variant="info" title="Release responsibilities are excluded">

Dev omits version preparation and application, workflow initialization,
release-artifact and changelog generation, tag-message editing, tag creation,
and tag push. Use Release when you need a versioned, tagged publication.

</InfoBox>

<InfoBox variant="warning" title="Dev validates only what it uses">

The profile validates repository, commit-message, hook, and remote readiness.
It intentionally skips version and tag-message validation because those values
are outside the Dev workflow. Confirm staged changes and remotes before normal
execution.

</InfoBox>

<Section title="Failure and Retry">

If Dev fails before commit, inspect the edited message, backups, and the Git
index. If it fails during or after push, verify whether the local commit and any
remote updates already completed. Do not rerun the whole profile until that
state is understood.

</Section>
