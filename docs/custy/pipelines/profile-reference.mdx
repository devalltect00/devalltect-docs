## Overview

`PIPELINE_PROFILES` is Custy's complete resolver catalog. A profile is a named
step definition, not automatically a public CLI value. Some profiles are
accepted by `custy run`, some are selected internally by focused commands, and
some exist only to compose larger profiles.

<InfoBox variant="danger" title="Resolver profile does not mean public Run profile">

Only `commit`, `tag`, `push`, `dev`, `release`, and `full` are accepted by the
current typed `custy run` argument. For example, `validate` is a real resolver
profile used by `custy validate`, but `custy run validate` is not currently a
supported public invocation.

</InfoBox>

<InfoBox variant="info" title="Expansion order and merged order are different concepts">

The lists above show one profile resolved by itself. When two or more profiles
are selected, Custy combines them, removes repeated step names, and sorts the
result using `STEP_ORDER`. See [Step Priority and Ordering](./step-order) for
the complete algorithm and priority table.

</InfoBox>
