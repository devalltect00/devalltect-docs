## Overview

Release is the complete public publication profile. It includes repository,
commit, tag, and remote validation before it applies version state, generates
release documentation, creates Git history, and pushes to the resolved remotes.

<Terminal title="Preview and execute" language="bash">

{`custy --dry-run run release
custy run release`}

</Terminal>

<InfoBox variant="warning" title="Changelog generation is conditional">

The Release profile contains the changelog step, but the workflow engine can
skip generation for a non-final version or according to active command and
configuration rules. A registered step does not guarantee that it will mutate
a file.

</InfoBox>

<InfoBox variant="danger" title="Publication is not atomic">

A failure can occur after files were changed, after a commit or local tag was
created, or after one remote succeeded. Inspect the exact completion boundary
before retrying.

</InfoBox>

---

<Section title="Release or Full?">

Release ends after push. Full contains the same Release stages and then invokes
experimental branch workflow finalization. Prefer Release unless that
post-publication transition is deliberately required and understood.

</Section>
