## Overview

The Reference section is the quickest route to an exact name or current
contract. It intentionally links to the longer command, configuration,
pipeline, concept, and architecture guides instead of repeating their full
explanations.

<InfoBox variant="info" title="Current behavior, not a compatibility promise">

These pages describe the active Custy source reviewed for this documentation.
Items marked experimental, loaded-only, reserved, mismatch, or current
limitation should not be treated as stable public guarantees.

</InfoBox>
