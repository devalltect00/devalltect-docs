# Devalltect Docs

Devalltect Docs is the shared Docusaurus portal for four Devalltect developer
tools. It gives readers one place to discover a project, learn its safe usage,
find command and configuration references, and understand its development and
release workflows.

## Supported Documentation

| Project                 | Documented release | Main focus                                                         |
| ----------------------- | ------------------ | ------------------------------------------------------------------ |
| **Custy**               | v2.1.2             | Git, versioning, changelog, backup, cleanup, and release workflows |
| **Path Header Scanner** | v1.0.1             | Previewing, validating, and applying repository path headers       |
| **Doc Gen**             | v1.0.2             | Generating, printing, and analyzing project structures             |
| **Reflow**              | v1.0.2             | Tag conversion, release recovery, and container publishing         |

English is the default locale, and Bahasa Indonesia provides an aligned
documentation set. Command names, options, paths, configuration keys, and code
identifiers remain literal when translating them would reduce technical
accuracy.

## How the Portal Is Organized

- Project landing pages introduce each tool and provide a representative visual preview.
- Getting-started guides provide the shortest safe path to a useful result.
- Command and configuration pages document exact user-facing contracts.
- Concepts and architecture pages explain behavior and implementation boundaries.
- Developer and troubleshooting guides support maintenance and diagnosis.
- Release-aware status pages show which project version the documentation represents.

## Development Environments

Maintainers can work directly with the pinned Yarn runtime or use the optional
Docker and Compose environment. Both paths run the same formatting, freshness,
type-checking, and multilingual build contracts. The production container is a
local or self-hosted preview; GitHub Pages and GitLab Pages still deploy static
files directly.

See [Docker and Compose](./devalltect-docs/docker) for image stages, commands, ports, volume
behavior, and the CI boundary.

## For Maintainers

Read the [maintainer workflow](./devalltect-docs/maintainer-workflow) before changing shared
components, project metadata, translations, or screenshots. Use
[versioning and freshness](./devalltect-docs/versioning-and-freshness) when updating a project
baseline or preparing a portal release.

The public portal is available at
[devalltect00.github.io/devalltect-docs](https://devalltect00.github.io/devalltect-docs).
