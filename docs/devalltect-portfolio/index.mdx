# Devalltect Portfolio

Devalltect Portfolio v2 is a bilingual, interactive presentation of projects,
technical experience, and creative software engineering work. It guides
visitors through a curated journey while retaining a searchable archive for
deeper exploration.

**Open the portfolio:** [devalltect-portfolio.vercel.app](https://devalltect-portfolio.vercel.app/)

## Supported experience

- English is the default locale and Bahasa Indonesia is available throughout.
- Light is the initial theme; explicit preferences persist in the browser.
- Project cards handle unavailable screenshots and optional links gracefully.
- The static production build does not require a database or persistent backend.
- Vercel hosts production while Docker remains optional development and
  portability tooling.

Use [Getting Started](./getting-started.mdx) to visit or run the project locally.
