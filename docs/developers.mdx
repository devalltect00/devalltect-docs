## Maintain This Documentation Portal

Use the [Devalltect Docs maintainer workflow](./devalltect-docs/maintainer-workflow)
when changing shared components, project metadata, translations, screenshots,
documentation freshness, or release material.

Before submitting changes, run the checks required by the affected project and
validate this portal with its freshness tests, TypeScript check, and both-locale
production build.
