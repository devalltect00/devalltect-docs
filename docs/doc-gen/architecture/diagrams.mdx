## Component Interactions

### CLI to Core

```
CLI (main.py)
    │
    ├── Commands (init, structure generate, structure print, structure analyze)
    │   │
    │   └── Options & Models
    │
    └── Core Services
        │
        ├── Scanner Service
        ├── Generator Service
        ├── Analyzer Service
        └── Presenter Service
```

### Generator Pipeline

```
Input (Target Directory)
    │
    ├── Scanner (discovers files and directories)
    ├── Analyzer (extracts metadata)
    ├── Builder (constructs structure model)
    └── Renderer (outputs markdown)
        │
        └── Output (PROJECT_STRUCTURE.md)
```
