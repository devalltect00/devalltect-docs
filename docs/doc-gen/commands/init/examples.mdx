### 1. Preview

<Terminal language="bash">{`doc-gen init --dry-run`}</Terminal>

**Result:** Shows plan.

### 2. Initialize

<Terminal language="bash">{`doc-gen init`}</Terminal>

**Result:** Creates `.config/doc_gen/config.toml` when it does not exist.

### 3. Configuration only

<Terminal language="bash">{`doc-gen init --mode config`}</Terminal>

**Result:** Creates the same configuration file through the explicit `config` mode.

### 4. Force

<Terminal language="bash">{`doc-gen init --mode all --force`}</Terminal>

**Result:** Replaces the existing configuration file without prompting.
