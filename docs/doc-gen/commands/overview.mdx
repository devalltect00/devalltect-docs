<Section title="Supported commands">

| Command | Result | Writes project documentation |
| --- | --- | --- |
| [`doc-gen init`](./init/overview) | Project configuration | Yes, unless dry-run |
| [`doc-gen structure generate [TARGET]`](./structure/generate/overview) | Markdown structure document | Yes, unless dry-run |
| [`doc-gen structure print [TARGET]`](./structure/print/overview) | Terminal tree | No |
| [`doc-gen structure analyze [TARGET]`](./structure/analyze/overview) | Terminal analysis | No |

</Section>

Structure commands share profile, smart-mode, depth, file visibility, collapse, project-type, verbosity, and dry-run options.

<InfoBox variant="warning" title="Only generate persists structure output">

`print` and `analyze` are read-only. `generate --dry-run` performs discovery
and rendering in memory but creates neither its output directory nor file.

</InfoBox>
