### 1. Analyze current project

<Terminal language="bash">{`doc-gen structure analyze .`}</Terminal>

**Result:** Displays analysis.

### 2. Override type

<Terminal language="bash">{`doc-gen structure analyze . --project-type python`}</Terminal>

**Result:** Uses Python classification.

### 3. Smart analysis

<Terminal language="bash">{`doc-gen structure analyze . --smart`}</Terminal>

**Result:** Applies automatic optimization decisions.

### 4. Dry-run

<Terminal language="bash">{`doc-gen structure analyze . --dry-run`}</Terminal>

**Result:** Remains read-only.
