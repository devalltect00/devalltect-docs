<Section title="Purpose">
  Scan a repository, render its tree as Markdown, and write only the resolved output
  document.
</Section>

<InfoBox variant="warning" title="Safety boundary">
  This is the only structure command that writes output. --dry-run renders in memory but
  creates neither the output directory nor file.
</InfoBox>

- Resolve target, profile, smart mode, rendering, and output settings.
- Scan while applying ignore/collapse rules.
- Render Markdown in memory.
- In dry-run, show the plan and stop before directory/file creation.
- In live mode, write only the resolved output and display summary/progress.
