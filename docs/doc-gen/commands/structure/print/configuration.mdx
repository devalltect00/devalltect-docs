| Key                                           | Default       | Effect                     |
| --------------------------------------------- | ------------- | -------------------------- |
| `tool.doc-gen.cli.execution.dry_run`          | false         | Global simulation default. |
| `tool.doc-gen.cli.execution.debug`            | false         | Diagnostic logging.        |
| `tool.doc-gen.cli.structure.target_directory` | .             | Default root.              |
| `tool.doc-gen.cli.structure.profile`          | custom        | Structure profile.         |
| `tool.doc-gen.cli.structure.smart_mode`       | false         | Automatic optimization.    |
| `tool.doc-gen.cli.structure.max_depth`        | 5             | Depth limit.               |
| `tool.doc-gen.cli.structure.show_files`       | true          | File visibility.           |
| `tool.doc-gen.cli.structure.collapse_dirs`    | built-in list | Collapsed directories.     |
| `tool.doc-gen.cli.structure.verbose`          | false         | Extra terminal output.     |

```toml
[tool.doc-gen.cli.execution]
dry_run = false
debug = false

[tool.doc-gen.cli.structure]
target_directory = "."
profile = "custom"
smart_mode = false
max_depth = 5
show_files = true
verbose = false
collapse_dirs = ["node_modules", "venv", ".venv", "dist", "build", ".next"]

[tool.doc-gen.cli.structure.print]
# Reserved for future print-specific settings.
```
