<CommandHero command="doc-gen structure print" title="Examples" description="Print is inherently read-only. --dry-run is accepted and remains non-mutating." category="Project Structure" status="Read Only" syntax="doc-gen structure print [OPTIONS]" links={[{label:"Overview",href:"./overview"},{label:"Options",href:"./options"},{label:"Workflow",href:"./workflow"},{label:"Examples",href:"./examples"}]} />

### 1. Print current project

<Terminal language="bash">{`doc-gen structure print .`}</Terminal>

**Result:** Displays tree.

### 2. Minimal

<Terminal language="bash">{`doc-gen structure print . --profile minimal`}</Terminal>

**Result:** Displays concise tree.

### 3. Directories only

<Terminal language="bash">{`doc-gen structure print . --hide-files`}</Terminal>

**Result:** Hides files.

### 4. Dry-run

<Terminal language="bash">{`doc-gen structure print . --dry-run`}</Terminal>

**Result:** Remains read-only.
