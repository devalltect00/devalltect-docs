# AI Development Workflow

This guide describes how AI agents should work with the DocGen codebase.

---

## Overview

AI agents can assist with:

- Code development
- Bug fixing
- Documentation writing
- Test creation
- Refactoring

---

## Starting a Task

1. Understand the user's request
2. Explore relevant code files
3. Plan the changes
4. Get user confirmation
5. Implement changes

---

## Code Exploration

### Find Relevant Files

Use list_files to explore directory structure:

```
app/doc_gen/
├── cli/           # CLI commands
├── core/         # Core logic
├── config/       # Configuration
├── ui/           # UI components
└── utils/       # Utilities
```

### Read Files

Use read_file to examine code:

```python
# Read a specific file
read_file("app/doc_gen/cli/main.py")
```

### Search Code

Use search_files to find patterns:

```
# Find function definitions
search_files("app/doc_gen", "def ")
```

---

## Making Changes

### Edit Files

Use edit_file to make changes:

```python
edit_file(
    path="app/doc_gen/cli/main.py",
    old_str="old code here",
    new_str="new code here"
)
```

### Create Files

Use create_file for new files:

```python
create_file(
    absolute_path="app/doc_gen/new_module.py",
    content="# New module..."
)
```

---

## Testing Changes

After making changes:

1. Run lint check:

```bash
ruff check app tests
```

2. Run format check:

```bash
ruff format app tests
```

3. Run tests:

```bash
pytest -v
```

---

## Safety Guidelines

- Always get user confirmation before making changes
- Don't modify protected files
- Keep docs aligned with code
- Test changes before finalizing
- Follow project style guidelines
