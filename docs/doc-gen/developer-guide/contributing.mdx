## Overview

Keep CLI interaction under `app/doc_gen/cli`, reusable structure behavior under
`app/doc_gen/core/structure`, Markdown construction in renderers, and file
persistence in writers. Make selected targets and outputs explicit.

<Section title="Quality Gates">

<Terminal title="Contributor validation" language="bash">

{`# Focused examples
python -m pytest tests/cli
python -m pytest tests/test_dry_run.py

# Complete validation

python -m pytest
make check

# Hook validation

make pre-commit-validate
make pre-commit-run-staged
make pre-commit-run`}

</Terminal>

<InfoBox variant="warning" title="Refresh is a maintainer operation">

Use `make pre-commit-refresh` only for intentional hook upgrades. It may access
the network and modify `.pre-commit-config.yaml` and active files. Review the
complete result before keeping any change.

</InfoBox>

</Section>
