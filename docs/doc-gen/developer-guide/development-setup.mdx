## Goal

Use an isolated environment whose `doc-gen` command loads the active checkout.
Install `.[dev]`; a runtime-only editable installation does not include pytest,
Ruff, Black, or pre-commit.

<Section title="Manual Setup">

<Terminal title="Create and install" language="bash">

{`python -m venv venv

# Windows PowerShell

venv\\Scripts\\Activate.ps1

# Linux or macOS

# source venv/bin/activate

python -m pip install --upgrade pip
python -m pip install -e ".[dev]"`}

</Terminal>

Use `python -m pip install -e ".[dev,docs]"` only when working with the
repository's MkDocs source.

</Section>

---

<Section title="Makefile Setup">

<Terminal title="Setup helpers" language="bash">

{`make venv
make upgrade-pip
make install-dev

# Combined environment setup and Git-hook installation

make setup`}

</Terminal>

The Make workflow uses the Python interpreter under the conventional `venv/`
directory.

</Section>

<Section title="Pre-Commit Workflow">

Doc Gen's hook configuration runs Ruff fixes, Ruff formatting, Black,
trailing-whitespace cleanup, and final-newline correction. Ruff and Black read
their project policy from `pyproject.toml`.

<Terminal title="Install and run hooks" language="bash">

{`make pre-commit-install-hooks
make pre-commit-validate
make pre-commit-run-staged
make pre-commit-run`}

</Terminal>

<InfoBox variant="warning" title="Refresh is an intentional hook upgrade">

`make pre-commit-refresh` updates hook revisions, clears and reinstalls hook
environments, and runs every hook against all files. It may require network
access and may modify configuration and source files. Review the full diff.

</InfoBox>

</Section>
