## Contributor priorities

`structure print` and `structure analyze` are read-only. `structure generate`
may write only its resolved output document, while `--dry-run` may scan and
render but must not create directories or files.

<Section title="Quality workflow">

Install Doc Gen with its contributor dependencies, enable the repository hook,
run the smallest affected test, and finish with `make check` plus applicable
generation and dry-run regression coverage.

<InfoBox variant="note" title="Pre-commit is one quality layer">

Hooks handle Ruff, formatting, whitespace, and newline policy. They do not
replace output-boundary tests, complete pytest coverage, or applicable Docker,
Compose, package, and documentation checks.

</InfoBox>
