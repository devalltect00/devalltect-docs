<Section title="Read-only inspection">

<Terminal language="bash">{`doc-gen structure print . --max-depth 3
doc-gen structure analyze . --smart

# Show directories only

doc-gen structure print . --hide-files`}</Terminal>

</Section>

<Section title="Preview, then generate">

<Terminal language="bash">{`# Render in memory and show the resolved plan
doc-gen structure generate . --profile detailed --output docs/project_structure.md --dry-run

# Write the selected output only after review

doc-gen structure generate . --profile detailed --output docs/project_structure.md`}</Terminal>

</Section>

<InfoBox variant="warning" title="Dry-run creates no output path">

Generation dry-run may scan and render, but it does not create the output
directory or file. `print` and `analyze` are read-only in both modes.

</InfoBox>
