<Section title="Published Image Tags">

| Tag    | Example  | Behavior                                                     |
| ------ | -------- | ------------------------------------------------------------ |
| Exact  | `v1.0.1` | Immutable and recommended for CI or reproducible automation. |
| Minor  | `v1.0`   | Moves to the newest stable patch in the 1.0 line.            |
| Major  | `v1`     | Moves to the newest stable release in the 1.x line.          |
| Latest | `latest` | Moves to the newest stable Doc Gen release.                  |

<Terminal title="Pull and verify Doc Gen" language="bash">

{`docker pull ghcr.io/devalltect00/doc-gen:v1.0.1
docker run --rm ghcr.io/devalltect00/doc-gen:v1.0.1 --help`}

</Terminal>

<InfoBox variant="note" title="Bare invocation shows help">

Starting Doc Gen without a subcommand displays the banner and command help.
Use `--no-banner` when a compact help screen is preferable for scripts or
captured output.

</InfoBox>

<InfoBox variant="warning" title="Prereleases do not move stable aliases">

`v1.0.0-rc.1` publishes only its exact tag. Stable aliases are updated only by
a stable release.

</InfoBox>

</Section>

<Section title="Build a Local Image">

The Make targets pass Doc Gen's reviewed source version into the Docker build.
This prevents setuptools-scm from using its legacy fallback when Git metadata
is intentionally excluded from the image context.

<Terminal title="Build and verify a local production image" language="bash">

{`make c-build-prod
docker run --rm doc-gen-prod:latest --version`}

</Terminal>

For an explicitly reviewed build, override the detected value with
`DOC_GEN_BUILD_VERSION=1.0.1`. Hosted release images continue to receive their
version from the validated release tag.

</Section>

<Section title="Choose a Tag Deliberately">

Use the exact version for repeatable generation in CI. Use `v1.0`, `v1`, or
`latest` only when controlled automatic upgrades are acceptable. Mount only
the intended project and use `structure generate --dry-run` before allowing a
generated document to be written.

</Section>
