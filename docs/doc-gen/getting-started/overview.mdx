<Section title="Requirements">

- Python 3.9+ compatibility; Python 3.14 standard runtime
- A dedicated virtual environment
- A reviewed source checkout, trusted artifact, or authorized private GitLab package
- Write permission only for workflows that intentionally persist output

registry. The package and command name are both `doc-gen`.
