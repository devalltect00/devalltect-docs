## Commands

- `doc-gen init`
- `doc-gen structure generate [TARGET]`
- `doc-gen structure print [TARGET]`
- `doc-gen structure analyze [TARGET]`

## Global options

- `--no-banner`
- `--version / -v`
- `--debug`
- `--log-level`

<InfoBox variant="warning" title="Safety">
  Generate writes only its resolved Markdown output; print and analyze are read-only.
  Generate dry-run never creates its output directory or file.
</InfoBox>
