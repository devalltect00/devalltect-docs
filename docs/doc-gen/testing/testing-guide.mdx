# Testing Guide

This guide describes how to test DocGen.

---

## Running Tests

### Basic Test Run

Run all tests:

```bash
pytest -v
```

### Run Specific Tests

Run tests for a specific module:

```bash
pytest tests/cli/ -v
```

Run tests for a specific file:

```bash
pytest tests/cli/test_main.py -v
```

### Run with Coverage

```bash
pytest --cov=doc_gen --cov-report=term-missing
```

---

## Writing Tests

### Test Location

Tests are in the `tests/` directory:

```text
tests/
├── cli/
├── config/
├── core/
├── services/
└── utils/
```

### Test Structure

```python
# tests/cli/test_main.py
import pytest
from doc_gen.cli.main import app

def test_main_help():
    # Test implementation
    pass
```

---

## Test Conventions

- Use descriptive test names
- Test one thing per test
- Use fixtures for common setup
- Keep tests independent

---

## Running Tests in Docker

```bash
make d-test
```

---

## Running Tests in Docker Compose

```bash
make c-test
```

## Test Coverage

Check coverage:

```bash
pytest --cov=doc_gen --cov-report=html
```

View coverage report:

```bash
open htmlcov/index.html
```

---

## CI Testing

Tests run automatically in CI. See Makefile:

```bash
make test-ci
make c-ci
```
