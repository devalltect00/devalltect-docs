# Smart Mode

Smart Mode is an intelligent feature that automatically optimizes the output based on your project size and complexity.

## What is Smart Mode?

Smart Mode analyzes your project and automatically adjusts the documentation detail level to provide the most useful output without overwhelming you with information.

## How It Works

When Smart Mode is enabled, DocGen automatically:

- **Analyzes project size** - Counts files, directories, and total lines of code
- **Adjusts detail level** - Uses minimal for small projects, detailed for large ones
- **Filters noise** - Excludes generated files, caches, and build artifacts
- **Optimizes output** - Balances comprehensiveness with readability

## Usage

### CLI Usage

```bash
# Enable smart mode for generate
doc-gen structure generate --smart

# Enable smart mode for print
doc-gen structure print --smart

# Enable smart mode for analyze
doc-gen structure analyze --smart
```

### Makefile Usage

```bash
# Generate with smart mode
make l-generate-smart

# Or using Docker
make d-generate-smart
```

## Smart Mode Levels

| Project Size          | Smart Mode Output       |
| --------------------- | ----------------------- |
| Small (< 50 files)    | Minimal overview        |
| Medium (50-200 files) | Default with key files  |
| Large (> 200 files)   | Detailed with summaries |

## Use Cases

- **Quick overview** - Get a project snapshot without configuration
- **CI/CD automation** - Use in scripts where detail level varies by project
- **Ad-hoc analysis** - Fast way to generate useful documentation

## Examples

### Small Project

```bash
$ doc-gen structure generate --smart
# Output: Minimal structure showing main directories
```

### Large Project

```bash
$ doc-gen structure generate --smart
# Output: Detailed structure with file counts and summaries
```
