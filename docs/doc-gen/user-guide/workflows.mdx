| Command                               | Effect                       |
| ------------------------------------- | ---------------------------- |
| `doc-gen init`                        | Project setup                |
| `doc-gen structure generate [TARGET]` | Primary workflow             |
| `doc-gen structure print [TARGET]`    | Additional explicit workflow |
| `doc-gen structure analyze [TARGET]`  | Additional explicit workflow |

<InfoBox variant="tip" title="Preview">
  Generate writes only its resolved Markdown output; print and analyze are read-only.
  Generate dry-run never creates its output directory or file.
</InfoBox>
