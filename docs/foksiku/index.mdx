# Foksiku

Foksiku v0.2.0 is a private Telegram expense tracker implemented with TypeScript,
Google Apps Script, and Google Sheets. Invited users can record purchases,
reuse saved products, confirm changes, and request spending reports without
giving a general-purpose chatbot authority over financial records.

**Telegram bot:** [@foksikubot](https://t.me/foksikubot)

## Privacy and access

Foksiku accepts financial and administrative operations only in private
Telegram chats. Access is controlled by numeric Telegram user ID and explicit
roles. Usernames and display names never grant permission.
