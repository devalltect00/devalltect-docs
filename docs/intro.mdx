# Devalltect Documentation

Welcome to the shared documentation portal for Devalltect developer and DevOps tools. Use it to learn a project, find command and configuration references, understand implementation decisions, or prepare a contribution.

## Explore the Projects

| Project                 | Focus                                                                       | Documentation                      |
| ----------------------- | --------------------------------------------------------------------------- | ---------------------------------- |
| **Path Header Scanner** | Path and source-header inspection workflows                                 | [Open docs](./path-header-scanner) |
| **Doc Gen**             | Project structure and documentation generation                              | [Open docs](./doc-gen)             |
| **Reflow**              | Repository-aware tag conversion, release recovery, and container publishing | [Open docs](./reflow)              |
| **Custy**               | Git workflow, version, changelog, backup, cleanup, and release automation   | [Open docs](./custy)               |

See [Projects Overview](./projects-overview) for a broader description of each project and its current documentation coverage.

## Languages

English is the default locale. Bahasa Indonesia is also available from the language selector. The portal maintains aligned English and Indonesian documentation for Custy, Path Header Scanner, Doc Gen, and Reflow.

## Using This Portal

- Start with a project's overview or getting-started section.
- Use command pages for syntax, options, examples, output, and troubleshooting.
- Use concepts and architecture pages to understand behavior and internal boundaries.
- Check the source-aligned reference pages before relying on configuration or workflow details.
- Use the [Devalltect Docs guide](./devalltect-docs) to understand how the portal itself is maintained.

## Repository

The portal source, issue tracker, and deployment workflow are maintained in the [devalltect-docs repository](https://github.com/devalltect00/devalltect-docs). The public site is available at [devalltect00.github.io/devalltect-docs](https://devalltect00.github.io/devalltect-docs).
