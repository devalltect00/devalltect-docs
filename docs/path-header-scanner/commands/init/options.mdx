| Flag / value                      | Default                        | Effect                                                                                     |
| --------------------------------- | ------------------------------ | ------------------------------------------------------------------------------------------ |
| `--mode, -m`                      | `all`                          | Choose `all` or `config`. Both currently initialize the configuration resource.            |
| `--force/--no-force, -f/-F`       | `false`                        | Overwrite an existing selected resource without prompting.                                 |
| `--ask, -a`                       | `false`                        | Ask before creating or replacing resources when a decision is needed.                      |
| `--dry-run/--no-dry-run, -dr/-Dr` | configured value, then `false` | Display the initialization plan without creating directories, writing files, or prompting. |

<InfoBox variant="note" title="Mode scope in v1.0.0">

The installed enum exposes only `all` and `config`. Names such as `templates`
and `examples` are not accepted initialization modes in this release.

</InfoBox>
