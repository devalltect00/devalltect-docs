<Section title="Supported commands">

| Command | Purpose | Writes by default |
| --- | --- | --- |
| [`path-header-scanner init`](./init/overview) | Generate project configuration | Yes, unless dry-run |
| [`path-header-scanner scan TARGET`](./scan/overview) | Discover and preview header changes | No |
| `path-header-scanner scan TARGET --apply` | Apply reviewed insertions or updates | Yes |

</Section>

<InfoBox variant="warning" title="Preview before apply">

`scan` previews by default. `--apply` opts into target-file writes, while an
explicit or configured `--dry-run` overrides apply mode. Initialization has a
separate dry-run option for previewing its configuration plan.

</InfoBox>

Use `--help` on either command for the installed version's exact options.
