## Does scan write by default?

No, it previews.

## What enables writes?

Only effective apply mode; --dry-run always disables it.

## Which languages are supported?

Python, JavaScript, shell, HTML, PHP, and Markdown.

## What does workdir do?

It supplies the base for resolving a relative target.
