| Flag / value                                            | Default          | Effect                                          |
| ------------------------------------------------------- | ---------------- | ----------------------------------------------- |
| `TARGET_DIRECTORY`                                      | app (configured) | Directory to scan.                              |
| `--workdir`                                             | none             | Base used to resolve a relative target.         |
| `--apply`                                               | false            | Write inserted or updated headers.              |
| `--dry-run/--no-dry-run, -dr/-Dr`                       | false            | Force simulation and override apply.            |
| `--include-target-directory/--exclude-target-directory` | true             | Control whether target name appears in headers. |
| `--debug`                                               | false            | Enable scan diagnostics.                        |
