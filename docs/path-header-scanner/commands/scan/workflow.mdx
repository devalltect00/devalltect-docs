### 1. Stage 1

Resolve workdir and target.

### 2. Stage 2

Discover supported files while respecting exclusions.

### 3. Stage 3

Select a language strategy and validate each header.

### 4. Stage 4

Compute valid, inserted, updated, and failed results.

### 5. Stage 5

Write only in live --apply mode; otherwise render preview and summary.

<InfoBox variant="warning" title="Safety boundary">
  Preview is the default. --apply enables writes; --dry-run overrides CLI and configured
  apply mode and guarantees no target-file changes.
</InfoBox>
