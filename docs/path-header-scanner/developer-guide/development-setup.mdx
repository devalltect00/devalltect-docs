## Goal

Install the active checkout with its `dev` dependency group. A runtime-only
`pip install -e .` does not install the quality tools used by this contributor
workflow.

<Section title="Manual Setup">

<Terminal title="Create and install" language="bash">

{`python -m venv venv

# Windows PowerShell
venv\\Scripts\\Activate.ps1

# Linux or macOS
# source venv/bin/activate

python -m pip install --upgrade pip
python -m pip install -e ".[dev]"`}

</Terminal>

Add the `docs` extra only when working with the repository's MkDocs source:
`python -m pip install -e ".[dev,docs]"`.

</Section>

---

<Section title="Makefile Setup">

<Terminal title="Setup helpers" language="bash">

{`make venv
make upgrade-pip
make install-dev

# Combined environment setup and Git-hook installation
make setup`}

</Terminal>

The Make workflow expects the repository's conventional `venv/` directory.

</Section>

<Section title="Pre-Commit Workflow">

The scanner hook configuration runs Ruff fixes, Ruff formatting, Black,
trailing-whitespace cleanup, and final-newline correction. Ruff and Black use
their project policies from `pyproject.toml`.

<Terminal title="Install and run hooks" language="bash">

{`make pre-commit-install-hooks
make pre-commit-validate
make pre-commit-run-staged
make pre-commit-run`}

</Terminal>

<InfoBox variant="warning" title="Refresh can change configuration and source">

Use `make pre-commit-refresh` only when intentionally upgrading hook revisions.
It updates the configuration, clears and reinstalls hook environments, and runs
all hooks against all files. Review the resulting diff before keeping it.

</InfoBox>

</Section>
