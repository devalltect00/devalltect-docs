## Overview

Use temporary source trees for scanner tests. Preview must remain read-only,
`--apply` may update only selected supported files, and `--dry-run` must override
both explicit and configured apply behavior.

<InfoBox variant="tip" title="Pair read and write assertions">

For every mutation feature, assert both the intended changed content and the
files or directories that must remain untouched.

</InfoBox>

<Section title="Focused Validation">

<Terminal title="Focused pytest examples" language="bash">

{`# Scanner processing and updates
python -m pytest tests/core/scan

# One language strategy

python -m pytest tests/languages/test_python_strategy.py

# Full scan integration

python -m pytest tests/integration/test_full_scan.py

# Dry-run regression boundaries

python -m pytest tests/test_dry_run.py`}

</Terminal>

On Windows, pass a repository-local `--basetemp` when the system temporary
directory cannot be accessed.

</Section>

<Section title="Pre-Commit Quality Gates">

The hook runs Ruff lint fixes, Ruff formatting, Black, trailing-whitespace
cleanup, and final-newline correction.

<Terminal title="Pre-commit checks" language="bash">

{`make pre-commit-validate
make pre-commit-run-staged
make pre-commit-run`}

</Terminal>

Protected reference-file exclusions apply even when a hook or editor supplies
a matching path explicitly.
