<Section title="Preview and resolve targets">

<Terminal language="bash">{`# Preview the configured application target
path-header-scanner scan app

# Resolve app from another project base

path-header-scanner scan app --workdir ../project

# Explicit simulation wins over apply

path-header-scanner scan app --apply --dry-run`}</Terminal>

</Section>

<Section title="Apply after review">

<Terminal language="bash">{`# Re-run with writes enabled only after reviewing the preview
path-header-scanner scan app --apply`}</Terminal>

</Section>

<InfoBox variant="warning" title="Know the effective mode">

Preview is the default. `--apply` enables writes, but `--dry-run` from the CLI
or project configuration disables effective apply mode.

</InfoBox>
