## Commands

- `path-header-scanner init`
- `path-header-scanner scan TARGET`
- `path-header-scanner scan TARGET --apply`
- `path-header-scanner scan TARGET --dry-run`

## Global options

- `--no-banner`
- `--version / -v`
- `--help / -h`

<InfoBox variant="warning" title="Safety">
  Scan previews by default. Only effective --apply writes target files, and --dry-run
  overrides CLI and configured apply mode.
</InfoBox>
