- `path-header-scanner scan TARGET`
- `path-header-scanner scan TARGET --apply`
- `path-header-scanner scan TARGET --dry-run`

<InfoBox variant="warning" title="Safety">Scan previews by default. Only effective --apply writes target files, and --dry-run overrides CLI and configured apply mode.</InfoBox>
