| Command | Effect |
| --- | --- |
| `path-header-scanner init` | Project setup |
| `path-header-scanner scan TARGET` | Primary workflow |
| `path-header-scanner scan TARGET --apply` | Additional explicit workflow |
| `path-header-scanner scan TARGET --dry-run` | Additional explicit workflow |

<InfoBox variant="tip" title="Preview">Scan previews by default. Only effective --apply writes target files, and --dry-run overrides CLI and configured apply mode.</InfoBox>
