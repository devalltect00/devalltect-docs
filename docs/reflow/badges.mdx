# 🏷️ Project Badges

This document describes all badges used by Reflow and their purpose.

## 📖 Documentation Strategy

Reflow uses **MkDocs** for project documentation because it is lightweight, fast, and easy to maintain.

The documentation is organized around:

- User Guides
- Command Documentation
- Architecture Documentation
- Configuration Reference
- Developer Documentation

This structure keeps command usage, architecture, and implementation details clearly separated.
