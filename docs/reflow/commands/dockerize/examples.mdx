# Dockerize Releases Examples

## Overview

This document contains practical examples for building and publishing Docker images from Git tags.

Examples range from local testing to production publishing workflows.

---

# Basic Usage

Build and publish images for repository tags.

Command:

```bash id="v81z4e"
reflow dockerize
```

Configuration:

```toml id="6x6jzz"
[tool.reflow.docker]

provider = "github"

[tool.reflow.github]

image = "ghcr.io/acme/my-app"
```

Example repository:

```text id="c7r4i4"
v1.0.0
v1.1.0
v2.0.0
```

Produced images:

```text id="f7h6cu"
ghcr.io/acme/my-app:v1.0.0
ghcr.io/acme/my-app:v1.1.0
ghcr.io/acme/my-app:v2.0.0
```

# Keep Local Images

Configuration:

```toml id="9s6q0i"
[tool.reflow.docker]

keep_local_images = true
```

Workflow:

```text id="0w6s4e"
Build
Push
Keep Image
```

Result:

```text id="w2i8tb"

```

Useful for:

- Local testing
- Verification
- Debugging

# After Tag Conversion

Repository originally used:

```text id="6v5l4f"
v1.0.0rc1
v1.0.0b1
```

Convert first:

```bash id="3uxvmh"
reflow tags convert
```

Result:

```text id="nqq40r"
v1.0.0-rc.1
v1.0.0-beta.1
```

Then:

```bash id="j7l2o9"

```

```text id="2b2p1r"

ghcr.io/acme/my-app:v1.0.0-beta.1
```

# Complete Release Workflow

Recommended workflow:

Step 1:

```bash id="d2k1l7"
reflow tags convert
```

Step 2:

```bash id="w8n4bo"
reflow tags replay
```

Step 3:

```bash id="j6g6vb"
reflow dockerize
```

Workflow:

```text id="79z88j"
Convert Tags
      ↓
Replay Releases
      ↓
Build Images
```

# Common Mistakes

## Docker Not Running

Problem:

```text id="4w1mrx"
Cannot connect to Docker daemon
```

Solution:

Start Docker Desktop or Docker Engine.

---

## Not Logged Into Registry

Problem:

```text id="7g0n9r"
unauthorized
```

Solution:

```bash id="c4s9tz"
docker login ghcr.io
```

or:

```bash id="0ktuxu"
docker login registry.gitlab.com
```

---

## Missing Dockerfile

Problem:

```text id="0v4c5r"
Docker build failed
```

Solution:

Ensure:

```text id="06wxah"
./Dockerfile
```

exists.

---

## Invalid Image Name

Problem:

```text id="x6kn7x"
invalid reference format
```

Verify:

```toml id="x7v87r"
image = "ghcr.io/acme/my-app"
```

is configured correctly.
