### 1. Preview

<Terminal language="bash">{`reflow --dry-run -C ../project dockerize`}</Terminal>

**Result:** Shows operations.

### 2. Publish

<Terminal language="bash">{`reflow -C ../project dockerize`}</Terminal>

**Result:** Builds and pushes.

### 3. URL

<Terminal language="bash">{`reflow --repository-url https://github.com/acme/project.git dockerize`}</Terminal>

**Result:** Uses a managed clone.
