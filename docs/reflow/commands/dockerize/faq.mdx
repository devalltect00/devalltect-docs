# Dockerize Releases FAQ

## Overview

This document answers common questions about the Dockerize command.

If you are new to Reflow, start with:

- overview.md
- workflow.md

before reading this FAQ.

---

# General Questions

## What does Dockerize actually do?

Dockerize builds Docker images from Git tags and publishes them to a container registry.

Workflow:

```text id="9w93ga"
Git Tag
    ↓
Docker Image
    ↓
Registry
```

Example:

```text id="xz5t3w"
v1.0.0
```

becomes:

```text id="juz2ul"
ghcr.io/acme/my-app:v1.0.0
```

---

## Does Dockerize create Git tags?

No.

Dockerize only consumes existing tags.

To create SemVer tags:

```bash id="4b3gwm"
reflow tags convert
```

---

## Does Dockerize replay releases?

No.

To recover release automation:

```bash id="d5imvt"
reflow tags replay
```

---

## Does Dockerize modify commits?

No.

Dockerize:

```text id="0n6hyj"
✓ Builds images
✓ Pushes images

✗ Does not modify commits
✗ Does not modify branches
✗ Does not modify history
```

---

# Tag Questions

## Which tags are used?

Dockerize uses repository tags.

Example:

```text id="7cnzyr"
v1.0.0
v1.1.0
v2.0.0
```

These become Docker image versions.

---

## Does Dockerize build all tags?

Current behavior depends on:

```text id="mljk6t"
Configuration
Resolver logic
Command options
```

The selected tag set is processed.

---

## Can I build only one tag?

Not currently.

Possible future feature:

```bash id="rxyb3e"
reflow dockerize --tag v1.0.0
```

---

## Can I build a tag range?

Not currently.

Possible future feature:

```bash id="f3fffd"
reflow dockerize \
    --from v1.0.0 \
    --to v2.0.0
```

---

## Does Dockerize support prerelease tags?

Yes.

Examples:

```text id="ddh9t4"
v1.0.0-rc.1
v1.0.0-beta.1
v1.0.0-alpha.1
```

become:

```text id="jpsgo5"
ghcr.io/acme/my-app:v1.0.0-rc.1
ghcr.io/acme/my-app:v1.0.0-beta.1
ghcr.io/acme/my-app:v1.0.0-alpha.1
```

# Image Questions

## How are image names generated?

From configuration.

Example:

```toml id="zt5wpu"
[tool.reflow.github]

image = "ghcr.io/acme/my-app"
```

Tag:

```text id="lq3c20"
v1.0.0
```

Produces:

```text id="rj84zs"
ghcr.io/acme/my-app:v1.0.0
```

---

## Does Dockerize create latest?

Not currently.

Current behavior:

```text id="8wz72g"
Version Tags Only
```

Example:

```text id="g8e0ru"
v1.0.0
v2.0.0
```

Produces:

```text id="o4dmdv"
:v1.0.0
:v2.0.0
```

but not:

```text id="bq07ql"
:latest
```

---

## Can I keep local images?

Yes.

Configuration:

```toml id="1y7t6w"
keep_local_images = true
```

---

## Can I automatically remove local images?

Yes.

Configuration:

```toml id="n8rdb8"
keep_local_images = false
```

Workflow:

```text id="ms0cwb"
Build
Push
Delete Local Image
```

# Docker Questions

## Do I need Docker installed?

Yes.

Verify:

```bash id="5v5fjx"
docker --version
```

---

## Does Docker daemon need to be running?

Yes.

Verify:

```bash id="t9ehy7"
docker info
```

---

## Do I need a Dockerfile?

Yes.

Typical location:

```text id="hht31e"
./Dockerfile
```

---

## Can Dockerize generate a Dockerfile?

No.

Dockerize expects a valid Dockerfile already exists.

---

# Authentication Questions

## Do I need registry login?

Yes.

Example:

```bash id="jv1xnp"
docker login ghcr.io
```

or:

```bash id="pmvjyy"
docker login registry.gitlab.com
```

---

## How do I verify authentication?

Try:

```bash id="0z3zlp"
docker pull hello-world
```

or perform a test push.

# Troubleshooting

## Docker Not Found

Problem:

```text id="a4z65s"
docker: command not found
```

Solution:

Install Docker.

---

## Docker Daemon Unavailable

Problem:

```text id="g3s7vt"
Cannot connect to Docker daemon
```

Solution:

Start Docker Desktop or Docker Engine.

---

## Registry Login Failed

Problem:

```text id="r0lww6"
unauthorized
```

Solution:

```bash id="yt1r8x"
docker login ghcr.io
```

or:

```bash id="m0ig99"
docker login registry.gitlab.com
```

---

## Push Denied

Problem:

```text id="7z7fef"
permission denied
```

Possible causes:

```text id="43rzzt"
Wrong credentials
Missing permissions
Wrong repository
Wrong registry
```

---

## Dockerfile Missing

Problem:

```text id="wwgfg4"
failed to read Dockerfile
```

Solution:

Create a valid Dockerfile.
