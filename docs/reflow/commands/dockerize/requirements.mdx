# Dockerize Releases Requirements

## Overview

Before running:

```bash id="uvm7io"
reflow dockerize
```

ensure all required tools, credentials, and configuration are available.

Dockerize depends on several external systems and will fail if any required component is missing.

---

# Required Software

## Git

Git is required.

The command reads repository tags and release versions from Git.

Verify:

```bash id="z8d8ec"
git --version
```

Example:

```text id="ec0j13"
git version 2.50.0
```

---

## Docker

Docker is required.

The command builds and tags Docker images.

Verify:

```bash id="5xhlol"
docker --version
```

Example:

```text id="78jfoh"
Docker version 28.x.x
```

---

## Docker Daemon

Docker daemon must be running.

Verify:

```bash id="mh6kmr"
docker info
```

Expected:

```text id="mz1abx"
Server:
...
```

If Docker daemon is unavailable:

```text id="e6hv4e"
Cannot connect to Docker daemon
```

Dockerize cannot continue.

---

# Repository Requirements

## Valid Git Repository

Dockerize must run inside a Git repository.

Example:

```bash id="t3qhxq"
cd my-project

reflow dockerize
```

---

## Existing Tags

The repository must contain tags.

Verify:

```bash id="mecm0e"
git tag
```

Example:

```text id="b9jlwm"
v1.0.0
v1.1.0
v2.0.0
```

These tags become image versions.

---

## Dockerfile

A valid Dockerfile must exist.

Typical location:

```text id="q6a7mb"
./Dockerfile
```

Example:

```dockerfile id="g5hv83"
FROM python:3.14-slim

COPY . /app

WORKDIR /app

CMD ["python", "main.py"]
```

Without a Dockerfile, image builds will fail.

# Registry Configuration

## GitHub Container Registry

Configuration:

```toml id="rjlwm8"
[tool.reflow.docker]

provider = "github"

[tool.reflow.github]

image = "ghcr.io/acme/my-app"
```

---

## GitLab Container Registry

Configuration:

```toml id="a5p8vf"
[tool.reflow.docker]

provider = "gitlab"

[tool.reflow.gitlab]

image = "registry.gitlab.com/acme/my-app"
```

---

# Authentication

## GitHub Container Registry

Login:

```bash id="t3i7v8"
docker login ghcr.io
```

Verify:

```bash id="nchuk4"
docker info
```

or perform a test push.

Required permissions:

```text id="2l7b0g"
write:packages
read:packages
```

depending on repository configuration.

---

## GitLab Container Registry

Login:

```bash id="5rzvph"
docker login registry.gitlab.com
```

Verify credentials before running Dockerize.

---

Configuration:


# Common Problems

## Docker Not Installed

Problem:

```text id="3s7m4i"
docker: command not found
```

Solution:

Install Docker Desktop or Docker Engine.

---

## Docker Daemon Not Running

Problem:

```text id="1gnpjz"
Cannot connect to Docker daemon
```

Solution:

Start Docker.

Verify:

```bash id="nq04jl"
docker info
```

---

## Dockerfile Missing

Problem:

```text id="yj1yku"
failed to read Dockerfile
```

Solution:

Create a valid Dockerfile.

---

## Authentication Failure

Problem:

```text id="bhbnhs"
unauthorized
```

Solution:

Login again.

Example:

```bash id="u7sj8z"
docker login ghcr.io
```

---

## Invalid Image Name

Problem:

```text id="f4z9mh"
invalid reference format
```

Example:

```text id="r9i4o8"
ghcr.io/
```

Solution:

Configure a complete image name.

---

## Push Failure

Problem:

```text id="2r4dnl"
denied: permission denied
```

Possible causes:

```text id="oz5yd8"
Missing permissions
Wrong credentials
Wrong registry
Wrong repository
```

---
