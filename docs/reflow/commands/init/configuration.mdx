| Configuration key                  | Default | Effect                      |
| ---------------------------------- | ------- | --------------------------- |
| `tool.reflow.initialization.force` | false   | Default overwrite behavior. |
| `tool.reflow.initialization.ask`   | false   | Default prompt behavior.    |

```toml
[tool.reflow.initialization]
force = false
ask = false
```

<InfoBox variant="note" title="Precedence">
  CLI values override project configuration, which overrides internal defaults.
</InfoBox>
