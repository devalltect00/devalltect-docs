### 1. Preview

<Terminal language="bash">{`reflow --dry-run init`}</Terminal>

**Result:** Shows planned resources only.

### 2. Defaults

<Terminal language="bash">{`reflow init`}</Terminal>

**Result:** Creates resolved initialization resources.

### 3. Configuration only

<Terminal language="bash">{`reflow init --mode config`}</Terminal>

**Result:** Creates configuration resources only.

### 4. Force replacement

<Terminal language="bash">{`reflow init --mode all --force`}</Terminal>

**Result:** Replaces selected existing resources.
