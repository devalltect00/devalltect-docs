<InfoBox variant="warning" title="Safety boundary">

Live mode writes only the selected initialization resource. Dry-run does not
create directories, write or replace files, or request overwrite confirmation.
The command never creates commits, tags, pushes, releases, or registry images.

</InfoBox>

<InfoBox variant="note" title="Supported modes in Reflow 1.0.0">

The public CLI accepts `all` and `config`. Both currently prepare the Reflow
configuration workspace; values such as `templates`, `examples`, and
`all_no_examples` are not accepted by the active `InitMode` enum.

</InfoBox>
