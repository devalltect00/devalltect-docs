## Before you run it

- A writable target project directory.
- Reflow installed with Python 3.14 or newer.
- Review existing .config/reflow content before using --force.

<InfoBox variant="tip" title="Dry run">
  Dry-run performs discovery and validation but does not persist local, remote, or
  registry changes.
</InfoBox>
