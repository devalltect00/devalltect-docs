reflow [GLOBAL OPTIONS] init [OPTIONS]`}</Terminal>

<InfoBox variant="note" title="Target and global options">

Place `--repository`/`--repo`/`-C`, `--dry-run`, `--debug`, and `--log-level`
before `init`. Although `--repository-url` is a global option, `reflow init`
rejects URL targets because initialized files must belong to a persistent local
directory.

</InfoBox>
