<Section title="Supported Commands">

| Command | Target and purpose | Persistent live-mode effect |
| --- | --- | --- |
| [`reflow init`](./init/overview) | Persistent local directory; create project-owned configuration | Local configuration file |
| [`reflow tags convert local`](./tags/convert/local/overview) | Persistent local checkout; replace supported tag names | Local tag refs only; never pushes |
| [`reflow tags convert remote`](./tags/convert/remote/overview) | Checkout remote or Git URL; replace supported remote tag names | One guarded atomic remote push |
| [`reflow releases recover`](./releases/recover/overview) | GitHub repository; retrigger automation for tags missing releases | Remote tag delete/re-push and CI trigger |
| [`reflow dockerize`](./dockerize/overview) | Repository tags plus configured image destinations | Docker build, registry push, optional local cleanup |

</Section>

<InfoBox variant="warning" title="Deprecated compatibility alias">

`reflow tags replay` delegates to `reflow releases recover` and prints a
deprecation warning. Use the [canonical recovery guide](./releases/recover/overview)
for new documentation, scripts, and automation.

</InfoBox>

Global target and safety options belong before the command path:
`--repository`/`--repo`/`-C`, `--repository-url`, and `--dry-run`.
