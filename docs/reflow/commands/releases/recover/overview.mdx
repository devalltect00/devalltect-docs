<Section title="Purpose">

Find version tags without corresponding GitHub releases and re-push them to retrigger tag-based CI/CD.

</Section>

<InfoBox variant="warning" title="Safety boundary">Deletes and re-pushes selected tags; it does not create release records through the website or API.</InfoBox>

- Read version tags and releases.
- Select tags lacking releases.
- Apply stable and limit filters.
- Display target and plan.
- After confirmation, delete and re-push with delay.
