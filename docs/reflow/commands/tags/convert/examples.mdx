# Convert Version Tags Examples

## Overview

This document contains practical examples for converting Git tags from PEP 440 format to Semantic Versioning.

Examples range from simple repository conversions to larger migration scenarios.

---

# Basic Conversion

Convert all supported tags.

Command:

```bash
reflow tags convert
```

Example repository:

Before:

```text
v1.0.0rc1
v1.0.0b1
v1.0.0a1
```

After:

```text
v1.0.0rc1
v1.0.0b1
v1.0.0a1

v1.0.0-rc.1
v1.0.0-beta.1
v1.0.0-alpha.1
```

Original tags remain unchanged.

---

# Safe Migration (Recommended)

This is the safest workflow.

Step 1:

Preview operations.

```bash
reflow tags convert --dry-run
```

Step 2:

Convert tags.

```bash
reflow tags convert
```

Step 3:

Verify results.

```bash
git tag
```

Step 4:

Remove old tags later if desired.

This minimizes migration risk.

---

# Conversion With Cleanup

Convert tags and remove originals.

Command:

```bash
reflow tags convert --delete-old
```

Example:

Before:

```text
v2.0.0rc1
```

After:

```text
v2.0.0-rc.1
```

Original tag removed.

Use carefully.

Repository:

```text
v1.0.0
v1.1.0rc1
v1.2.0b2
v1.3.0a1
```

After conversion:

```text
v1.0.0

v1.1.0rc1
v1.1.0-rc.1

v1.2.0b2
v1.2.0-beta.2

v1.3.0a1
v1.3.0-alpha.1
```

Stable releases remain unchanged.

Pre-release tags are converted.

# Python Project Migration

Scenario:

A Python package historically used PEP 440.

Existing tags:

```text
v0.9.0rc1
v1.0.0rc1
v1.1.0b1
```

Goal:

Standardize on SemVer.

Command:

```bash
reflow tags convert
```

Result:

```text
v0.9.0-rc.1
v1.0.0-rc.1
v1.1.0-beta.1
```

# Container Publishing Preparation

Scenario:

Docker image tags should follow SemVer.

Current tags:

```text
v2.0.0rc1
v2.0.0b1
```

Workflow:

```bash
reflow tags convert
```

Then:

```bash
reflow dockerize
```

Result:

```text
v2.0.0-rc.1
v2.0.0-beta.1
```

available for image publishing.

# Dry Run Validation

Always recommended before production migrations.

Command:

```bash
reflow tags convert --dry-run
```

Example output:

```text
Would convert:

v1.0.0rc1
    ↓
v1.0.0-rc.1

v2.0.0b1
    ↓
v2.0.0-beta.1
```

No repository changes are made.

# Common Mistakes

## Using --delete-old Immediately

Risk:

Original tags are removed.

Recommended:

```bash
reflow tags convert
```

Validate first.

Cleanup later.

---

## Converting Unsupported Tags

Example:

```text
release-candidate
preview
build-123
```

These formats are not currently supported.

---

## Skipping Backup

Recommended:

```bash
git tag > tags-backup.txt
```

before large migrations.
