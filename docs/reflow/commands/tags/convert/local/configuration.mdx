| Configuration key | Default | Effect |
| --- | --- | --- |
| `tool.reflow.repository.path` | current directory | Persistent checkout. |
| `tool.reflow.cli.tags.convert.target_format` | semver | Destination format. |
| `tool.reflow.cli.tags.convert.yes` | false | Prompt bypass. |

```toml
[tool.reflow.repository]
path = "../project"

[tool.reflow.cli.tags.convert]
target_format = "semver"
yes = false
```
