<Section title="Purpose">

Replace convertible tag names in one persistent local checkout while preserving tag type and annotated metadata when possible.

</Section>

<InfoBox variant="warning" title="Safety boundary">
  Changes local refs only, rejects repository URLs, and never pushes.
</InfoBox>

- Resolve the checkout and read tag objects.
- Build the complete replacement plan.
- Reject URL targets, collisions, signed tags, and invalid destinations.
- Display target and plan; confirm unless --yes/dry-run.
- Create metadata-preserving destinations, then remove source local refs.
