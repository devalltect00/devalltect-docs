| Symptom              | Likely cause                        | Solution                               |
| -------------------- | ----------------------------------- | -------------------------------------- |
| URL rejected.        | Local scope requires a checkout.    | Clone it or use remote conversion.     |
| Destination exists.  | A distinct ref may be overwritten.  | Resolve the collision manually.        |
| Signed tag selected. | Renaming invalidates its signature. | Recreate the signature outside Reflow. |
