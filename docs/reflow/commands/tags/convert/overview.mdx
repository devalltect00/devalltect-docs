<CommandHero
  command="reflow tags convert"
  title="Tag Conversion"
  description="SemVer is the default destination; select local or remote scope."
  category="Git Tags"
  status="Stable"
  syntax="reflow tags convert local|remote [OPTIONS]"
/>

| Scope  | Guide                       | Effect                      |
| ------ | --------------------------- | --------------------------- |
| Local  | [local](./local/overview)   | Persistent checkout only.   |
| Remote | [remote](./remote/overview) | Guarded atomic remote push. |

<InfoBox variant="warning" title="Replacement">
  A successful conversion creates the destination ref and removes the source ref within
  the selected scope.
</InfoBox>
