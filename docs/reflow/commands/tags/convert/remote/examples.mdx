### 1. Preview URL

<Terminal language="bash">{`reflow --dry-run --repository-url https://github.com/acme/project.git tags convert remote`}</Terminal>

**Result:** Inspects without push.

### 2. Convert

<Terminal language="bash">{`reflow --repository-url https://github.com/acme/project.git tags convert remote --yes`}</Terminal>

**Result:** Atomically replaces refs.

### 3. PEP 440

<Terminal language="bash">{`reflow --repository-url https://github.com/acme/project.git tags convert remote --to pep440 --yes`}</Terminal>

**Result:** Uses PEP 440 destinations.
