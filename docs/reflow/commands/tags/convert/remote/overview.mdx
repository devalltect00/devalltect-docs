<Section title="Purpose">

Replace tag names on a selected Git remote through one guarded atomic push.

</Section>

<InfoBox variant="warning" title="Safety boundary">
  Mutates remote refs only after full validation and confirmation unless --yes is
  supplied.
</InfoBox>

- Resolve URL/checkout and materialize a workspace.
- Build the full remote plan.
- Reject the whole operation if any ref is unsafe.
- Display target, remote, and replacements.
- After confirmation, atomically push creations and deletions.
