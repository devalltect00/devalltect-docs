## Before you run it

- A URL or checkout with a push-capable remote.
- Permission to create and delete tag refs.
- No collision, signed tag, or unsupported conversion.

<InfoBox variant="tip" title="Dry run">
  Dry-run performs discovery and validation without persistent mutation.
</InfoBox>
