| Symptom                  | Likely cause                                    | Solution                                               |
| ------------------------ | ----------------------------------------------- | ------------------------------------------------------ |
| Path and URL configured. | Targets are mutually exclusive.                 | Keep only one.                                         |
| Atomic push rejected.    | Policy, authentication, or deletion was denied. | Review policy/credentials and rerun dry-run.           |
| Clone works, push fails. | Read and write permissions differ.              | Configure Git authentication without tokens in config. |

<InfoBox variant="tip" title="Diagnostics">
  Use `--debug` before retrying live mutation.
