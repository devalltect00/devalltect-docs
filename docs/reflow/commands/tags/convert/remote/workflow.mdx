### 1. Stage 1

Resolve URL/checkout and materialize a workspace.

### 2. Stage 2

Build the full remote plan.

### 3. Stage 3

Reject the whole operation if any ref is unsafe.

### 4. Stage 4

Display target, remote, and replacements.

### 5. Stage 5

After confirmation, atomically push creations and deletions.

<InfoBox variant="warning" title="Safety boundary">Mutates remote refs only after full validation and confirmation unless --yes is supplied.</InfoBox>
