<InfoBox variant="info" title="A URL does not require a permanent clone">

Supported operational commands materialize a repository URL in a managed
temporary workspace. `reflow init` and `reflow tags convert local` require a
persistent local checkout and reject URL targets.

</InfoBox>

<Terminal title="Safe onboarding sequence" language="bash">

{`# Prepare project-owned configuration in a local checkout
reflow -C /path/to/project init

# Review the generated configuration and the Git state
git -C /path/to/project status --short

# Preview local tag conversion without changing refs
reflow --dry-run -C /path/to/project tags convert local --to semver`}

</Terminal>
