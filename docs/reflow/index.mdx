## Overview

Reflow is a repository-aware release-maintenance CLI. It keeps target selection
visible, separates local and remote tag replacement, and applies dry-run and
confirmation boundaries before consequential operations.

<InfoBox variant="warning" title="Repository and image targets are different">

A repository path or URL selects the Git repository. `github.image` and
`gitlab.image` select container destinations; they never select which
repository Reflow operates on.

</InfoBox>

<Terminal title="Safe starting points" language="bash">

# Preview a local-only tag replacement
