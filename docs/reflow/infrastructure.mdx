# Infrastructure

## Overview

Reflow interacts with several external tools and services.

This document explains the infrastructure components used by Reflow and how they fit into release workflows.

---

# Infrastructure Overview

High-level view:

```text id="q7w3mx"
Git Repository
       ↓
Git Tags
       ↓
Reflow
       ↓
GitHub / GitLab
       ↓
Container Registry
```

Depending on the command being executed, Reflow may interact with:

```text id="w4e2jr"
Git
GitHub
GitLab
GitHub CLI
Docker
GitHub Container Registry
GitLab Container Registry
```

---

# Git

## Purpose

Git is the foundation of Reflow.

Reflow uses Git to:

```text id="m8t1fj"
Discover tags
Read tag metadata
Read commit references
Create new tags
Delete tags
```

---

## Commands That Use Git

Convert:

```bash id="r5c2kn"
reflow tags convert
```

Replay:

```bash id="h9d3vp"
reflow tags replay
```

Dockerize:

```bash id="t1x4sb"
reflow dockerize
```

---

## Verify Installation

```bash id="u8y7dr"
git --version
```


# Docker

## Purpose

Docker is used to build container images.

Reflow does not create Dockerfiles.

Instead, it assumes:

```text id="m2v8de"
Dockerfile already exists
```

and automates the release process.

---

## Required For

```bash id="s4q9jk"
reflow dockerize
```

---

## Verify Installation

```bash id="k1x7nv"
docker --version
```

---

# GitHub Container Registry

## Overview

GitHub Container Registry (GHCR) is supported.

Example image:

```text id="y3t5rm"
ghcr.io/your-org/your-image
```

---

## Configuration

```toml id="w6p4sz"
[tool.reflow.docker]

provider = "github"

[tool.reflow.github]

image = "ghcr.io/your-org/your-image"
```

---

## Workflow

```text id="f8m2dv"
Git Tag
      ↓
Docker Build
      ↓
GHCR Push
```

---

# GitLab Container Registry

## Overview

GitLab Container Registry is supported.

Example image:

```text id="r9k1qh"
registry.gitlab.com/your-org/your-image
```

---

## Configuration

```toml id="u2n8xw"
[tool.reflow.docker]

provider = "gitlab"

[tool.reflow.gitlab]

image = "registry.gitlab.com/your-org/your-image"
```

---

## Workflow

```text id="v4j7zy"
Git Tag
      ↓
Docker Build
      ↓
Registry Push
```

# Not Currently Managed By Reflow

Reflow intentionally does not manage:

```text id="h5q2tw"
Kubernetes
Terraform
Cloud Infrastructure
Dockerfile Generation
CI/CD Pipelines
```

These remain the responsibility of the user.

# Summary

Reflow builds on existing infrastructure rather than replacing it.

Core integrations include:

```text id="n3x7rb"
Git
GitHub
GitLab
GitHub CLI
Docker
Container Registries
```

allowing Reflow to automate release and container workflows while keeping infrastructure ownership in the hands of the user.
