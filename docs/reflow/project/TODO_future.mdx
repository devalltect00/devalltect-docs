# TODO - Future

This document tracks potential future improvements for Reflow.

Items are grouped by priority and may change over time.

---

# High Priority

Features that align closely with the current architecture and provide immediate value.

## Tag Filtering

Allow processing only matching tags.

Examples:

```bash
reflow tags convert --match "v2.*"

reflow tags replay --match "v1.*"

reflow dockerize --match "v3.*"
```

Benefits:

- Faster execution
- Safer migrations
- Better control

---

## Single Tag Processing

Allow operating on a single tag.

Examples:

```bash
reflow tags convert --tag v2.0.0rc1

reflow tags replay --tag v2.0.0

reflow dockerize --tag v2.0.0
```

Benefits:

- Easier testing
- Incremental migration
- Safer production usage

---

## Tag Range Processing

Examples:

```bash
reflow dockerize \
    --from v1.0.0 \
    --to v2.0.0

reflow tags replay \
    --from v1.0.0 \
    --to v2.0.0
```

Benefits:

- Large repository support
- Controlled rollouts
