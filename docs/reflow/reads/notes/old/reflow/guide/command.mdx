# 🧩 Commands

## reflow init

Initialize configuration.

```bash
reflow init
````

---

## reflow dockerize

Build and push Docker images.

```bash
reflow dockerize
```

Options:

| Option    | Description           |
| --------- | --------------------- |
| --dry-run | Preview commands only |

---

## reflow replay-tags

Replay Git tags to trigger CI.

```bash
reflow replay-tags
```

Options:

| Option        | Description           |
| ------------- | --------------------- |
| --dry-run     | Simulate only         |
| --delay       | Delay between tags    |
| --only-stable | Skip pre-release tags |
| --limit       | Limit number of tags  |
| --no-debug    | Minimize debug        |

---

## reflow convert-tags

Convert PEP440 → SemVer.
Convert tags format.

```bash
reflow convert-tags
```
