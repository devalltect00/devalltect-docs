# 🧑‍💻 Developer Guide

## 📁 Project Structure

````

app/
cli.py              # CLI entry
core/               # business logic
services/           # external services (Docker, GitHub)
utils/              # helpers (git, config, logging)

```

---

## 🧠 CLI Overview

Commands defined in:

````

app/cli.py

```

---

## 🧩 Commands Mapping

| CLI Command     | Function |
|----------------|--------|
| replay-tags    | Orchestrator |
| convert-tags   | GitHelper |
| dockerize      | DockerService |
| init           | Config generator |

---

## 🧠 Architecture

- CLI → entry point
- Config → `.reflow.toml`
- Services → external integrations
- Core → orchestration logic

---

## 🔄 Flow (dockerize)

```

CLI → Config → Git tags → Docker build → Push → Cleanup

````

---

## 📦 Config Usage

```

app/utils/config.py

```

---

Used in:

- dockerize command

---

## ➕ Extend

To add new provider:

1. Add config
2. Add service
3. Extend CLI logic
```

---

## 🧪 Testing

```bash
pytest
````

---

## ➕ Adding New Provider

1. Create service:

```
app/services/gitlab.py
```

2. Extend config:

```
config.py
```

3. Add logic in CLI

---

## 🧱 Design Principles

* Keep CLI thin
* Move logic to services
* Config-driven behavior
* Sequential execution (predictable)

---

## 🚀 Future Improvements
