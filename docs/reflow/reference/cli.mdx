## Commands

- `reflow init`
- `reflow tags convert local`
- `reflow tags convert remote`
- `reflow releases recover`
- `reflow dockerize`

## Global options

- `--repository / --repo / -C`
- `--repository-url`
- `--dry-run`
- `--debug`
- `--log-level`

<InfoBox variant="warning" title="Safety">
  Local and remote tag replacement are separate commands. Remote pushes, release
  recovery, and registry publishing are explicit external mutations.
</InfoBox>
