These pages document **Reflow v1.0.0** and were reviewed against the active source on **August 25, 2026**. The portal compares this baseline with stable SemVer tags from the public repository during Docusaurus startup and builds.

```bash
reflow --version
```

If the installed version differs from `1.0.0`, review the corresponding release notes before relying on version-sensitive commands or configuration. A freshness notice appears when the portal detects newer documentation, newer releases, or an unavailable remote check.
