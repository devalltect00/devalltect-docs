| Symptom                         | First check                                                           |
| ------------------------------- | --------------------------------------------------------------------- |
| Wrong target                    | CLI target, configured target, then current directory                 |
| Dry-run changed expected result | Confirm mutation was simulated rather than persisted                  |
| Configuration ignored           | Check the exact table/key and CLI override                            |
| External tool failure           | Verify Git, Docker, provider CLI, filesystem, or terminal environment |

<InfoBox variant="tip" title="Diagnostic first">
  Capture the concise error and debug context; do not retry an external mutation
