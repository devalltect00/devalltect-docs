# User Guide Overview

## Welcome

Welcome to Reflow.

Reflow is a command-line tool for:

- Project initialization
- Git tag conversion
- Release replay and recovery
- Docker image publishing

Reflow treats Git tags as the source of truth for release automation.

---

# Who Is This Guide For?

This guide is intended for:

- Developers
- Release maintainers
- DevOps engineers
- Open-source maintainers

You do not need to understand the internal architecture of Reflow to use it.

---

# What Can Reflow Do?

## Initialize Projects

Create project configuration and scaffolding.

Command:

```bash
reflow init
```

---

## Convert Tags

Convert PEP 440 tags into Semantic Version tags.

Command:

```bash
reflow tags convert
```

Example:

```text
v1.0.0rc1
      ↓
v1.0.0-rc.1
```

---

## Replay Releases

Recover release automation from existing Git tags.

Command:

```bash
reflow tags replay
```

---

## Dockerize Releases

Build and publish Docker container images.

Command:

```bash
reflow dockerize
```

---

# Typical Workflow

Most users follow a workflow similar to:

```text
Install Reflow
      ↓
reflow init
      ↓
Edit config.toml
      ↓
reflow tags convert
      ↓
reflow tags replay
      ↓
reflow dockerize
```

Not every project requires every command.

Use only the commands relevant to your workflow.
