# Quick Start

## Overview

This guide helps you get started with Reflow in a few minutes.

By the end of this guide, you will:

- Install Reflow
- Initialize a project
- Configure Reflow
- Run your first command

---

# Prerequisites

Required:

```text id="kpn1tk"
Python 3.14+
Git
```

Recommended:

```text id="jlwm4o"
Docker
GitHub CLI
```

Depending on the commands you plan to use.

---

# Step 1 — Install Reflow

Clone the repository:

```bash id="rl00bk"
git clone <repository-url>
```

Enter the project:

```bash id="zrrk2e"
cd reflow
```

Create a virtual environment:

```bash id="9v3kdu"
python -m venv .venv
```

Activate the environment.

Windows:

```bash id="6bw91k"
.venv\Scripts\activate
```

Linux/macOS:

```bash id="qg0xzk"
source .venv/bin/activate
```

Install Reflow:

```bash id="zlnvh7"
pip install -e .
```

Verify installation:

```bash id="76j6s5"
reflow --help
```

---

# Step 2 — Initialize Project

Create the default Reflow project structure:

```bash id="6xhckr"
reflow init
```

Typical output:

```text id="dkv7wf"
config.toml
__version__.py
templates/
examples/
```

Documentation:

```text id="f12f0w"
docs/init/
```

---

# Step 3 — Review Configuration

Open:

```text id="gtr03t"
config.toml
```

Review settings such as:

```toml id="kbl7n7"
[tool.reflow.docker]

provider = "github"
```

and update them for your project.

---

# Step 4 — Choose A Workflow

Reflow commands are independent.

Use only the commands you need.

---

## Convert Tags

Convert PEP 440 tags into Semantic Version tags.

Command:

```bash id="8rlk9u"
reflow tags convert
```

Example:

```text id="7t4r3j"
v1.0.0rc1
      ↓
v1.0.0-rc.1
```

---

## Replay Releases

Recover GitHub releases from existing tags.

Command:

```bash id="g1x2lu"
reflow tags replay
```

Recommended when:

```text id="l2d86m"
Release automation failed
Releases are missing
Historical releases need recovery
```

---

## Dockerize Releases

Build and publish Docker images.

Command:

```bash id="z9fr8l"
reflow dockerize
```

Supported registries:

```text id="0u4b7j"
GitHub Container Registry
GitLab Container Registry
```

---

# Common Workflow

Many projects follow:

```text id="yd6u8r"
reflow init
      ↓
Edit config.toml
      ↓
reflow tags convert
      ↓
reflow tags replay
      ↓
reflow dockerize
```

Run only the commands relevant to your project.
