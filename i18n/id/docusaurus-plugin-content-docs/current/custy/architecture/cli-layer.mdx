## Tanggung jawab

CLI layer memiliki public command tree dan mengubah input pengguna menjadi nilai bertipe untuk coordinator di core. Callback menjelaskan perilaku serta merakit dependency; logika Git, changelog, release, backup, cleanup, dan mutasi file tetap berada di luar callback.

<InfoBox variant="warning" title="AppContext berbeda dari WorkflowConfig">
  `AppContext` menyimpan flag global pada scope Typer. `WorkflowConfig` adalah model
  konstruksi core. Setiap callback harus memetakan nilai yang didukung secara eksplisit.
</InfoBox>

<Section title="Varian eksekusi">
  Sebagian besar command merakit workflow engine dan registered pipeline. `custy init`
  memakai coordinator initialization khusus; branch cleanup memakai handler khusus;
  group `workflow` masih experimental.
</Section>
