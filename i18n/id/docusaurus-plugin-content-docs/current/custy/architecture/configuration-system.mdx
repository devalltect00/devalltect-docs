## Alur konfigurasi

`custy init` menyalin packaged template ke `.config/custy/`. Setelah itu file tersebut milik project dan dapat diedit pengguna. Loader membaca TOML berdasarkan working directory, resolver menggabungkan CLI value, project config, dan built-in default, lalu subsystem membentuk typed settings yang diperlukan.

<InfoBox variant="warning" title="Cache dan status implementasi">
  Konfigurasi di-cache sekali per process. Tidak semua key yang tersedia pada template
  aktif digunakan runtime; periksa status setiap property pada configuration reference.
</InfoBox>

<Section title="Saat menambah setting">
  Perbarui template, loader/model, resolver atau consumer, validation, dokumentasi, dan
  test terkait. Jangan hanya menambah key TOML tanpa jalur konsumsi yang jelas.
</Section>
