## Peta subsistem

`app/core` memuat orkestrasi aplikasi sekaligus domain dan infrastructure service. `pipeline` mengatur profile dan step; `workflow` membangun service serta mengoordinasikan release; `git_ops` membatasi kebijakan repository dan subprocess; `changelog` mengubah history menjadi Markdown; `initialize`, `backup`, dan `cleanup` menangani pemeliharaan project.

<Section title="Arah dependensi">

```text
CLI callback -> pipeline -> registered step -> WorkflowEngine -> focused service -> Git/files/subprocess
```

Tambahkan perilaku baru sebagai focused service dengan engine method yang tipis agar `WorkflowEngine` tidak menjadi tempat semua implementasi low-level.

</Section>
