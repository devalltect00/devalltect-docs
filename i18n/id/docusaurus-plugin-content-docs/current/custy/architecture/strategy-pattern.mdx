## Tiga tanggung jawab

`TagStrategy` menghasilkan version baru dari input strategy. `TagSorter` mengurutkan tag yang sudah ada. Converter menjembatani format version tertentu. Ketiganya berkaitan, tetapi bukan satu kontrak dan tidak boleh digabungkan hanya karena sama-sama menangani string version.

<InfoBox variant="info" title="Extension point internal">Factory dan strategy memudahkan contributor menambah implementasi, tetapi belum merupakan third-party plugin API yang stabil.</InfoBox>

<Section title="Saat menambah strategy">Tambahkan implementasi, factory dispatch, CLI/config validation, sorter atau conversion hanya bila diperlukan, serta unit dan integration test untuk pre-release, invalid input, dan existing tags.</Section>
