## Peran utama

`WorkflowEngineBuilder` mengubah `WorkflowConfig` menjadi engine dengan Git, changelog, versioning, backup, dan service lain. Registered pipeline step memanggil phase method pada engine melalui shared `GitContext`; engine menyimpan state yang dibutuhkan phase berikutnya.

<InfoBox variant="warning" title="Eksekusi tidak transaksional">Jika phase akhir gagal, commit, tag, atau perubahan file dari phase sebelumnya tidak otomatis dibatalkan. Diagnosis harus dimulai dari state repository aktual.</InfoBox>

<Section title="Batas desain">Engine sebaiknya mengoordinasikan service, bukan menyerap seluruh implementasi. Tambahkan focused service untuk logic baru dan pertahankan phase method singkat serta dapat diuji.</Section>
