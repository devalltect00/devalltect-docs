## Ringkasan

Contoh berikut menunjukkan cara paling umum membuat backup copy dari template
files Custy.

---

<CommandExample
  examples={[

    {
      title: "Backup Tag Message Template",

<Section title="Workflow yang Direkomendasikan">

Backup paling berguna sebelum:

- Memperbarui commit message templates.
- Mengubah tag message templates.
- Menguji format template alternatif.
- Bereksperimen dengan release workflows.
- Melakukan pemeliharaan proyek.

</Section>

---

<InfoBox variant="tip" title="Buat Backup Sebelum Mengedit">

Membuat backup sebelum perubahan lebih mudah daripada mencoba memulihkan versi
lama setelahnya. Backup rutin membantu mempertahankan riwayat revisi template.

</InfoBox>

---

<Section title="Langkah Berikutnya">

Lanjutkan ke halaman **Output** untuk mempelajari informasi yang dilaporkan
Custy setelah membuat backup files.

</Section>
