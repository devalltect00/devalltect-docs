## Ringkasan

Command backup menerima command-specific options yang mengatur cara backup
files dibuat. Nilai configuration juga dapat ditentukan dari `config.toml`
proyek.

<InfoBox variant="tip" title="Configuration First">

Command-line options meng-override nilai configuration hanya untuk eksekusi
saat ini. Jika option tidak diberikan, Custy memakai configured value proyek
atau default bawaan.

</InfoBox>

<Section title="Resolusi Option">

Custy menentukan perilaku backup dalam urutan:

1. Command-line options.
2. Project configuration (`config.toml`).
3. Default bawaan Custy.

Dengan demikian, proyek dapat menetapkan backup policy dan eksekusi individual
tetap dapat meng-override pengaturan tertentu.

</Section>

---

<InfoBox variant="note" title="Global CLI Options">

Global options `--dry-run`, `--debug`, dan `--log-level` didokumentasikan
terpisah karena berlaku untuk setiap command Custy.

</InfoBox>

---

<Section title="Backup Directories">

Backup destination bergantung pada subcommand yang dipilih. Lokasi umum
mencakup direktori terpisah untuk commit backup dan tag backup, dan dapat
disesuaikan melalui project configuration.

</Section>

---

<Section title="Langkah Berikutnya">

Lanjutkan ke halaman **Backup Files** untuk mempelajari file yang di-backup,
lokasi penyimpanan, penamaan, dan pengelolaan backup lama.

</Section>
