## Ringkasan

Setelah operasi selesai, Custy melaporkan hasil backup beserta informasi
generated files. Satu atau beberapa template files dapat di-backup dalam satu
eksekusi sesuai subcommand.

<Section title="Backup Berhasil">

Ketika backup berhasil:

- File ditulis ke configured backup directory.
- Backup lama tetap tersedia kecuali dihapus retention policy.
- Template asli tidak berubah.
- Riwayat Git tidak berubah.

</Section>

---

<Section title="Backup Retention">

Setelah membuat backup, Custy dapat menghapus file lama sesuai configured
retention policy. Housekeeping ini mencegah direktori berkembang tanpa perlu
sambil mempertahankan riwayat terbaru.

</Section>

---

<Section title="Template Files Tidak Tersedia">

Jika template yang diminta tidak tersedia, Custy melewati operasi tersebut
dengan aman dan tidak membuat backup kosong. Operasi lain masih dapat
dilanjutkan sesuai subcommand.

</Section>

---

<InfoBox variant="tip" title="Dry Run">

Dengan global option `--dry-run`, Custy melaporkan operasi yang akan dilakukan
tanpa membuat backup files.

</InfoBox>

---

<Section title="Langkah Berikutnya">

Jika backup tidak berhasil, lanjutkan ke halaman **Troubleshooting**.

</Section>
