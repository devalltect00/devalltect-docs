## Ringkasan

Command **backup** membuat backup copy dari template files Custy sebelum file
tersebut diubah atau digunakan kembali oleh workflow berikutnya.

Command ini tidak mem-backup seluruh proyek. Fokusnya adalah generated template
resources Custy agar versi sebelumnya dapat dipulihkan jika diperlukan.

<InfoBox variant="tip" title="Aman Sebelum Perubahan">

Membuat backup sebelum mengedit template mempertahankan versi sebelumnya dan
memberikan recovery point jika perubahan perlu dibatalkan.

</InfoBox>

<Section title="Apa yang Di-backup?">

Custy dapat membuat backup untuk:

- Commit message templates.
- Tag message templates.
- Custom template locations dalam `.config/custy/config.toml`.

Backup files ditulis ke configured backup directories dengan timestamped
filenames untuk mempertahankan versi sebelumnya.

</Section>

---

<InfoBox variant="note" title="Pengelolaan Backup Otomatis">

Custy otomatis membuat backup directories saat diperlukan dan mengelola file
lama sesuai configured retention policy.

</InfoBox>

---

<Section title="Kapan Backup Perlu Dibuat?">

Backup direkomendasikan sebelum:

- Mengedit template files.
- Mengubah commit conventions.
- Memperbarui release message formats.
- Memigrasikan project configuration.
- Menjalankan release workflows.

Walaupun opsional, backup memberikan mekanisme pemulihan sederhana untuk
perubahan template.

</Section>
