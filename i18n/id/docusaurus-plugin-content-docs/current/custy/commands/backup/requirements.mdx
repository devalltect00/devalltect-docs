## Ringkasan

Command **backup** bekerja pada file yang dibuat atau dikelola Custy. Sebelum
membuat backup, pastikan template files yang diperlukan sudah tersedia dalam
proyek.

<InfoBox variant="tip" title="Jalankan Init Lebih Dahulu">

Jika proyek belum di-init, jalankan `custy init` sebelum membuat backup.
Init membuat configuration dan template files yang digunakan command backup.

</InfoBox>

<Section title="Persiapan yang Direkomendasikan">

Sebelum membuat backup:

- Jalankan `custy init` jika proyek belum di-init.
- Tinjau configuration `config.toml` proyek.
- Pastikan template files yang ingin di-backup tersedia.
- Pastikan configured backup directory dapat ditulis.

</Section>

---

<InfoBox variant="note" title="Operasi Aman">

Backup tidak mengubah riwayat Git. Command hanya membuat timestamped copy dari
template yang dipilih di configured backup directories.

</InfoBox>

---

<Section title="Apa yang Tidak Diperlukan?">

Command backup tidak memerlukan staged Git changes, Git tags, remote
repositories, atau published releases. Command hanya memerlukan file yang akan
di-backup.

</Section>
