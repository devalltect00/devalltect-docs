## Ringkasan

Command **backup** menyediakan tiga subcommands untuk menentukan template
resources yang di-backup. Setiap subcommand menjalankan operasi berbeda dengan
perilaku umum yang sama.

<InfoBox variant="tip" title="Pilih Scope yang Sesuai">

Gunakan backup scope terkecil yang memenuhi workflow. Jika hanya commit message
template yang berubah, backup template tersebut saja biasanya sudah cukup.

</InfoBox>

<Section title="Subcommands">

| Subcommand | Tujuan |
|------------|--------|
| `commit` | Backup commit message template yang dikonfigurasi. |
| `tag` | Backup tag message template yang dikonfigurasi. |
| `all` | Backup kedua template files dalam satu operasi. |

Setiap subcommand membuat timestamped backup files di configured backup
directories.

</Section>

---

<Section title="Integrasi Workflow">

Command backup dapat dijalankan langsung jika Anda hanya ingin membuat backup.
Backup operations juga dapat menjadi bagian dari workflow Custy yang lebih
besar. Workflow-oriented backup stages tersebut dijelaskan dalam dokumentasi
command **Run**.

</Section>

---

<InfoBox variant="note" title="Global CLI Options">

Global options `--dry-run`, `--debug`, dan `--log-level` didokumentasikan
terpisah dalam dokumentasi CLI karena berlaku untuk semua command Custy.

</InfoBox>
