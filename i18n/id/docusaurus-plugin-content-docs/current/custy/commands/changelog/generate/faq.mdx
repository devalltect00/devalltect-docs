## Ringkasan

<InfoBox variant="info" title="Gunakan Direct Command">Untuk operasi terfokus, gunakan `custy changelog generate`.</InfoBox>

<Section title="Apakah Generation Mengubah Git History?">Tidak. Generator menulis changelog artifact tetapi tidak membuat commit, tag, atau push.</Section>
<Section title="Dapatkah Saya Menjalankan custy run changelog?">Jangan dokumentasikan internal stage sebagai public profile. Gunakan direct command; profile besar dapat menjalankannya secara internal.</Section>
<Section title="Haruskah Semua Commit Menggunakan Conventional Commits?">Tidak selalu, tetapi structured messages menghasilkan classification dan grouping yang lebih dapat diprediksi.</Section>
<Section title="Apakah --force Mengabaikan Semua Configuration?">Tidak. Option tersebut mengubah keputusan force-generation, bukan menonaktifkan seluruh aturan collection dan rendering.</Section>

## Bagaimana Cara Membuat Changelog Hanya dari Riwayat Git?

<Section>

Di `.config/custy/config.toml` milik proyek Anda, ubah `enabled` menjadi `false`
pada bagian pending commit yang sudah ada:

<Terminal title="Kecualikan pesan pending commit" language="toml">

{`[tool.custy.changelog.pending_commit]
enabled = false`}

</Terminal>

Kemudian jalankan `custy changelog generate` seperti biasa. Anda tidak perlu
menghapus atau mengosongkan `commit-message.txt`; file tersebut tetap dapat
digunakan untuk operasi commit. Pesan yang sudah di-commit ke Git masih dapat
muncul melalui riwayat, sesuai filter changelog Anda.

Lihat [konfigurasi Pending Commit](../../../configuration/changelog/pending-commit#buat-changelog-hanya-dari-riwayat-git)
untuk perbandingan pengaturan dan contoh pembuatan ulang changelog.

</Section>

<Section title="Dapatkah Manual Content Dipertahankan dalam CHANGELOG.md?">Tergantung template dan generation behavior. Selalu uji dengan dry run dan tinjau diff sebelum mengandalkan preservation.</Section>
<Section title="Di Mana Generator Dikonfigurasi?">Edit `.config/custy/config.toml` dan template dalam `.config/custy/templates/`; jangan mengedit source template internal aplikasi.</Section>
