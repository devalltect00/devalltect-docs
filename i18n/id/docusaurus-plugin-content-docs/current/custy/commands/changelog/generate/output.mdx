## Ringkasan

<Section title="Console Progress">

Custy menampilkan determinate Rich progress bar saat mengumpulkan changelog
history. Total progress terdiri dari satu unit untuk `Unreleased` dan satu unit
untuk setiap Git tag yang ditemukan. Deskripsi berubah dari `Processing
Unreleased changes` menjadi `Processing release TAG` ketika setiap range
diproses.

<InfoBox variant="info" title="Progress Selesai Bukan Konfirmasi File Ditulis">

Progress bar melacak history collection. Release behavior, sorting, rendering,
dan keputusan final output berlangsung sesudahnya. Dalam dry-run, Custy tetap
menampilkan progress dan merender preview tanpa mengganti `CHANGELOG.md`.

</InfoBox>
