## Ringkasan

Generator membaca repository history, project configuration, dan template sebelum menulis artifact Markdown.

<InfoBox variant="warning" title="Repository File Change">Command ini dapat membuat atau mengubah `CHANGELOG.md`. Gunakan `custy --dry-run changelog generate` dan tinjau diff.</InfoBox>
