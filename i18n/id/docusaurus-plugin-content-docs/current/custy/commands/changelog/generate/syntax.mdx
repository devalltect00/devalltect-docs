## Ringkasan

<CommandSyntax
  examples={[
    { title: "Default Generation", command: `custy changelog generate` },
    { title: "Force Generation", command: `custy changelog generate --force` },
    {
      title: "Alternative Pending Message",
      command: `custy changelog generate --commit-msg-file path/to/commit-message.txt`,
    },
    { title: "Preview", command: `custy --dry-run changelog generate` },
  ]}

<Section title="Global Option Placement">
  Tempatkan `--dry-run`, `--debug`, atau `--log-level` sebelum `changelog generate`.
</Section>

<InfoBox variant="warning" title="Unsupported Form">
  Jangan menganggap nama internal pipeline sebagai public Run value. Gunakan `custy
  changelog generate` untuk operasi langsung.
</InfoBox>
