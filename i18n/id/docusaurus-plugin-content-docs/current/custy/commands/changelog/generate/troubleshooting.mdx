## Ringkasan

<InfoBox variant="tip" title="Periksa Input Sebelum Mengulang">
  Periksa Git history, tags, effective configuration, template path, pending message,
  dan current diff.
</InfoBox>

## Commit Tidak Muncul

<Section compact>
  Periksa release boundary, ignored types, merge-commit policy, message parsing, serta
  filter konfigurasi.
</Section>

## Entry yang Sama Muncul Lebih dari Sekali

<Section compact>
  Periksa deduplication, pending content, release boundaries, dan apakah artifact lama
  ikut digabungkan.
</Section>

## Scope Heading Terlalu Ramai

<Section compact>
  Tinjau `scope_map`, group-by-scope behavior, dan aturan unknown scope.
</Section>

## Pending Content Salah Posisi

<Section compact>
  Periksa apakah pending collection aktif, file yang dibaca benar, serta placement dan
  release behavior yang berlaku.
</Section>

## Comparison Link Tidak Benar

<Section compact>
  Periksa repository URL, tag format, previous/current release boundary, dan link
  configuration.
</Section>

## Alternative Pending Message File Ditolak

<Section compact>
  Pastikan path pada `--commit-msg-file` menunjuk file yang ada dan dapat dibaca dari
  current working directory.
</Section>

## Pemulihan yang Aman

<Section compact>
  Simpan atau tinjau perubahan yang diperlukan, pulihkan artifact yang salah melalui
  version control, lalu jalankan dry run setelah memperbaiki akar masalah.
</Section>
