## Ringkasan

<InfoBox variant="info" title="Progress Bar Mencakup History Collection">

Progress counter selesai setelah Custy memproses `Unreleased` dan setiap tagged
release range. Release behavior, sorting, template rendering, serta keputusan
normal-write atau dry-run-preview masih berlangsung sesudahnya.

</InfoBox>

<InfoBox variant="info" title="Juga Digunakan oleh Profile Besar">Generation merupakan internal stage dalam `custy run commit`, `custy run release`, dan `custy run full`. Standalone command tetap `custy changelog generate`.</InfoBox>

<Section title="Failure Behavior">Jika collection, parsing, template resolution, atau rendering gagal, perbaiki stage tersebut dan periksa working-tree diff sebelum menjalankan ulang.</Section>
