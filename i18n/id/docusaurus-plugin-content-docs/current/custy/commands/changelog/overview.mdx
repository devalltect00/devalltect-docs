## Ringkasan

Custy mengumpulkan commit yang memenuhi syarat, membersihkan presentation-only content, mengelompokkan entry, membuat link, lalu merender changelog dengan template proyek.

<InfoBox variant="info" title="Gunakan Public Command">Operasi mandiri yang didukung adalah `custy changelog generate`. Changelog juga dapat dijalankan sebagai internal stage dalam profile publik tertentu.</InfoBox>
