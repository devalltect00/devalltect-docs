## Ringkasan
Options meng-override `config.toml` untuk satu eksekusi.

<Section title="Options yang Tersedia">
<CommandOption options={[
    {name: "--type", shorthand: "-t", required: false, defaultValue: "all", description: "Pilih kategori backup yang dibersihkan.", example: "--type commit"},
    {name: "--keep", shorthand: "-k", required: false, defaultValue: "10", description: "Tentukan jumlah backup terbaru yang dipertahankan.", example: "--keep 20"},
]} />
</Section>

<Section title="Cleanup Types">
| Value | Deskripsi |
|---|---|
| `commit` | Hanya commit message backups. |
| `tag` | Hanya tag message backups. |
| `all` | Keduanya. |
</Section>

<Section title="Retention Count">
`--keep` menentukan jumlah terbaru yang dipertahankan, misalnya `--keep 5`,
`--keep 10`, atau `--keep 20`.
</Section>

<InfoBox variant="tip" title="Project Defaults">
Tim dapat menetapkan defaults dalam `config.toml`.
</InfoBox>

<Section title="Global Options">
`--dry-run`, `--debug`, dan `--log-level` berada sebelum command:
```bash
custy --dry-run cleanup backups
```
</Section>

<Section title="Configuration Resolution">
Prioritas: command-line option, project configuration, lalu built-in default.
</Section>
