## Ringkasan

Backup Cleanup menghapus backup files lama yang dibuat Custy sambil
mempertahankan backup terbaru sesuai retention policy. Operasi ini hanya
mengubah backup files dan tidak memodifikasi Git repository.

<InfoBox variant="tip" title="Maintenance yang Aman">

Backup Cleanup tidak mengubah source files, commit, branch, atau tag.

</InfoBox>

<Section title="Integrasi Workflow">

Operasi dapat dijalankan langsung atau otomatis setelah backup stages dalam
beberapa pipeline Custy.

</Section>

<InfoBox variant="note" title="Berbasis Configuration">

Jumlah backup yang dipertahankan dikendalikan oleh `config.toml` proyek.

</InfoBox>

<Section title="Kapan Digunakan?">

Gunakan ketika direktori berisi banyak file historis, ingin menghemat disk,
atau hanya ingin menyimpan backup terbaru.

</Section>
