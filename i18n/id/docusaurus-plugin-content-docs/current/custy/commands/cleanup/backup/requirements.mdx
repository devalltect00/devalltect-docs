## Ringkasan

Backup Cleanup bekerja pada backup files yang sebelumnya dibuat Custy. Pastikan
file sudah tersedia dan retention policy sesuai kebutuhan.

<InfoBox variant="tip" title="Paling Berguna Setelah Operasi Backup">

Proyek dengan sedikit backup files mungkin tidak memiliki file untuk dihapus.

</InfoBox>

<Section title="Persiapan yang Direkomendasikan">

- Pastikan backup files tersedia.
- Tinjau retention count.
- Pastikan file penting tidak lagi diperlukan.
- Tinjau cleanup configuration.

</Section>

<InfoBox variant="note" title="Git Repository Tidak Diperlukan">
  Operasi hanya bekerja pada backup files Custy dan tidak memerlukan Git.
</InfoBox>

<Section title="Configuration">
  `config.toml` mengatur cleanup target, retention count, dan backup directories.
  Command-line options dapat meng-override nilai untuk satu eksekusi.
</Section>

<Section title="Apa yang Tidak Diperlukan?">
  Staged changes, commit, branch, tag, dan remote tidak diperlukan.
</Section>

<Section title="Langkah Berikutnya">
  Lanjutkan ke **Syntax** untuk memilih commit backup, tag backup, atau keduanya.
</Section>
