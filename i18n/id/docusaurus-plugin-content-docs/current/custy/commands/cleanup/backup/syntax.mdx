## Ringkasan

Command membersihkan commit message backups, tag message backups, atau keduanya
sesuai options dan project configuration.

<Section title="Basic Syntax">
  <CommandSyntax
    examples={[
      {
        title: "Backup Cleanup",
        description: "Hapus obsolete backup files dengan configured settings.",
        command: "custy cleanup backups",
      },
    ]}
  />
</Section>

<InfoBox variant="note" title="Public Invocation">
  Gunakan `custy cleanup backups`. `cleanup_backups` bukan public Run argument.
</InfoBox>

<Section title="Cleanup Targets">
  Target dapat berupa commit backups, tag backups, atau keduanya.
</Section>

<Section title="Global Options">
  <Terminal>```bash custy --dry-run cleanup backups ```</Terminal>
  <Terminal>```bash custy --debug cleanup backups ```</Terminal>
  <Terminal>```bash custy --log-level DEBUG cleanup backups ```</Terminal>
  Global options selalu berada sebelum command.
</Section>

<InfoBox variant="tip" title="Configuration First">
  Jika options tidak diberikan, Custy menggunakan `config.toml`.
</InfoBox>

<Section title="Exit Behavior">
  Command dapat menghapus file lama, menentukan cleanup tidak diperlukan, lalu
  melaporkan summary tanpa mengubah Git repository.
</Section>

<Section title="Langkah Berikutnya">Lanjutkan ke **Options**.</Section>
