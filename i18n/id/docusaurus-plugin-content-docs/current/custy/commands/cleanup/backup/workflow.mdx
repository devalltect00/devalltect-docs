## Ringkasan

Backup Cleanup menghapus file lama secara predictable sambil mempertahankan
backup terbaru. Source files dan Git metadata tidak berubah.

<Section title="Workflow Stages">
  <WorkflowStep title="1. Resolve Cleanup Settings">
    Gabungkan arguments, `config.toml`, dan defaults.
  </WorkflowStep>
  <WorkflowStep title="2. Scan Backup Directories">
    Cari commit backup, tag backup, atau keduanya.
  </WorkflowStep>
  <WorkflowStep title="3. Preserve the Newest Backups">
    Urutkan terbaru ke terlama dan pertahankan jumlah yang ditentukan.
  </WorkflowStep>
  <WorkflowStep title="4. Remove Old Backups">
    Hanya file yang melebihi retention count dihapus.
  </WorkflowStep>
  <WorkflowStep title="5. Finish">
    Laporkan summary tanpa mengubah branch, commit, atau tag.
  </WorkflowStep>
</Section>
