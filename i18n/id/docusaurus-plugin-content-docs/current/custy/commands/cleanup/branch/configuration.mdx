## Ringkasan

Branch Cleanup membaca pengaturan cleanup dari `.config/custy/config.toml`. Konfigurasi proyek membuat kebijakan konsisten untuk developer dan pipeline.

<InfoBox variant="danger" title="Periksa Konfigurasi Sebelum Eksekusi">
  Kesalahan prefix atau filter dapat memperluas kandidat penghapusan. Gunakan dry run
  setelah setiap perubahan konfigurasi.
</InfoBox>

<Section title="Protected Branches">
  Daftar protected branch dikelola oleh konfigurasi Git/Custy terkait. Branch yang
  dilindungi selalu dikecualikan dari kandidat.
</Section>

<Section title="Layered Filtering">
  Branch harus cocok dengan prefix, merge status, batas usia atau tanggal yang aktif,
  dan bukan protected branch. Setiap filter mempersempit kandidat.
</Section>

<Section title="Strategi yang Disarankan">
  Mulai dengan prefix sempit, gunakan `merged`, lindungi branch utama, lalu tambahkan
  filter usia. Verifikasi dengan `custy --dry-run cleanup branches`.
</Section>
