## Ringkasan

Branch Cleanup mengevaluasi local Git branch melalui beberapa filter dan hanya menghapus branch yang memenuhi seluruh aturan aktif.

<InfoBox variant="danger" title="Branch Cleanup Mengubah Git Repository">
  Command ini dapat menghapus local branch. Tinjau konfigurasi dan gunakan `custy
  --dry-run cleanup branches` sebelum eksekusi nyata.
</InfoBox>

<Section title="Alur Ringkas">

1. Baca configuration.
2. Periksa local branches.
3. Terapkan filters.
4. Lindungi protected branches.
5. Hapus kandidat.
6. Tampilkan summary.

</Section>

<InfoBox variant="warning" title="Configuration Driven">
  Jika `include_prefixes` tidak dikonfigurasi dan tidak diberikan melalui CLI, Custy
  memilih perilaku aman dan tidak menghapus branch.
</InfoBox>
