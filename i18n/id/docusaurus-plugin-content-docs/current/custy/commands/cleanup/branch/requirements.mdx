## Ringkasan

Pastikan Anda menjalankan command dari Git repository yang benar dan memahami branch mana yang boleh dihapus.

<InfoBox variant="warning" title="Tinjau Sebelum Menghapus">Mulai dengan `custy --dry-run cleanup branches`. Penghapusan local branch tidak selalu mudah dipulihkan.</InfoBox>
