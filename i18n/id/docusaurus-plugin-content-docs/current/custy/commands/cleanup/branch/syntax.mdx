## Ringkasan

<Terminal command="custy cleanup branches" title="Basic Syntax" />

<InfoBox variant="note" title="Public Invocation">Gunakan `custy cleanup branches` untuk operasi mandiri. Nama step internal bukan nilai publik untuk `custy run`.</InfoBox>

<Section title="Global Options">
Global options ditempatkan sebelum subcommand:

```bash
custy --dry-run cleanup branches
custy --debug cleanup branches
custy --log-level DEBUG cleanup branches
```
</Section>

<Section title="Hasil Ditentukan oleh Konfigurasi">Command yang sama dapat menghasilkan kandidat berbeda karena Custy menggabungkan project configuration dengan option CLI.</Section>
