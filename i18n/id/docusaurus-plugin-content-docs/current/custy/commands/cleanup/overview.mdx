## Ringkasan

Command **cleanup** menghapus resource yang tidak lagi diperlukan setelah
aktivitas development rutin. Custy mendukung dua operasi yang independen:

- **Backup Cleanup** menghapus backup files lama sambil mempertahankan backup
  terbaru sesuai retention policy.
- **Branch Cleanup** menghapus Git branches yang memenuhi cleanup rules sambil
  melindungi branch penting seperti `main`, `master`, dan `develop`.

<InfoBox variant="tip" title="Dua Operasi Cleanup yang Independen">

Backup Cleanup mengelola file yang dibuat Custy. Branch Cleanup mengelola Git
branches dalam repository. Jalankan sesuai kebutuhan maintenance.

</InfoBox>

<Section title="Cleanup Otomatis dan Manual">

| Operasi | Otomatis | Manual | Tujuan |
|---|---|---|---|
| Backup Cleanup | Ya | Ya | Menghapus backup files lama. |
| Branch Cleanup | Tidak | Ya | Menghapus obsolete Git branches. |

Backup Cleanup dapat berjalan otomatis dalam workflow tertentu. Branch Cleanup
sengaja dijalankan manual karena memodifikasi Git repository.

</Section>

---

<InfoBox variant="warning" title="Tinjau Operasi yang Dipilih">

Kedua operasi bekerja pada resource berbeda. Pahami configuration dan safety
mechanism masing-masing sebelum menjalankannya.

</InfoBox>

---

<Section title="Integrasi Workflow">

Backup Cleanup terintegrasi ke beberapa pipeline. Branch Cleanup tidak
disertakan dalam automated release workflow untuk mencegah penghapusan branch
yang tidak disengaja.

</Section>

---

<Section title="Berbasis Configuration">

`config.toml` mengatur retention count, branch prefix, merge status, branch
age, dan date filters agar maintenance sesuai Git workflow proyek.

</Section>
