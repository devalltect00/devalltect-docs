## Ringkasan

<InfoBox variant="tip" title="Mulai dengan Dry Run">Gunakan `custy --dry-run commit` sebelum profile menulis artifacts, mengubah index, atau membuat commit.</InfoBox>

<CommandExample examples={[
 {title:"Preview Before Changing the Repository",command:"custy --dry-run commit",description:"Tinjau planned pipeline melalui global dry-run mode.",result:"Tidak menerapkan perubahan normal profile."},
 {title:"Project Defaults",command:"custy commit",description:"Gunakan resolved configuration.",result:"Menjalankan seluruh commit profile."},
 {title:"Update Tracked Files",command:"custy commit --auto-stage --stage-mode update",description:"Stage tracked modifications.",result:"Menggunakan update staging behavior."},
 {title:"Alternative Version File",command:"custy commit --version-file src/package_version.py",description:"Override version file.",result:"Menulis resolved version ke file tersebut."},
 {title:"Allow Empty Commit",command:"custy commit --allow-empty-commit",description:"Izinkan deliberate empty commit.",result:"Commit dapat dibuat tanpa normal changes."},
]} />

<InfoBox variant="warning" title="Empty Commits Merupakan Pengecualian Disengaja">Gunakan hanya untuk workflow yang memang membutuhkan commit tanpa normal file changes.</InfoBox>
