## Ringkasan

<InfoBox variant="info" title="A Multi-stage Profile">
  Command mengoordinasikan validation dan artifacts sebelum final Git commit.
</InfoBox>

<Section title="Apakah custy commit Sama dengan git commit?">
  Tidak. Custy menjalankan versioning, artifact, changelog, backup, validation, dan
  staging stages tambahan.
</Section>
<Section title="Apakah Command Ini Melakukan Push?">
  Tidak. Profile berhenti setelah local commit.
</Section>
<Section title="Apa Perbedaan custy run commit?">
  Keduanya menggunakan registered commit profile; direct command menyediakan
  commit-specific CLI overrides.
</Section>
<Section title="Dapatkah Command Membuat Empty Commit?">
  Ya, bila `--allow-empty-commit` atau resolved configuration mengizinkannya.
</Section>
<Section title="Apakah Command Membuat Changelog?">
  Ya, changelog generation merupakan internal stage profile.
</Section>
<Section title="Haruskah Saya Stage Manual Terlebih Dahulu?">
  Tergantung `auto_stage` dan `stage_mode`. Tinjau resolved configuration dan Git index
  sebelum eksekusi.
</Section>
