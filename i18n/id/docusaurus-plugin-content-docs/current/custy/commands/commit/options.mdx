## Ringkasan

<CommandOption options={[
 {name:"--commit-msg-file",shorthand:"-cmsg",description:"Override existing commit-message template.",example:"--commit-msg-file templates/commit-message.txt"},
 {name:"--auto-stage",shorthand:"-as",description:"Aktifkan automatic staging.",defaultValue:"Resolved configuration",example:"--auto-stage"},
 {name:"--stage-mode",shorthand:"-sm",description:"Pilih all, update, none, atau manual.",example:"--stage-mode update"},
 {name:"--allow-empty-commit / --no-allow-empty-commit",shorthand:"-aec / -Aec",description:"Izinkan atau tolak commit tanpa normal changes.",example:"--allow-empty-commit"},
 {name:"--strategy",description:"Pilih semver, pep440, date, gitcount, atau commitizen.",example:"--strategy semver"},
 {name:"--backup-commit-dir",shorthand:"-bcd",description:"Override commit-message backup directory.",example:"--backup-commit-dir .config/custy/templates/backups/commit"},
 {name:"--version-file",shorthand:"-vf",description:"Override existing project version file.",example:"--version-file app/__version__.py"},
 {name:"--check-cz",shorthand:"-cz",description:"Wajibkan configured dan installed Commitizen validation untuk invocation ini.",example:"--check-cz"},
]} />

<Section title="Global Execution Options">`custy --dry-run commit`, `custy --debug commit`, dan `custy --log-level debug commit`.</Section>
<InfoBox variant="tip" title="Gunakan Provider Configuration untuk Team Policy">`--check-cz` sekarang menjadi strict one-time override yang setara dengan `provider = "commitizen"` dan `require_tool = true`. Untuk reusable policy, lihat [Commit validation configuration](../../configuration/commit-validation).</InfoBox>
