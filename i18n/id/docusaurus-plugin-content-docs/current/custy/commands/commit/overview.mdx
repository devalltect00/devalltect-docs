## Ringkasan

`custy commit` adalah multi-stage profile, bukan sekadar wrapper untuk `git commit`.

<InfoBox variant="warning" title="Broad Working-Tree Effects">Profile dapat mengubah version file dan `CHANGELOG.md`, membuat backup, mengubah Git index, lalu membuat commit. Mulai dengan `custy --dry-run commit`.</InfoBox>
