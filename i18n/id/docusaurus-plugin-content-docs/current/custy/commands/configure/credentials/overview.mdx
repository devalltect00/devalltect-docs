## Ringkasan

Linux container tidak otomatis mewarisi Windows Git Credential Manager atau
host login session lain. Custy dapat menyediakan personal access token GitHub
atau GitLab setelah normal Git helpers memperoleh kesempatan pertama untuk
melakukan authentication.

<InfoBox variant="success" title="Local credentials tetap lokal">

Dengan rekomendasi `container_only = true`, Custy yang berjalan lokal hanya
memakai normal Git authentication. External fallback dapat aktif di Docker.

</InfoBox>
