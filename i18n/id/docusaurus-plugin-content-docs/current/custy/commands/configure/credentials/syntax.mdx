## Guided setup

<Terminal>{`custy configure credentials`}</Terminal>

Wizard meminta provider, source, non-secret username, dan source metadata. File
mode meminta PAT melalui hidden input dan confirmation.

<InfoBox variant="danger" title="Tidak ada --token option">

Custy sengaja menerima file-backed token hanya melalui hidden prompt. Jangan
taruh PAT pada shell argument, repository URL, message file, atau TOML.

</InfoBox>

<Section title="Global Dry-Run"><Terminal>{`custy --dry-run configure credentials status
custy --dry-run configure credentials test --remote origin`}</Terminal>

Dry-run tidak membuka token file, membaca token environment value, menghubungi
remote, menulis TOML, atau membuat/menghapus external credential file.

</Section>
