## Ringkasan

`custy configure` berisi operasi setup yang membutuhkan interaksi lebih aman
daripada mengedit TOML secara manual. Command family saat ini mengatur fallback
token HTTPS GitHub dan GitLab opsional untuk push dari container.

<InfoBox variant="warning" title="Configuration menyimpan policy, bukan secret">

Project file dapat menyimpan provider name, username, external filename, dan
environment-variable name. Nilai token tetap berada di luar proyek.

</InfoBox>
