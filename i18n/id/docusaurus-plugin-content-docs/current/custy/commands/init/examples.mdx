## Ringkasan

Contoh berikut menunjukkan cara umum menjalankan init pada proyek.

Sebagian besar pengguna hanya memerlukan init default, sedangkan workflow
lanjutan dapat menggunakan init modes dan overwrite options untuk menyesuaikan
resource yang dibuat.

<InfoBox
    variant="tip"
    title="Mulai Menggunakan Custy"
>

Jika ini pertama kalinya Anda menggunakan Custy, mulailah dengan init default.

</InfoBox>

<InfoBox
    variant="tip"
    title="Refresh Example Catalog dengan Aman"
>

Jalankan `custy init --mode examples` setelah upgrade Custy untuk menambahkan
packaged examples baru tanpa mengganti examples yang sudah Anda sesuaikan.
Tambahkan `--force` hanya jika packaged content memang harus mengganti existing
example files.

</InfoBox>

<Section
    title="Setup Pertama yang Umum"
>

Untuk proyek baru, workflow yang direkomendasikan adalah:

1. Jalankan `custy init`.
2. Tinjau configuration yang dibuat.
3. Sesuaikan templates jika diperlukan.
4. Commit generated resources ke version control.

Dengan cara ini, setiap kontributor dapat menggunakan project configuration
yang sama sejak awal.

</Section>
