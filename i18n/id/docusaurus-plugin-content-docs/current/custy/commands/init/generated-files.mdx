## Ringkasan

Menjalankan `custy init` membuat workspace khusus proyek di dalam repositori.

Resource ini menjadi bagian dari proyek dan dapat disesuaikan dengan workflow
tim Anda.

<InfoBox
    variant="tip"
    title="Version Control"
>

File yang dibuat ditujukan untuk disimpan dalam repositori agar setiap
kontributor menggunakan configuration dan templates Custy yang sama.

</InfoBox>

<Section
    title="Struktur Proyek"
>

Setelah init berhasil, proyek memiliki struktur yang mirip dengan berikut.

<Terminal>

{`
.config/
└── custy/
    ├── config.toml
    └── templates/
        ├── backups/
        │   ├── commit/
        │   └── tag/
        ├── changelog/
        │   └── changelog.j2
        ├── examples/
        │   ├── commit_message/
        │   │   ├── since_custy_v1/
        │   │   └── since_custy_v2/
        │   └── tag_message/
        │       ├── since_custy_v1/
        │       └── since_custy_v2/
        ├── commit-message.txt
        └── tag-message.txt
`}

</Terminal>

<InfoBox
    variant="info"
    title="Project-aware Version Initialization"
>

`custy init` tidak lagi mengasumsikan setiap project memiliki `app/`. Python
project tanpa version metadata dapat menerima `__version__.py` di detected
source directory. Metadata Python atau Node.js yang sudah ada dipertahankan,
dan project Node.js atau generic tidak menerima file version Python buatan.

</InfoBox>

<InfoBox
    variant="note"
    title="Recursive Example Merge"
>

Ketika mode `all` atau `examples` dijalankan kembali, Custy menggabungkan
seluruh packaged example tree ke direktori ini. Direktori dan file bertingkat
yang belum ada akan ditambahkan. File yang sudah ada dipertahankan kecuali
`--force` diaktifkan; direktori examples itu sendiri tidak diganti.

</InfoBox>

</Section>

<Section
    title="Customization"
>

Semua resource yang dibuat merupakan bagian dari proyek, bukan aplikasi Custy.

Artinya, Anda dapat:

- Mengubah isi template.
- Menyesuaikan nilai configuration.
- Melakukan commit terhadap file yang dibuat.
- Membagikannya kepada development team.

Command Custy berikutnya otomatis menggunakan resource yang telah disesuaikan
tersebut ketika tersedia.

</Section>

---

<InfoBox
    variant="note"
    title="Init Modes"
>

Resource yang dibuat bergantung pada init mode yang dipilih.

Sebagai contoh, mode `examples` hanya membuat example resources, sedangkan
`config` hanya membuat project configuration.

</InfoBox>
