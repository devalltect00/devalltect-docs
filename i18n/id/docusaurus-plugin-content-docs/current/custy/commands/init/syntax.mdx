## Ringkasan

Command `custy init` merupakan public interface untuk project initialization.

<InfoBox
    variant="tip"
    title="Rekomendasi"
>

Jalankan init pada proyek dengan:

`custy init`

Profile init internal tidak diekspos oleh argumen public `custy run` saat ini.

</InfoBox>

---

<Section
    title="Docker"
>

Setelah mem-build `custy-prod:latest` dari target production Docker milik
Custy, jalankan command terhadap proyek yang di-mount.

<Terminal>

{`
docker run -it --rm \
    -v "<project>:/workspace" \
    -w /workspace \
    custy-prod:latest \
    init
`}

</Terminal>

Lihat [panduan setup Docker](../../getting-started/docker) untuk command build,
requirements host, perilaku workspace mount, dan pertimbangan kredensial Git.

</Section>

---

<InfoBox
    variant="note"
    title="Public Command"
>

Gunakan `custy init`. `custy run init` tidak diterima oleh argumen public Run
profile saat ini.

</InfoBox>
