## Ringkasan

Menjalankan `custy init` menyiapkan proyek dengan membuat resource yang
digunakan Custy pada operasi berikutnya.

Command ini tidak langsung menjalankan Git workflow. Sebagai gantinya, Custy
membuat workspace proyek yang dapat disesuaikan dan digunakan kembali oleh
command berikutnya.

<InfoBox
    variant="tip"
    title="Operasi Aman"
>

Init workflow tidak membuat commit, tag, release, atau mengubah riwayat Git.

Tanggung jawabnya hanya menyiapkan proyek untuk operasi Custy selanjutnya.

</InfoBox>

<InfoBox
    variant="note"
    title="Dirancang untuk Digunakan Kembali"
>

Configuration dan templates yang dibuat menjadi bagian dari proyek Anda.

Resource tersebut dapat diedit, disimpan dalam version control, dan dibagikan
kepada developer lain yang mengerjakan repositori yang sama.

Menjalankan init kembali bersifat additive untuk packaged examples secara
default: nested examples baru disalin sementara existing example files tidak
diubah.

</InfoBox>
