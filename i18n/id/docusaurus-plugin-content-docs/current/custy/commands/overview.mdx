## Ringkasan

Custy menyediakan command khusus untuk operasi individual dan command `run`
untuk pipeline profile multi-langkah yang didukung. Pilih command berdasarkan
hasil yang Anda perlukan, lalu tinjau requirements dan efek sampingnya sebelum
eksekusi.

<InfoBox
    variant="warning"
    title="Hanya public commands"
>

Dokumentasi ini menjelaskan command yang diterima oleh public CLI saat ini.
Nama profile internal merupakan detail implementasi dan tidak didokumentasikan
sebagai argumen `custy run` yang valid.

</InfoBox>

<Section
    title="Direct Commands dan Pipeline Profiles"
>

Direct command menjalankan satu tanggung jawab khusus. Sebagai contoh,
`custy changelog generate` membuat changelog dan `custy push` menyinkronkan
Git reference yang dipilih.

Command `custy run` mengoordinasikan public profiles yang terdaftar. Nama
profile yang diterima saat ini adalah:

- `commit`
- `tag`
- `push`
- `dev`
- `release`
- `full`

Profile dapat menggabungkan validasi, pengeditan file, perubahan versi,
pembuatan changelog, backup, cleanup, staging, commit, tag, push, atau
finalisasi workflow. Setiap halaman profile menampilkan urutan yang
ditentukan beserta efek sampingnya.

</Section>

<Section
    title="Global Options"
>

Global options seperti dry run, debug output, dan pemilihan log level berada
pada root command `custy`. Efek tepatnya dapat berbeda untuk setiap operasi,
sehingga setiap halaman command menjelaskan apakah suatu tindakan hanya
dipratinjau, dilewati, atau tetap memerlukan perhatian.

</Section>
