## Ringkasan

<InfoBox variant="warning" title="Read Every Resolved Destination">
  Dry-run output lebih penting daripada asumsi berdasarkan nama CLI option.
</InfoBox>

<CommandExample
  examples={[
    {
      title: "Preview Default Push",
      command: "custy --dry-run push",
      description: "Resolve destinations tanpa network mutation.",
      result: "Menampilkan planned actions.",
    },
    {
      title: "Default Push",
      command: "custy push",
      description: "Push current HEAD.",
      result: "Menggunakan resolved main destination.",
    },
    {
      title: "Specific Remote",
      command: "custy push --remote upstream",
      description: "Override semua configured groups.",
      result: "Push hanya ke upstream.",
    },
    {
      title: "All Configured Remotes",
      command: "custy push --all-remote",
      description: "Pilih main dan eligible backup groups.",
      result: "Menggunakan de-duplicated destination set.",
    },
    {
      title: "Preview with Tag",
      command: "custy --dry-run push --tag v1.4.0",
      description: "Preview HEAD dan tag push.",
      result: "Menampilkan destination dan tag actions.",
    },
    {
      title: "Push with Tag",
      command: "custy push --tag v1.4.0",
      description: "Push HEAD dan tag.",
      result: "Mengirim ke main destination.",
    },
    {
      title: "Backup Synchronization",
      command: "custy push --sync-backup --tag v1.4.0",
      description: "Minta main dan backup synchronization.",
      result: "Backup berjalan bila destination valid.",
    },
  ]}
/>

<InfoBox variant="info" title="Skip Tag Deliberately">
  Gunakan `custy push --skip-tag` untuk push HEAD tanpa push tag. Pada Release dan Full
  profiles, option yang sama juga mencegah pembuatan tag.
</InfoBox>
