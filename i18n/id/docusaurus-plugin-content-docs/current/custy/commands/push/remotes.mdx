<Section title="Branch Safety">
  Pastikan current branch memang boleh dipush dan upstream/destination sesuai. Custy
  tidak menggantikan branch-protection rules.
</Section>
<InfoBox variant="info" title="Selection Priority">
  `--remote` memiliki prioritas tertinggi, dilanjutkan `all_remote = true`, lalu
  `tool.custy.git.push_to`. `sync_backup = true` menambahkan configured backups ke
  main-group push jika branch diizinkan.
</InfoBox>

<Section title="Inspect Repository Remotes">
  ```bash git remote -v git branch -vv ```
</Section>
