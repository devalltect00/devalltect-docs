## Ringkasan

<InfoBox variant="danger" title="Do Not Force-Push by Default">Cari penyebab rejection terlebih dahulu. Force push dapat menimpa remote history.</InfoBox>

## Main Remote yang Valid Tidak Ditemukan
<Section compact>Periksa `git remote -v`, project configuration, remote URL, dan interactive resolution.</Section>

## Authentication Gagal
<Section compact>Uji Git secara langsung, lalu periksa SSH key, token, credential helper, account, dan permission.</Section>

## Push Ditolak
<Section compact>Remote mungkin memiliki commit baru atau branch protection. Fetch, tinjau divergence, dan integrasikan perubahan secara aman.</Section>

## Backup Synchronization Dilewati
<Section compact>Pastikan `--sync-backup` aktif dan eligible backup remote dapat di-resolve.</Section>

## Tag Tidak Ikut Dipush
<Section compact>Periksa exact tag, `--skip-tag`, local tag existence, dan resolved destination.</Section>

## --remote Tidak Memilih Destination
<Section compact>Ini sesuai current adapter limitation. Gunakan dry-run output untuk melihat actual destination dan konfigurasi role yang didukung engine.</Section>
