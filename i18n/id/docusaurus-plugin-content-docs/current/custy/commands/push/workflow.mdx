## Ringkasan

Profile memvalidasi repository sebelum me-resolve dan memproses setiap
destination yang eligible. `custy push` dan `custy run push` yang dijalankan
secara mandiri tidak menginisialisasi release workflow, menghitung versi baru,
atau meminta konfirmasi release.

<InfoBox variant="warning" title="Fail-Fast Behavior">
  Required main-remote failure menghentikan profile. Periksa destination mana yang sudah
  menerima perubahan sebelum retry.
</InfoBox>
<InfoBox variant="info" title="Non-Interactive Safety">
  Recommended credential policy mencegah Git menunggu input tanpa batas ketika terminal
  tidak tersedia. Sediakan configured file atau environment source sebelum
  non-interactive container push.
</InfoBox>
<Section title="Retry Safety">
  Jangan rerun secara buta setelah partial success. Verifikasi branch dan tag pada
  setiap remote secara terpisah.
</Section>
