## Ringkasan

<CommandExample
  examples={[
    {
      title: "Commit and Push",
      command: "custy run commit push",
      result: "Menggabungkan stages dalam normalized order.",
    },
    {
      title: "Release-like Composition",
      command: "custy run commit tag push",

    },

    },

<Section title="Normalization Behavior">
  Resolver deduplicates dan mengurutkan stages berdasarkan global step order, bukan
  selalu urutan token input.
</Section>
<InfoBox variant="warning" title="Composition Can Be Broader Than Expected">
  Profile names berkembang menjadi banyak stages. Tinjau resolved pipeline dengan dry
  run.
</InfoBox>
<InfoBox variant="note" title="Only Public Names Are Accepted">
  Gunakan hanya `commit`, `tag`, `push`, `dev`, `release`, dan `full`.
</InfoBox>
