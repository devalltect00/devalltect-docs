## Ringkasan

<InfoBox variant="tip" title="Choose the Smallest Profile">
  Profile kecil lebih mudah ditinjau, retry, dan pulihkan.
</InfoBox>
<Section title="Profile Mana yang Harus Digunakan?">
  Focused operation: commit/tag/push; daily work: dev; publication: release;
  experimental finalization: full.
</Section>
<Section title="Dapatkah Hanya Menjalankan Changelog Generation?">
  Gunakan direct `custy changelog generate`; internal changelog name bukan public Run
  profile.
</Section>
<Section title="Dapatkah Profile Digabungkan?">
  Ya, gunakan beberapa public names dan tinjau normalized pipeline.
</Section>
<Section title="Apakah commit tag push Identik dengan release?">
  Tidak selalu; Release adalah registered intentional flow dan dapat memiliki
  preparation/validation yang lebih luas.
</Section>
<Section title="Apakah Run Selalu Melakukan Push?">
  Tidak. Hanya profile yang mencakup Push stage.
</Section>
<Section title="Apakah full Lebih Aman Karena Validation Lebih Banyak?">
  Tidak. Full memiliki scope terluas dan experimental finalization setelah push.
</Section>
