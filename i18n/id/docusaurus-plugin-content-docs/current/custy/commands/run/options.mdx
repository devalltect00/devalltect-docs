<Section title="Global Execution Options">
  Global options ditempatkan sebelum `run`, misalnya `custy --dry-run run release`.
</Section>
<InfoBox variant="warning" title="Current Adapter Limitations">
  Push selection inputs sudah dipropagasikan. Non-push inputs `bump` dan `skip_check`
  masih belum dipropagasikan secara andal. `check_cz` sudah dipropagasikan sebagai
  strict Commitizen override. Gunakan profile-specific guide dan dry-run output.
</InfoBox>
<InfoBox variant="note" title="Commit Validation Provider">
  Untuk reusable behavior pada Run profiles, konfigurasikan
  [`tool.custy.commit.validation`](../../configuration/commit-validation).
</InfoBox>
