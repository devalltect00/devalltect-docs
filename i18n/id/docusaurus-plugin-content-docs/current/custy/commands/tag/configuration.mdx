## Ringkasan

<PropertyTable title="Tag Profile Configuration" items={[
 {property:"[tool.custy.cli.templates.file]",type:"tag_message",description:"Pilih tag-message template."},
 {property:"[tool.custy.cli.templates.directory]",type:"backups_tag",description:"Pilih retained tag-message backup directory."},
 {property:"[tool.custy.cli.paths]",type:"version_file",description:"Pilih file yang menerima resolved version."},
 {property:"[tool.custy.cli.versioning]",type:"strategy and modifiers",description:"Atur strategy, bump, dan release modifiers."},
 {property:"[tool.custy.cli.execution]",type:"validation",description:"Atur pre-tag checks dan force behavior."},
]} />

<Section title="Example Configuration">
```toml
[tool.custy.cli.templates.file]
tag_message = ".config/custy/templates/tag-message.txt"

[tool.custy.cli.templates.directory]
backups_tag = ".config/custy/templates/backups/tag"

[tool.custy.cli.paths]
version_file = "auto"
```
</Section>

<InfoBox variant="tip" title="Use Shared Release Inputs">Simpan team defaults dalam `.config/custy/config.toml`; gunakan CLI overrides untuk release khusus.</InfoBox>
