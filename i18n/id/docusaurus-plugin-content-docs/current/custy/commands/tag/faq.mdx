## Ringkasan

<InfoBox variant="info" title="Local Before Remote">
  Verifikasi tag secara lokal sebelum menggunakan Push.
</InfoBox>

<Section title="Apakah custy tag Melakukan Push?">
  Tidak. Command membuat local tag.
</Section>
<Section title="Apa Perbedaan custy run tag?">
  Keduanya memakai registered Tag profile; direct command menyediakan tag-specific
  overrides.
</Section>
<Section title="Haruskah Menggunakan --tag atau --bump?">
  Gunakan `--tag` untuk exact version; gunakan bump dan strategy untuk membentuk versi
  berikutnya.
</Section>
<Section title="Apakah Profile Memperbarui Version File?">
  Ya, resolved version ditulis ke configured version file sebagai bagian workflow.
</Section>
<Section title="Dapatkah Saya Membuat Pre-release?">
  Ya, gunakan strategy dan modifier yang kompatibel seperti `--pre`.
</Section>
<Section title="Kapan --force-tag Digunakan?">
  Hanya setelah conflict dipahami dan replacement aman. Hindari mengganti published tag
  tanpa koordinasi.
</Section>
