## Ringkasan

`custy tag` adalah release profile yang memvalidasi repository, menentukan versi, memperbarui artifacts, lalu membuat tag lokal.

<InfoBox variant="danger" title="Creates Git History">Tag menjadi Git reference permanen dan dapat memicu CI/CD setelah dipush. Verifikasi commit target dan exact version terlebih dahulu.</InfoBox>
