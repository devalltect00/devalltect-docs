## Ringkasan

<InfoBox variant="danger" title="Never Replace a Published Tag Casually">Periksa apakah tag sudah dipush atau dipakai release sebelum menghapus atau menggantinya.</InfoBox>

## Tag Sudah Ada
<Section compact>Periksa local dan remote tag. Gunakan versi baru kecuali replacement benar-benar diperlukan dan terkoordinasi.</Section>

## Custy Tidak Dapat Menentukan Versi Berikutnya
<Section compact>Periksa strategy, bump, current version, Git history, dan explicit `--tag`.</Section>

## Version File Tidak Ditemukan
<Section compact>Periksa configured path atau `--version-file`, lalu pastikan file ada dan writable.</Section>

## Pre-Tag Validation Gagal
<Section compact>Perbaiki repository state atau artifact yang dilaporkan sebelum retry.</Section>

## Local Tag yang Salah Dibuat
<Section compact>Jangan push. Verifikasi commit dan publication state, hapus local tag melalui Git hanya bila aman, lalu buat ulang versi yang benar.</Section>
