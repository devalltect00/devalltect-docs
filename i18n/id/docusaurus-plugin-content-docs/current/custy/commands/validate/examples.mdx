<InfoBox variant="tip" title="Kapan Validation Perlu Dijalankan Manual?">

Menjalankan **custy validate** paling berguna ketika Anda ingin memeriksa
kesiapan proyek sebelum workflow yang lebih besar. Jika Anda terutama
menggunakan **custy run**, validation sudah disertakan sebagai workflow stage
pertama.

</InfoBox>

---

<Section title="Situasi Umum">

Manual validation sangat membantu ketika:

- Menyiapkan proyek untuk pertama kali.
- Meninjau perubahan sebelum membuat commit.
- Memastikan configuration files yang diperlukan tersedia.
- Memeriksa template files setelah menjalankan `custy init`.
- Mendiagnosis workflow failure sebelum mencoba release kembali.

</Section>
