## Ringkasan

Command validate mendukung beberapa command-line options yang memengaruhi cara
validation dijalankan.

Beberapa options mengubah perilaku validation, sementara yang lain menentukan
cara Custy berinteraksi dengan proyek selama proses tersebut.

<InfoBox variant="tip" title="Configuration First">

Sebagian besar perilaku validation diatur melalui
`.config/custy/config.toml`. Command-line options meng-override nilai
configuration tersebut hanya untuk eksekusi saat ini.

</InfoBox>

<Section title="Prioritas Option">

Custy menentukan perilaku validation menggunakan urutan prioritas berikut:

1. Command-line options.
2. Project configuration (`config.toml`).
3. Default bawaan Custy.

Proyek dapat menetapkan default yang sesuai, sementara eksekusi individual
tetap dapat meng-override pengaturan tertentu.

</Section>

---

<InfoBox variant="note" title="Workflow Commands">

Saat validation dijalankan sebagai bagian dari workflow, beberapa options
mungkin sudah diberikan oleh workflow configuration. Dalam kondisi tersebut,
manual command-line options meng-override configured defaults hanya untuk
eksekusi saat ini.

</InfoBox>
