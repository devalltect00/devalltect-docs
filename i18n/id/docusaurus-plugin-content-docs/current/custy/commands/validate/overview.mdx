## Ringkasan

Command **validate** menjalankan serangkaian pre-flight checks untuk memastikan
proyek siap digunakan oleh operasi Custy berikutnya.

Command ini tidak mengubah repository. Custy memeriksa proyek, configuration,
Git repository, serta resource yang diperlukan untuk menemukan masalah sebelum
masalah tersebut menghentikan workflow yang lebih besar.

<InfoBox variant="tip" title="Validation Otomatis">

Walaupun dapat dijalankan secara manual, command yang berorientasi pada
workflow seperti `custy run` umumnya melakukan validation secara otomatis
sebelum melanjutkan ke workflow steps berikutnya.

</InfoBox>

<Section title="Mengapa Validation Penting?">

Menjalankan validation sebelum workflow membantu menemukan masalah umum lebih
awal, misalnya:

- Current directory bukan Git repository.
- Git remote yang diperlukan belum dikonfigurasi.
- Version file yang dikonfigurasi tidak ditemukan.
- Template yang diperlukan tidak tersedia.
- Tidak ada staged changes sebelum commit workflow.
- Commit message tidak memenuhi validation strategy yang dipilih.

Dengan menemukan masalah tersebut lebih dahulu, Custy mencegah workflow yang
tidak lengkap atau gagal.

</Section>

---

<InfoBox variant="note" title="Berbasis Configuration">

Sebagian besar target validation ditentukan dari `config.toml` proyek.
Contohnya, lokasi version file, lokasi template, dan nama Git remote ditentukan
dari project configuration, bukan fixed path, selama memungkinkan.

</InfoBox>

---

<Section title="Kapan Validation Perlu Dijalankan?">

Validation berguna untuk memastikan proyek siap sebelum operasi Git atau
release, terutama:

- Sebelum membuat commit.
- Sebelum membuat versi.
- Sebelum membuat Git tag.
- Sebelum melakukan push.
- Sebelum menjalankan release workflow.

Jika Anda biasanya menggunakan `custy run`, checks ini dijalankan otomatis
sebagai bagian dari workflow.

</Section>
