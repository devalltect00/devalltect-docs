## Ringkasan

Public validation interface adalah standalone command `custy validate`.

<InfoBox variant="tip" title="Public Command">

Gunakan `custy validate` untuk menjalankan validation saja. Public profile
seperti `custy run commit`, `custy run release`, dan `custy run full` secara
otomatis menyertakan validation stages yang diperlukan.

</InfoBox>

<Section title="Cara Validation Dijalankan">

Standalone command menjalankan public validation profile secara lengkap tanpa
melanjutkan ke operasi commit, tag, atau push.

Setelah validation berhasil, workflow commands berikutnya dapat melanjutkan ke
operasi commit, tagging, pushing, atau release.

</Section>

---

<Section title="Command Forms">

Command validate memiliki satu bentuk publik.

| Command          | Tujuan                               |
| ---------------- | ------------------------------------ |
| `custy validate` | Jalankan validation secara langsung. |

Internal validation profiles digunakan kembali oleh command lain, tetapi
namanya tidak diterima sebagai public Run arguments.

</Section>

---

<InfoBox variant="note" title="Validation Otomatis">

Sebagian besar command yang berorientasi pada workflow otomatis melakukan
validation sebelum menjalankan workflow stages selanjutnya.

Menjalankan `custy validate` secara manual berguna ketika Anda ingin memeriksa
kesiapan proyek sebelum memulai workflow yang lebih besar.

</InfoBox>
