## Ringkasan

Nilai dalam `config.toml` digunakan ketika option yang sesuai tidak diberikan melalui CLI.

<PropertyTable title="config.toml Properties" items={[
    {property: "strategy", type: "semver | pep440 | commitizen | date | gitcount", defaultValue: "semver", required: false, description: "Strategy default untuk membentuk versi berikutnya."},
    {property: "bump", type: "auto | patch | minor | major", defaultValue: "auto", required: false, description: "Bump level default."},
]} />

<Section title="Version File">

```toml
version_file = "auto"
```

Custy mendeteksi Python version module, static version dalam `pyproject.toml`,
atau version dalam `package.json` yang sudah ada. Project tanpa metadata yang
didukung tetap valid dan menggunakan tag-only versioning. Path eksplisit harus
tersedia.

</Section>

<Section title="Default Versioning Strategy">

```toml
[tool.custy.cli.versioning]
strategy = "semver"
bump = "auto"
```

</Section>

<InfoBox variant="tip" title="Configuration Resolution">Urutan prioritas: command-line arguments, project configuration, automatic project detection jika berlaku, lalu built-in defaults.</InfoBox>
