## Ringkasan

<CommandOption options={[
    {name: "--strategy", required: false, defaultValue: "config.toml", description: "Pilih versioning strategy.", example: "--strategy semver"},
    {name: "--bump", required: false, defaultValue: "auto", description: "Pilih bump level: auto, patch, minor, atau major.", example: "--bump minor"},
    {name: "--tag", required: false, description: "Gunakan explicit version.", example: "--tag v2.4.0"},
    {name: "--pre-release", required: false, description: "Buat pre-release seperti alpha, beta, atau rc.", example: "--pre-release beta"},
    {name: "--post-release", required: false, defaultValue: "false", description: "Buat post-release jika didukung strategy."},
    {name: "--dev-release", required: false, defaultValue: "false", description: "Buat development release jika didukung strategy."},
    {name: "--meta", required: false, description: "Tambahkan build metadata atau local version information.", example: "--meta build.42"},
    {name: "--epoch", required: false, description: "Tentukan komponen epoch PEP 440.", example: "--epoch 1"},
]} />

<Section title="Global Options">Contoh: `custy --dry-run version update`. Global option selalu ditempatkan sebelum `version update`.</Section>

<InfoBox variant="tip" title="Configuration First">Simpan default proyek dalam `config.toml`; gunakan CLI options untuk override satu kali.</InfoBox>
