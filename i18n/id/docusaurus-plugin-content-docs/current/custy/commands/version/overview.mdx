## Ringkasan

Command Version memisahkan dua tanggung jawab: menentukan versi berikutnya dan menerapkan versi tersebut secara konsisten ke file proyek.

  items={[

<InfoBox variant="tip" title="Satu Versi, Beberapa File">
  Custy menjaga version source dan metadata proyek tetap selaras sehingga release tidak
  menggunakan nomor versi yang berbeda.
</InfoBox>

<Section title="Command Utama">
  Gunakan `custy version update` untuk membentuk atau menerima versi target, lalu
  menyinkronkannya ke proyek.
</Section>
