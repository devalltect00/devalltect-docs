<Section title="Automatic Version Metadata Detection">

Dengan `version_file = "auto"`, Custy mencari Python `__version__.py` yang
sudah ada, static `[project].version` dalam `pyproject.toml`, lalu string
`version` dalam `package.json`. Mixed project dapat menyinkronkan metadata
Python dan Node.js. Nilai yang ditulis ke metadata tidak menyertakan tag prefix
seperti `v`.

Path `tool.custy.cli.paths.version_file` yang eksplisit tetap strict: path
tersebut harus tersedia dan berupa file.

</Section>

<InfoBox variant="note" title="Generic project tetap didukung">Project tanpa metadata yang didukung tidak menerima file Python buatan. Custy tetap dapat dijalankan dan menggunakan Git tag sebagai version source.</InfoBox>

<Section title="Persiapan yang Disarankan">Jalankan `custy --dry-run version update` sebelum menerapkan perubahan versi nyata.</Section>
