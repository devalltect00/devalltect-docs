<Section title="Global Options">

Global options ditempatkan sebelum command:

```bash
custy --dry-run version update
custy --debug version update
custy --log-level DEBUG version update
```

</Section>

<InfoBox variant="tip" title="Mulai dari Dry Run">
  Gunakan dry run untuk melihat file yang akan diperbarui sebelum Custy menulis
  perubahan.
</InfoBox>
