## Ringkasan

## Version File Tidak Ditemukan

<Section compact>
  Periksa `version_file` dalam configuration dan pastikan path dihitung dari project
  root yang benar.
</Section>

## Versioning Strategy Tidak Valid

<Section compact>
  Gunakan strategy yang didukung: `semver`, `pep440`, `commitizen`, `date`, atau
  `gitcount`.
</Section>

## Format Versi Tidak Sesuai Perkiraan

<Section compact>
  Periksa strategy, project ecosystem, pre/post/dev release option, metadata, dan epoch.
  Custy dapat menormalisasi representasi untuk file tertentu.
</Section>

## File Proyek Tidak Diperbarui

<Section compact>
  Pastikan file ditemukan, dapat ditulis, dan command tidak menggunakan `--dry-run`.
  Periksa output debug untuk configuration resolution.
</Section>

<InfoBox variant="warning" title="Jangan Memperbaiki File Secara Terpisah">
  Jika sinkronisasi hanya sebagian, cari penyebabnya sebelum mengubah version file
  manual agar metadata tidak berbeda.
</InfoBox>

## Langkah Diagnostik Berikutnya

<Section compact>
  Jalankan `custy --debug version update`, periksa effective configuration, project
  detection, target version, dan setiap file yang dilaporkan.
</Section>
