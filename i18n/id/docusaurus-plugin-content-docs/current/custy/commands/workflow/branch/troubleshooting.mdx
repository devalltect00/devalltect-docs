## Ringkasan
<InfoBox variant="danger" title="Do Not Work Around the Source Mismatch in Configuration">Perbaikan harus dilakukan pada source registration/resolution dan diverifikasi dengan tests.</InfoBox>

## Unknown finalize Step Dilaporkan
<Section compact>Ini known implementation blocker. Hentikan operational use sampai source diperbaiki.</Section>
## --check-transition Ditolak
<Section compact>Gunakan current spelling `--check_transition` dengan underscore.</Section>
## Tag Override Ditolak
<Section compact>Periksa exact `--from-tag`/`--to-tag` syntax, tetapi ingat pipeline tetap blocked.</Section>
## Enforcement Behavior Tidak Jelas
<Section compact>Jangan mengandalkan `--enforce` sampai implementation fix dan behavior tests tersedia.</Section>
## Backup Synchronization Dilewati
<Section compact>Jangan mendiagnosis backup stage sebelum pipeline construction berhasil; execution mungkin belum mencapainya.</Section>
