## Ringkasan

<InfoBox variant="tip" title="Use Configuration for Repeatability">
  Simpan team defaults dalam `.config/custy/config.toml`; gunakan CLI overrides untuk
  satu invocation.
</InfoBox>

<Section title="How Resolution Works">
  Secara umum: `CLI → config.toml → default`. Akan tetapi, tidak setiap option
  menggunakan semua sumber; beberapa command juga melakukan project detection atau
  validation.
</Section>

<Section title="Configuration File Shape">
```toml
[tool.custy.cli.execution]
dry_run = false

[tool.custy.cli.versioning]
strategy = "semver"

```
</Section>

<InfoBox variant="warning" title="Missing and Invalid Configuration">Missing optional value dapat memakai fallback; invalid value biasanya menghentikan execution agar behavior tidak ambigu.</InfoBox>
