## Ringkasan

<InfoBox variant="tip" title="Place the Option Before the Command">
  `--dry-run` adalah global option dan harus ditempatkan sebelum command group.
</InfoBox>

<Section title="Cara Menentukan Mode yang Efektif">

Custy menentukan dry-run berdasarkan urutan berikut: explicit CLI option,
setting `tool.custy.cli.execution.dry_run`, lalu built-in default `false`.
Karena itu, tidak menyertakan `--dry-run` belum tentu mengaktifkan normal
execution jika configuration menetapkan `dry_run = true`.

<Terminal title="Pilih preview atau normal execution secara eksplisit" language="bash">

{`# Paksa preview mode, apa pun default pada configuration
custy --dry-run changelog generate

# Paksa normal execution walaupun configuration mengaktifkan dry_run

custy --no-dry-run changelog generate`}

</Terminal>

</Section>

<Section title="A Safe Preview Sequence">
  1. Periksa repository state. 2. Jalankan dry run. 3. Baca resolved values, stages,
  files, tags, dan destinations. 4. Perbaiki configuration atau input. 5. Jalankan ulang
  dry run sebelum normal execution.
</Section>

<InfoBox variant="warning" title="Dry Run Is a Simulation, Not a Guarantee">
  Dry run tidak membuktikan future authentication, concurrency, editor interaction,
  remote acceptance, atau state yang berubah setelah preview.
</InfoBox>

<InfoBox variant="info" title="Diagnostic Logging Tetap Aktif">

Dry-run melindungi intended project, Git, dan remote mutations dari command.
Normal logging Custy masih dapat membuat atau menambahkan diagnostic log file.

</InfoBox>
