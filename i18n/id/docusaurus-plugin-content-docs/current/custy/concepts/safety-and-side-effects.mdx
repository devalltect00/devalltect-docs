## Ringkasan

<InfoBox variant="warning" title="Profiles Inherit Every Included Effect">Profile besar mewarisi file, Git, interactive, dan network effects dari seluruh stages.</InfoBox>

<InfoBox variant="info" title="Dry-Run Memisahkan Discovery dari Mutation">

Dalam dry-run, Custy masih dapat membaca configuration dan project files,
memeriksa history, branches, tags, serta remotes, menjalankan validation, dan
merender preview. Intended file changes, editor launches, Git mutations, dan
remote mutations disimulasikan. Diagnostic logging masih dapat menulis ke log
destination Custy.

</InfoBox>

<Section title="Before Normal Execution">
```bash
git status
git log -1 --oneline
git remote -v
custy --dry-run COMMAND
```
</Section>

<Section title="After Execution or Failure">Periksa diff, Git index/history, local tags, backup artifacts, dan setiap remote. Jangan menganggap pipeline atomic.</Section>

<InfoBox variant="danger" title="Remote Effects Deserve Separate Review">Verifikasi setiap destination secara independen; partial remote success dapat terjadi.</InfoBox>
