<Terminal
  title="Default aman yang dibuat"
  language="toml"
>{`[tool.custy.changelog.links]
repository = ""
enable_compare = false`}</Terminal>

Untuk mengaktifkan links, ganti nilai kosong dengan URL repository proyek yang sebenarnya:

<Terminal
  title="Aktifkan comparison links"
  language="toml"
>{`[tool.custy.changelog.links]
repository = "https://github.com/your-org/your-project"
enable_compare = true`}</Terminal>

<InfoBox variant="warning" title="Placeholder dan URL yang tidak valid tidak digunakan">

Jika comparison diaktifkan saat `repository` kosong, masih menggunakan contoh
seperti `org/project`, atau bukan URL browser HTTP(S) yang valid, Custy
menampilkan peringatan dan tetap membuat changelog tanpa comparison links.
Command changelog tidak gagal karena pengaturan yang dapat dipulihkan ini.

</InfoBox>

<InfoBox variant="note" title="Dua Switch Memengaruhi Visibility">
  `enable_compare` membuat comparison URLs. `render.show_compare_link` menentukan apakah
  Jinja template menampilkan available URLs.
</InfoBox>

## Repository URL vs Git remotes

| Setting                                   | Nilai                                                 | Tujuan                                                        |
| ----------------------------------------- | ----------------------------------------------------- | ------------------------------------------------------------- |
| `changelog.links.repository`              | URL browser, seperti `https://github.com/org/project` | Membuat links di `CHANGELOG.md`                               |
| `git.default_remote`                      | Satu nama remote, seperti `origin`                    | Menjadi fallback untuk operation yang menggunakan satu remote |
| `git.main_remotes` / `git.backup_remotes` | Daftar nama remote                                    | Mengelompokkan tujuan utama dan mirror                        |

Gunakan `git remote -v` untuk melihat nama dan URL remote. Jangan menyalin nama
remote seperti `origin` ke `changelog.links.repository`.
