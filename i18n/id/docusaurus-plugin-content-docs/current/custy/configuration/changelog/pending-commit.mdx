## Properties
<PropertyTable items={[{property: "enabled", type: "Boolean", defaultValue: "true", description: "Active. Sertakan configured commit-message file melalui PendingCommitProvider untuk newest unreleased range."}, {property: "generation", type: "append | regenerate", defaultValue: "regenerate", description: "Loaded only. Active generator tidak memanggil integrator yang menerapkan mode ini."}, {property: "placement", type: "before | after", defaultValue: "before", description: "Loaded only. Active generator saat ini tidak memindahkan pending content."}]} />
<Terminal title="Generated pending behavior" language="toml">{`[tool.custy.changelog.pending_commit]
enabled = true
generation = "regenerate"
placement = "before"`}</Terminal>
<InfoBox variant="tip" title="Message Path Dikonfigurasikan di Tempat Lain">Pending content membaca `tool.custy.cli.templates.file.commit_message`. Selaraskan file path dan pending behavior.</InfoBox>
<InfoBox variant="warning" title="Generation dan Placement Belum Mengubah Output">Active generator dapat menyertakan pending content, tetapi tidak memanggil `PendingCommitIntegrator`. Perlakukan `generation` dan `placement` sebagai loaded-only settings sampai integration path tersebut active.</InfoBox>
