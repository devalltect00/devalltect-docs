<InfoBox variant="danger" title="max_age dan before Tidak Boleh Digunakan Bersamaan">

Custy menolak configuration yang me-resolve kedua filter. Mulai dengan empty
prefixes, tambahkan narrowest useful prefixes, lalu preview eligible branches.

</InfoBox>

<Section title="Protected Branches">

Active cleanup workflow melindungi important branches seperti `main`, `master`,
dan `develop`, meskipun filter lain cocok. Protection merupakan final safety
layer, bukan pengganti careful prefix selection.

</Section>
