<Section title="Dry-Run Resolution">

Custy menentukan `dry_run` dengan urutan CLI → configuration → built-in
default. Karena itu, explicit global option akan mengesampingkan setting ini.

<Terminal title="Override configured default" language="bash">

{`# Aktifkan simulation
custy --dry-run run release

# Nonaktifkan simulation dan gunakan normal execution

custy --no-dry-run run release`}

</Terminal>

Read-only discovery dan validation masih dapat dijalankan dalam preview mode.
Normal diagnostic logging juga tetap aktif dan dapat memperbarui configured
log file.

</Section>

<InfoBox variant="danger" title="Force dan Automatic Staging Memperluas Side Effects">

Biarkan force settings nonaktif dalam shared configuration. Kombinasi
`auto_stage = true` dan `stage_mode = "all"` dapat menyertakan tracked dan
untracked changes.

</InfoBox>

<InfoBox variant="note" title="Gunakan Provider Table untuk Proyek Baru">

Konfigurasikan [`tool.custy.commit.validation`](../commit-validation) untuk auto
discovery dan explicit fallback behavior. Pertahankan `check_cz` hanya ketika
older configuration atau CLI workflow memerlukan strict boolean override.

</InfoBox>

<InfoBox variant="warning" title="Gunakan CLI untuk Skip-Check Behavior">

Sampai `skip_checks` dan `skip_check` diselaraskan dalam source dan generated
template, gunakan explicit command option dan verifikasi displayed plan.

</InfoBox>
