<InfoBox variant="info" title="Project tanpa version metadata tetap valid">

Jika automatic detection tidak menemukan version target yang didukung, Custy
tetap dapat dijalankan, menginisialisasi configuration, dan menggunakan
Git-tag-only versioning. Custy tidak membuat file Python pada project Node.js
atau generic. Gunakan target eksplisit hanya jika project memiliki version
file lain.

</InfoBox>

<InfoBox variant="warning" title="Ini Bukan project_source">

`project.project_source` menentukan main source directory. `version_file`
menentukan satu metadata file di dalam project. Kedua nilai dapat tetap
`auto`, dan setiap override eksplisit divalidasi secara terpisah.

</InfoBox>
