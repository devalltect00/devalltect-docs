## Ringkasan

Custy menyertakan `app/templates/config.toml` di dalam application package.
Saat initialization, Custy menyalin isinya ke `.config/custy/config.toml`.
Pengguna mengedit project copy tersebut dan tidak memerlukan akses ke installed
source file.

<Section title="TOML Root dan Loading">

<Terminal title="Required namespace shape" language="toml">

{`[tool.custy]

[tool.custy.project]
project_source = "auto"

[tool.custy.cli.execution]
dry_run = false`}

</Terminal>

- Central loader menyediakan values di bawah `[tool.custy]`.
- Missing configuration diperlakukan sebagai project yang belum diinisialisasi
  dan memuat empty mapping. Gunakan `custy init` ketika project-owned defaults
  diperlukan.
- Invalid TOML menghasilkan configuration error.
- Relative paths umumnya dievaluasi dari current working directory.
- Custy process baru memuat ulang perubahan pada file.
- Jangan simpan secret values di project configuration. Credential policy dan
  external token filenames boleh dikonfigurasikan di sana, tetapi isi token
  harus berada di external credential directory atau environment variable.

</Section>
