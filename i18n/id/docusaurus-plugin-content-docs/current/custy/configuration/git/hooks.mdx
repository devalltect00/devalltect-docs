<InfoBox variant="info" title="Configuration File Saja Tidak Menginstal Hook">

Dalam mode `auto`, `.pre-commit-config.yaml` tanpa installed
`.git/hooks/pre-commit` wrapper diperlakukan seperti repository tanpa hook.
Gunakan `pre-commit install` saat project memang ingin Git menegakkan checks
tersebut, atau pilih `pre_commit` secara explicit saat Custy harus mewajibkan
direct execution.

</InfoBox>

<InfoBox variant="warning" title="Direct Execution adalah Validation, Bukan Bypass">

Custy menggunakan Git `--no-verify` hanya setelah setiap recognized wrapper
yang akan dilewati flag tersebut berhasil dijalankan melalui `pre-commit`.
Unknown custom hooks, unavailable tooling, missing configuration, dan failed
checks menghentikan workflow. Tidak ada mode `skip`.

</InfoBox>

<Section title="Panduan Local dan Docker">

- Pertahankan `mode = "auto"` untuk kebanyakan project, termasuk project yang
  tidak menggunakan pre-commit.
- Gunakan `native` ketika custom hooks sudah portable pada setiap execution
  environment.
- Gunakan `pre_commit` ketika project policy mewajibkan direct framework
  execution.
- Instal local support dengan `pip install "custy[hooks]"`. Production image
  sudah menyertakan `pre-commit`.
- Direct check yang gagal menghasilkan `PRE_COMMIT_HOOK_FAILED` dan tidak
  membuat Git commit.

</Section>
