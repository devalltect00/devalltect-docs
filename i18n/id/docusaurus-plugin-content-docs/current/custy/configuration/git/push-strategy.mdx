<Terminal title="Service-level strategy" language="toml">

{`[tool.custy.git]
main_remotes = ["origin"]
backup_remotes = ["mirror"]
push_to = "all"

# Tersedia dalam generated file, tetapi saat ini masih reserved.
auto_push = true`}

</Terminal>

<InfoBox variant="warning" title="Explicit Remote Input Selalu Menang">

`--remote` memilih satu destination sebelum group setting diperiksa. Tanpa
option tersebut, `all_remote = true` memilih kedua configured groups;
selain itu `push_to` memilih main, backup, atau all.

</InfoBox>

<InfoBox variant="danger" title="auto_push Bukan Active Guarantee">

Jangan menganggap `auto_push = true` membuat commit atau tag commands
menghubungi remote. Gunakan documented push command atau run profile dan
tinjau plan-nya.

</InfoBox>
