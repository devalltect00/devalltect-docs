<Terminal title="Multi-host setup" language="toml">

{`[tool.custy.git]
default_remote = "origin"
main_remotes = ["origin", "gitlab"]
backup_remotes = ["mirror"]`}

</Terminal>

<InfoBox variant="note" title="Nilai ini adalah nama Git remote">

`origin`, `gitlab`, dan `mirror` adalah alias lokal yang dikonfigurasi oleh Git.
Nilai tersebut berbeda dari `tool.custy.changelog.links.repository`, yang harus
berupa URL browser HTTP(S) lengkap dan hanya digunakan dalam changelog yang
dihasilkan.

</InfoBox>

<InfoBox variant="danger" title="Verifikasi Names dan URLs Sebelum Push">

Jalankan `git remote -v`, konfirmasi authentication dan branch protection,
serta pastikan setiap configured name benar-benar tersedia di repository.

</InfoBox>
