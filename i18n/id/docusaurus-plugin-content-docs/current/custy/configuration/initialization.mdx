<InfoBox variant="danger" title="Hindari Shared Force Defaults">

Menyimpan `force = true` dalam shared project file dapat membuat `custy init`
biasa mengganti customized configuration dan templates. Pilih explicit one-run
`--force` setelah meninjau affected resources.

</InfoBox>

<Section title="Perilaku Direktori Examples">

Mode `all` dan `examples` menelusuri packaged examples secara recursive. Jika
destination sudah ada, Custy menambahkan missing nested directories dan files,
bukan melewati seluruh example tree. Existing files dipertahankan secara
default dan hanya ditimpa ketika effective force behavior diaktifkan.

</Section>

<Section title="Modes dan Scope">

Mode tetap merupakan CLI choice, bukan generated configuration property:
`all`, `all_no_examples`, `config`, `templates`, atau `examples`. Jika tidak
ditentukan, resolver menggunakan `all`.

</Section>
