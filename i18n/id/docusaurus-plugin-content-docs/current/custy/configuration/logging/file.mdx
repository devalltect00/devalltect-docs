<InfoBox variant="warning" title="Pastikan Destination Dapat Ditulis">

Logging membuat `log_dir` selama setup. Automated atau containerized
environments harus mengizinkan write di lokasi tersebut. Abaikan directory
ini dari version control jika logs harus tetap local.

</InfoBox>

<Section title="Contoh Rotation">

Dengan generated values, `custy.log` dirotasi setelah sekitar 10 MB dan
mempertahankan hingga lima numbered historical files selain active log.

</Section>
