## Ringkasan

`custy init` membuat file TOML milik project dari packaged source Custy.
Dokumentasi aktif mengikuti hierarchy file tersebut, sedangkan table yang
bertingkat dalam dikelompokkan menjadi bagian yang mudah dinavigasi.

<InfoBox variant="tip" title="Mulai dari Namespace, Lalu Buka Property">

Gunakan halaman ini untuk memilih namespace. Gunakan halaman namespace untuk
penjelasan dan contoh, atau buka [All Properties](./reference) jika Anda sudah
mengetahui full TOML path.

</InfoBox>

[tool.custy.git]

<Section title="Status yang Digunakan dalam Panduan Ini">

- **Active** — property digunakan oleh resolver atau service saat ini.
- **Optional** — didukung active code, tetapi dikomentari atau tidak disertakan
  dalam generated file.
- **Mismatch** — generated name atau shape tidak selaras dengan active code.
- **Loaded only** — dimuat ke model, tetapi belum digunakan renderer atau pipeline aktif.
- **Experimental** — behavior masih berkembang dan belum boleh dianggap stabil.
- **Reserved** — dibuat atau dideskripsikan, tetapi belum digunakan active command flow.

</Section>
