<InfoBox variant="info" title="Pemilihan source otomatis">

Untuk marker Python, Custy memprioritaskan `app/`, lalu `src/`. Untuk
repository Node.js dan generic, Custy memprioritaskan `src/`, lalu `app/`.
Jika keduanya tidak ada, project root tetap valid. Deteksi dilakukan saat
command dijalankan, sehingga repository Docusaurus, React, PHP, atau lainnya
tidak memerlukan directory `app/` hanya untuk menjalankan Custy.

</InfoBox>

<InfoBox variant="warning" title="Path eksplisit tetap strict">

Nilai eksplisit merupakan override yang disengaja. Custy menampilkan
configuration error jika path tidak ada atau bukan directory. Kembalikan nilai
ke `auto` atau perbaiki path; jangan membuat directory `app/` placeholder.

</InfoBox>
