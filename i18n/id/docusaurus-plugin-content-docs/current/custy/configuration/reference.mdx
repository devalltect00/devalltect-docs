## Status legend

**Active** berarti current code menerapkan property. **Optional** berarti active
tetapi tidak disertakan atau dikomentari dalam generated file. **Mismatch**
berarti generated name atau shape berbeda dari active code. **Loaded only**
berarti resolver menerimanya, tetapi active output path tidak menggunakannya.
**Reserved** berarti generated tanpa active consumer. **Experimental** berarti
belum stabil.

<InfoBox variant="note" title="Default di Halaman Ini adalah Generated Defaults">

Jika supported property dihilangkan, built-in fallback dapat berbeda. Halaman
detail menjelaskan kasus tersebut, termasuk date formatting, backup remotes,
dan changelog breaking defaults.

</InfoBox>
