## Ringkasan

Sebagian besar command resolvers menggunakan prioritas yang sama, tetapi
dukungan diterapkan per property. Munculnya sebuah key dalam generated file
belum membuktikan bahwa semua command menggunakannya.

<InfoBox variant="warning" title="Known Cross-Cutting Mismatch">

Generated execution key adalah `cli.execution.skip_checks`; direct Git-operation
dan `custy run` resolvers saat ini mencari `cli.execution.skip_check`. Gunakan
explicit skip-check option milik command hingga source dan template diselaraskan.

</InfoBox>
