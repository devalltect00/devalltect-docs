## Final Review Checklist

Pastikan public CLI behavior didiskusikan, tests tidak dihapus, configuration
dan documentation sinkron, serta recovery dan side effects dijelaskan.

<InfoBox variant="note" title="Keep Changes Reviewable">Pisahkan refactor yang tidak diperlukan dari behavior change. Focused diff memudahkan reviewers memverifikasi intent dan safety.</InfoBox>
