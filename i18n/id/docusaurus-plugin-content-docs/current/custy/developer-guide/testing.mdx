## Test Layers
Unit tests memeriksa focused resolver dan service behavior; integration tests
memeriksa boundaries; CLI tests memeriksa parsing, output, dan exit behavior.
## Focused Validation
<Terminal language="bash">{`python -m pytest tests/path/to/test_file.py -q
python -m pytest tests/path/to/test_file.py::test_name -q`}</Terminal>
## Pre-Commit Quality Gates
Repository hooks menggunakan Ruff untuk linting dan safe lint fixes, Black sebagai single Python formatter, serta utility hooks untuk trailing whitespace dan final newline. Ruff dan Black membaca policy dari `pyproject.toml`.
<Terminal language="bash">{`# Validate hook configuration
make pre-commit-validate

# Check staged files
make pre-commit-run-staged

# Check semua tracked files
make pre-commit-run`}</Terminal>
<InfoBox variant="note" title="Reference Files Tetap Tidak Berubah">Pre-commit exclusions serta Ruff dan Black force-exclusion settings melindungi `old/`, `example_before/`, copied, deprecated, development, dan temporary Python reference files. Protection tetap berlaku ketika hook, editor, atau command memberikan path secara explicit.</InfoBox>
## Complete Validation
<Terminal language="bash">{`python -m pytest
python -m ruff check .
python -m black --check .
make check`}</Terminal>
<InfoBox variant="warning" title="Test Behavior dan Boundaries">Changes pada command, step, strategy, atau configuration harus menguji resolution, happy path, invalid input, failure propagation, dan relevant side effects.</InfoBox>
