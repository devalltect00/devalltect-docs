## Ringkasan

Profil Dev publik mengoordinasikan pekerjaan development rutin. Urutan yang
terdaftar saat ini memvalidasi dan membuka hanya pesan commit, membuat backup,
melakukan stage, membuat commit, lalu mendorong branch `HEAD`.

Untuk eksekusi pertama, gunakan mode dry run global. Lanjutkan ke eksekusi
normal hanya setelah repositori, resource yang dibuat, pesan commit, dan tujuan
remote selesai ditinjau.

<InfoBox
    variant="warning"
    title="Dev diakhiri dengan push"
>

`custy run dev` bukan demonstrasi lokal saja. Tanpa `--dry-run`, profil yang
terdaftar mencapai tahap commit dan push. Gunakan `custy run commit` jika Anda
memerlukan profil commit lokal yang didokumentasikan.

</InfoBox>

<Section
    title="Pratinjau Alur Kerja"
>

Opsi global harus ditempatkan sebelum `run`.

<Terminal title="Dry run profil Dev" language="bash">

{`custy --dry-run run dev`}

</Terminal>

Tinjau output untuk commit-message file yang ditentukan, lokasi backup,
perilaku staging, persiapan commit, dan tujuan remote. Jika ada bagian yang
tidak sesuai harapan, hentikan dan sesuaikan konfigurasi proyek atau opsi
perintah.

</Section>

---

<Section
    title="Jalankan Secara Normal Saat Siap"
>

Eksekusi normal merupakan keputusan eksplisit setelah pratinjau dan peninjauan
repositori.

<Terminal title="Jalankan profil development" language="bash">

{`custy run dev`}

</Terminal>

Setelah selesai, verifikasi kondisi lokal dan remote.

<Terminal title="Verifikasi setelah eksekusi" language="bash">

{`git status --short --branch
git log -1 --decorate --oneline
git remote -v`}

</Terminal>

<InfoBox
    variant="warning"
    title="Pemilihan remote berbasis konfigurasi"
>

Profil Dev mengikuti explicit `--remote`, `--all-remote`, dan configured Git
remote groups. Pastikan effective destinations melalui output dry run dan
tinjau dokumentasi Push khusus sebelum eksekusi normal.

</InfoBox>

</Section>
