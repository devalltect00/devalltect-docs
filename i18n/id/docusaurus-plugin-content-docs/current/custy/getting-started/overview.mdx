## Ringkasan

Panduan ini mengantar Anda dari instalasi hingga pratinjau pipeline yang sudah
ditinjau. Anda akan menginstal Custy, membuat resource khusus proyek,
memvalidasi repositori, dan memeriksa pipeline development sebelum mengizinkan
Custy mengubah file atau riwayat Git.

<InfoBox
    variant="info"
    title="Custy bekerja dengan proyek yang sudah ada"
>

Custy adalah CLI untuk otomatisasi alur kerja dan rilis. Custy tidak membuat
aplikasi Anda atau menginisialisasi riwayat Git-nya. Mulailah dari direktori
root repositori yang ingin Anda kelola dengan Custy.

</InfoBox>

<Section
    title="Versi Singkat"
>

<Terminal title="Urutan orientasi awal yang aman" language="bash">

{`# Dari direktori root repositori Git yang sudah ada
custy --version
custy init
git status --short
custy validate
custy --dry-run run dev`}

</Terminal>

Dry run adalah langkah terakhir dalam orientasi awal dasar. Lanjutkan ke
eksekusi normal hanya setelah Anda memahami efek profil yang dipilih terhadap
file, Git, dan remote.

</Section>

---

<InfoBox
    variant="warning"
    title="Perintah pipeline dapat menimbulkan perubahan penting"
>

Profil seperti `dev`, `release`, dan `full` dapat mengedit file, membuat riwayat
Git, membuat tag, serta melakukan push ke remote. Baca halaman profil terkait
dan pastikan kondisi repositori sudah benar sebelum menjalankannya tanpa
`--dry-run`.

</InfoBox>
