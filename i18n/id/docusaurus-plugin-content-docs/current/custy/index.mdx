## Ringkasan

Custy adalah CLI produktivitas developer yang dapat dikonfigurasi untuk
mengelola pekerjaan Git dan rilis yang berulang. Custy menyatukan validasi
proyek, pembaruan versi, pembuatan changelog, backup, cleanup, commit, tag,
push, dan pipeline multi-langkah dalam satu antarmuka yang konsisten.

<InfoBox
    variant="info"
    title="Status dokumentasi"
>

Referensi perintah mencakup CLI publik yang tersedia saat ini. Profil pipeline
internal tidak ditampilkan sebagai perintah publik kecuali CLI yang terpasang
memang mengeksposnya. Keterbatasan implementasi yang diketahui dijelaskan pada
halaman terkait.
Halaman [Status Dokumentasi](./custy/reference/documentation-status) menjelaskan
baseline rilis, tanggal peninjauan, dan cara membandingkan versi terpasang yang
berbeda.

</InfoBox>

<Section
    title="Mulai dari Sini"
>

[Panduan Memulai](./custy/getting-started/overview) mengantar Anda dari instalasi
hingga pratinjau pipeline yang sudah ditinjau. Gunakan
[dokumentasi perintah](./custy/commands/overview) saat Anda memerlukan detail opsi,
efek samping, contoh, output, dan panduan pemecahan masalah. Gunakan
[panduan Konfigurasi](./custy/configuration/overview) untuk memahami nilai default
milik proyek, path, template, remote Git, perilaku changelog, dan logging.
Gunakan [panduan Pipeline](./custy/pipelines/overview) untuk memahami resolusi profil,
batas eksekusi, serta detail langkah internal untuk kontributor. Gunakan
[Panduan Pengguna](./custy/user-guide/overview) untuk alur pengembangan, rilis,
pemeliharaan, dan pemulihan yang berorientasi pada tugas. Gunakan
[Panduan Developer](./custy/developer-guide/overview) untuk menyiapkan source checkout,
menguji perubahan, serta memperluas perintah, pipeline, strategi versi, atau
konfigurasi dengan aman. Gunakan [panduan Arsitektur](./custy/architecture/overview)
untuk menelusuri fitur tersebut melalui CLI, layanan inti, batas Git, pipeline,
workflow engine, strategi, dan subsistem changelog.
Gunakan [Referensi](./custy/reference/overview) ketika Anda memerlukan nama perintah,
opsi global, format versi, profil pipeline, path, persyaratan lingkungan, atau
catatan status keluar secara tepat tanpa membaca panduan yang lebih panjang.
Gunakan [pusat Pemecahan Masalah](./custy/troubleshooting/overview) untuk mengarahkan
kegagalan ke diagnosis Git, konfigurasi, versioning, changelog, atau alur kerja
dan memulihkan kondisi parsial dengan aman.

<Terminal title="Titik awal yang umum" language="bash">

{`# Siapkan resource Custy khusus proyek
custy init

# Periksa apakah repositori siap
custy validate

# Lihat profil pipeline publik
custy run --help`}

</Terminal>

</Section>

<Section
    title="Pilih Operasi Terkecil yang Sesuai"
>

- Gunakan perintah langsung ketika Anda hanya memerlukan satu operasi tertentu.
- Gunakan `custy run dev`, `custy run release`, atau `custy run full` ketika
  Anda memerlukan pipeline yang terkoordinasi.
- Tinjau efek samping yang didokumentasikan sebelum menjalankan profil yang
  dapat mengedit file, membuat riwayat Git, atau berkomunikasi dengan remote.
- Gunakan dukungan dry run jika tersedia pada perintah atau alur kerja yang
  dipilih.

Grup perintah `custy workflow` masih eksperimental. Dokumentasinya dipisahkan
dari profil pipeline yang stabil dan menjelaskan keterbatasan saat ini dengan
jelas.

</Section>
