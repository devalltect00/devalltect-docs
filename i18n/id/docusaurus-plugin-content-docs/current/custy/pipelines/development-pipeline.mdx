## Ringkasan

Dev adalah deliberate daily-development profile. Profile ini menyiapkan dan
me-review release artifacts, generate changelog, membuat commit, lalu push.
Dev tidak menerapkan prepared version dan tidak membuat tag.

<Terminal title="Preview before normal execution" language="bash">{`custy --dry-run run dev
custy run dev`}</Terminal>

<InfoBox variant="info" title="Prepared Version Tidak Diterapkan">Dev menyertakan version preparation karena later services membutuhkan version context, tetapi tidak menyertakan `apply_version_step`. Dev juga tidak menyertakan `tag_step`. Gunakan Release jika perlu menulis version baru dan membuat release tag.</InfoBox>
<InfoBox variant="warning" title="Dev Memiliki Validation Prefix Lebih Sempit">Profile secara explicit dimulai dengan repository validation, bukan full pre-commit dan pre-push validation subprofiles milik Release. Downstream services tetap dapat menolak invalid state. Konfirmasi message files, staged changes, dan remotes sebelum normal execution.</InfoBox>

<Section title="Failure dan Retry">Jika Dev gagal sebelum commit, periksa generated files, edits, backups, dan Git index. Jika gagal saat atau setelah push, verifikasi apakah local commit dan remote updates sudah selesai. Jangan menjalankan ulang seluruh profile sampai state tersebut dipahami.</Section>
