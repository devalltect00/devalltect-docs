## Ringkasan

Dev adalah daily-development profile yang disengaja. Profile ini memvalidasi
dan meninjau pesan commit, melakukan stage, membuat commit, lalu mendorong
branch `HEAD`. Dev tidak menyiapkan release state, membuat release artifacts
atau changelog, membuat tag, atau mendorong tag.

<Terminal
  title="Preview before normal execution"
  language="bash"
>{`custy --dry-run run dev
custy run dev`}</Terminal>

<InfoBox variant="info" title="Release Responsibilities Dikecualikan">
  Dev tidak menyiapkan atau menerapkan version, menginisialisasi workflow rilis, membuat
  release artifacts atau changelog, mengedit tag message, membuat tag, atau mendorong
  tag. Gunakan Release untuk publikasi versioned dan tagged.
</InfoBox>
<InfoBox variant="warning" title="Dev Hanya Memvalidasi yang Digunakan">
  Profile memvalidasi repository, commit-message, hook, dan remote readiness. Version
  serta tag-message validation sengaja dilewati karena berada di luar Dev workflow.
</InfoBox>

<Section title="Failure dan Retry">
  Jika Dev gagal sebelum commit, periksa edited message, backups, dan Git index. Jika
  gagal saat atau setelah push, verifikasi apakah local commit dan remote updates sudah
  selesai. Jangan menjalankan ulang seluruh profile sampai state tersebut dipahami.
</Section>
