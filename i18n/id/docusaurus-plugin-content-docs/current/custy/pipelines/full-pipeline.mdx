## Ringkasan

Full menggunakan complete Release step list dan menambahkan `finalize_step` di
akhir. Finalization dapat melakukan branch transitions, merges, pushes, atau
cleanup berdasarkan workflow case yang ditemukan lebih awal dalam pipeline.

<Terminal title="Preview with extra care" language="bash">{`custy --dry-run run full
custy run full`}</Terminal>

<InfoBox variant="danger" title="Finalization Berjalan Setelah Remote Publication">Release commit, tag, dan push dapat berhasil sebelum finalization gagal. Jangan retry Full secara otomatis. Periksa local branches, commit, tag, setiap remote, dan workflow transition yang dicoba terlebih dahulu.</InfoBox>

<InfoBox variant="warning" title="Finalization Bersifat Conditional dan Experimental">Engine melewati post-workflow behavior ketika checks dilewati atau workflow context tidak tersedia. Sebagian workflow cases hanya melaporkan informasi; lainnya dapat checkout, rebase atau merge branches, push, atau membersihkan release branch. Setelah actions berhasil, Custy dapat pause untuk confirmation sebelum kembali.</InfoBox>
