## Ringkasan

Release adalah complete public publication profile. Profile ini mencakup
repository, commit, tag, dan remote validation sebelum menerapkan version
state, generate release documentation, membuat Git history, dan push ke
resolved remotes.

<Terminal title="Preview and execute" language="bash">{`custy --dry-run run release
custy run release`}</Terminal>

<InfoBox variant="warning" title="Changelog Generation Bersifat Conditional">Release profile memuat changelog step, tetapi workflow engine dapat melewati generation untuk non-final version atau berdasarkan active command dan configuration rules. Registered step tidak menjamin file akan dimutasi.</InfoBox>
<InfoBox variant="danger" title="Publication Tidak Atomic">Failure dapat terjadi setelah files berubah, commit atau local tag dibuat, atau satu remote berhasil. Periksa exact completion boundary sebelum retry.</InfoBox>

<Section title="Release atau Full?">Release berakhir setelah push. Full memuat Release stages yang sama, lalu invoke experimental branch workflow finalization. Pilih Release kecuali post-publication transition tersebut memang diperlukan dan dipahami.</Section>
