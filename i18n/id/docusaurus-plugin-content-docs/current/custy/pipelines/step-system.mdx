## Ringkasan

Pipeline package Custy memisahkan workflow definition dari execution. Profiles
memberi nama intended steps, registry memetakan names ke classes, builder
membuat instances, dan pipeline memanggil setiap instance dengan satu shared context.

<InfoBox variant="warning" title="Internal Extension Point, Bukan Public Plugin API">Registry memungkinkan dynamic construction di dalam Custy, tetapi project saat ini tidak menyediakan documented third-party plugin installation contract. Perlakukan modules ini sebagai contributor-facing internals yang dapat berubah bersama source.</InfoBox>

<Section title="Registry Contracts">

- Panggil `register_all_steps()` satu kali sebelum membangun pipeline. Mendaftarkan name sama kembali menghasilkan `ValueError`.
- Membangun unregistered name gagal dengan `KeyError` sebelum execution.
- Step constructor arguments dapat diberikan melalui `args` object dalam resolved step definition.
- Registration hanya membuat class dapat dibangun; ini tidak mengekspos public `custy run` profile name baru.

</Section>

<Section title="Context dan State Discipline">Simpan configuration dan services dalam workflow engine. Gunakan `GitContext` untuk shared runtime state yang harus melewati step boundary, seperti current tag, workflow case, atau staging list. Step harus mendelegasikan domain behavior ke engine atau focused service, bukan menduplikasi Git atau release logic.</Section>

---

<InfoBox variant="danger" title="Mengubah Order Dapat Mengubah Safety">Global order merupakan bagian execution contract untuk merged profiles. Priority baru atau yang dipindahkan dapat mengubah apakah validation berjalan sebelum file writes atau apakah commit, tag, push, cleanup, dan finalization berjalan dalam safe sequence. Perlakukan ordering changes sebagai behavioral changes dan test sesuai dampaknya.</InfoBox>

Setiap step yang dapat berpartisipasi dalam merged profiles harus memiliki
explicit `STEP_ORDER` entry. Tanpa entry, step menerima fallback priority `999`
dan berpindah setelah seluruh known steps. Tinjau complete contract dalam
[Step Priority and Ordering](./step-order).
