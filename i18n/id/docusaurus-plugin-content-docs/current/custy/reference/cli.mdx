<Section title="Command publik">

- Direct commands: `init`, `validate`, `commit`, `tag`, `push`, dan `run`.
- Command groups: `changelog`, `configure`, `workflow`, `version`, `backup`, dan `cleanup`.
- `custy configure credentials` menyiapkan, memeriksa, menguji, atau menghapus optional external HTTPS credential fallback. Lihat [Configure Credentials](../commands/configure/credentials/overview).
- Entrypoint setara: installed script `custy` dan `python -m app`.

</Section>

<InfoBox variant="warning" title="Internal profile bukan command publik">
  Nama dalam pipeline resolver tidak otomatis dapat digunakan melalui `custy run`.
  Gunakan hanya value yang tercantum pada Run command.
</InfoBox>
