<Section title="Aturan utama">
  `custy init` membuat konfigurasi dari packaged template. File hasilnya menjadi milik
  project. CLI value biasanya memiliki prioritas tertinggi, kemudian project
  configuration, lalu built-in fallback; halaman resolution mencatat pengecualian.
</Section>

<InfoBox variant="info" title="Baca status property">
  Label active, loaded-only, reserved, atau advanced menjelaskan apakah key benar-benar
  memengaruhi runtime. Keberadaan key pada template saja bukan bukti behavior aktif.
</InfoBox>
