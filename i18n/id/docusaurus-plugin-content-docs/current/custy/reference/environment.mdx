<Section title="Kebutuhan dasar">Local installation memerlukan Python yang memenuhi project metadata, `pip`, dan Git. Virtual environment direkomendasikan. Docker dan Make bersifat optional sesuai installation method atau helper yang digunakan.</Section>

<InfoBox variant="info" title="Authentication berada di luar Custy">Push memakai konfigurasi credential Git pada host atau container. Custy tidak menyimpan token remote. Pastikan editor eksternal dan encoding terminal juga sesuai environment Anda.</InfoBox>
