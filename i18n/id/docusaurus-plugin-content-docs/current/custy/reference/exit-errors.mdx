<Section title="Cara membaca kegagalan">Mulai dari pesan pertama, phase terakhir yang sukses, process status, dan state repository saat ini. Parser failure terjadi sebelum command body; validation failure menghentikan operation yang bergantung padanya; pipeline failure dapat terjadi setelah sebagian efek selesai.</Section>

<InfoBox variant="warning" title="Jangan mengandalkan exit code saja">Beberapa help, version, atau explicit-exit path memiliki behavior khusus. Gunakan output terminal dan log bersama exit status, lalu verifikasi Git serta file state.</InfoBox>
