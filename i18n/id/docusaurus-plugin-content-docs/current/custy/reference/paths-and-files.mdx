<Section title="File utama">
  Configuration berada di `.config/custy/config.toml`; template changelog berada di
  `.config/custy/templates/changelog/changelog.j2` secara default. Version file,
  changelog output, backup directory, dan log path mengikuti setting project.
</Section>

<InfoBox variant="warning" title="Working directory menentukan resolution">
  Jalankan Custy dari project root yang memuat `.config/custy/config.toml`. Relative
  path dapat menunjuk lokasi yang salah jika command dijalankan dari directory lain.
</InfoBox>
