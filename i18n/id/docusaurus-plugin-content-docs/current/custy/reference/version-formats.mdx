<Section title="Format yang perlu dibedakan">SemVer dan PEP 440 memiliki aturan pre-release berbeda. Commitizen dapat menjadi provider workflow. Date dan Git-count strategy menghasilkan bentuk yang bergantung pada waktu atau repository state. Prefix seperti `v` adalah bagian presentasi tag, bukan selalu bagian version file.</Section>

<InfoBox variant="warning" title="Conversion bersifat terbatas">Jangan menganggap setiap string valid dapat dikonversi losslessly antarformat. Uji pre-release, local version, prefix, dan invalid input sebelum mengubah strategy.</InfoBox>
