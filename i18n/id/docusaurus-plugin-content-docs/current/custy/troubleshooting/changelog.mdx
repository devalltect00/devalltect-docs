## Entry hilang atau duplicate

Periksa Git range, tag boundary, merge behavior, pending commit source, dan existing release parsing. Pastikan commit yang diharapkan berada pada history yang dikumpulkan.

## Grouping atau heading tidak sesuai

Periksa Conventional Commit parsing, section mapping, cleaning rules, sorting, dan release behavior. Gunakan exact configuration status karena sebagian key belum aktif di runtime.

## Template atau output gagal

Pastikan configured template ada dan valid untuk model yang diberikan. Periksa output path, encoding, permission, serta working directory sebelum mencoba lagi.
