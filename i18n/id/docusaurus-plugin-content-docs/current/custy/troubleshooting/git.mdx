## Repository tidak terdeteksi

Pastikan command dijalankan di dalam work tree yang benar. Jalankan `git status`, periksa project root, lalu pastikan `.git` dan `.config/custy/config.toml` merujuk project yang sama.

## Commit atau tag sudah ada

Periksa `git status`, recent commits, dan local tags. Jangan membuat ulang efek yang sudah berhasil; lanjutkan hanya phase yang belum selesai atau pilih version/tag yang benar.

## Push ditolak atau authentication gagal

Periksa URL serta nama remote, upstream branch, credential host, dan perbedaan local/remote. Custy memakai authentication Git environment dan tidak menyimpan token.

<InfoBox variant="warning" title="Branch cleanup bersifat destruktif">Gunakan filter konservatif dan dry-run bila tersedia. Pastikan protected branch dan current branch tidak menjadi target.</InfoBox>
