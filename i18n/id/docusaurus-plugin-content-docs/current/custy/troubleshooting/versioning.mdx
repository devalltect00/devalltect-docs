## Version file hilang atau tidak diperbarui

Periksa configured path, supported file format, dan working directory. Pastikan generation phase benar-benar diikuti file-application phase pada profile yang digunakan.

## Strategy atau format ditolak

Gunakan nama strategy yang didukung dan input version yang valid untuk format tersebut. Jangan mencampur SemVer pre-release, PEP 440, prefix tag, dan project-file representation.

## Tag conflict setelah update

Periksa local dan remote tags sebelum mencoba ulang. Jika version file sudah berubah tetapi tag gagal, pulihkan atau lanjutkan dari state aktual—jangan otomatis mengulang seluruh pipeline.

<InfoBox variant="warning" title="Generation dan tagging adalah phase terpisah">
  Version baru dapat sudah dihitung atau ditulis sebelum tag dibuat. Periksa file diff
  dan tags untuk menentukan recovery.
</InfoBox>
