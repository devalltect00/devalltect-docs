## Profile ditolak

Gunakan hanya public Run values yang didukung. Internal composition profile atau direct-command profile di resolver bukan pilihan publik.

## Urutan berbeda dari perkiraan

Profile expansion di-deduplicate dan dinormalisasi memakai `STEP_ORDER`. Periksa concrete sequence pada profile reference, bukan hanya urutan nama saat composition.

## Pipeline berhenti di tengah

Catat step terakhir yang sukses dan periksa Git serta file state. Jalankan validation atau command paling sempit untuk phase tersisa; hindari mengulang `release` atau `full` tanpa audit.

<InfoBox variant="warning" title="Workflow command masih experimental">`custy workflow branch` memiliki batas implementasi yang terdokumentasi. Jangan menganggapnya setara dengan public pipeline yang stabil.</InfoBox>
