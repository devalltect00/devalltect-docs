## Tujuan

Gunakan Dev ketika reviewed daily work harus menghasilkan supporting artifacts
dan changelog content, membuat satu local commit, lalu berakhir dengan remote
push. Pilih direct command jika hanya membutuhkan satu outcome.

<InfoBox variant="warning" title="Dev Bukan Local-Only">Normal execution berakhir dengan `push_step`. Konfirmasi destination saat dry-run dan tinjau [Push documentation](../commands/push/overview) sebelum menggunakan Dev pada repository dengan remotes yang belum diverifikasi.</InfoBox>

<Section title="Verify Completion"><Terminal title="Local verification" language="bash">{`git status --short --branch

git tag --points-at HEAD

uncommitted work. Dev tidak boleh membuat release tag baru. Konfirmasi remote
result melalui repository host atau appropriate Git fetch dan comparison workflow.
