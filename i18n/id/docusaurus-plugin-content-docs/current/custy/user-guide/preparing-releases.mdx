## Tujuan

Gunakan Release ketika approved version harus diterapkan, didokumentasikan,
di-commit, diberi tag, dan di-push. Profile memvalidasi release prerequisites
dan berakhir setelah push; profile tidak menjalankan experimental finalization
stage milik Full.

<InfoBox variant="danger" title="Release Bersifat Durable dan Non-Transactional">
  File updates, commit, local tag, dan satu atau lebih remote pushes dapat selesai
  sebelum later failure. Custy tidak me-roll back effects tersebut sebagai satu unit.
</InfoBox>

<Section title="Post-Release Verification"><Terminal title="Verify local release state" language="bash">{`git status --short --branch
git log -1 --decorate --stat
git tag --points-at HEAD
git remote -v`}</Terminal>
Verifikasi juga branch dan tag melalui setiap repository host atau appropriate
fetch-and-compare process. Successful push ke satu destination tidak membuktikan
seluruh configured destinations selesai.

</Section>

<InfoBox variant="warning" title="Release adalah Recommended Default daripada Full">
  Full menambahkan experimental post-push branch transitions dan cleanup. Gunakan
  Release kecuali Anda sengaja membutuhkan dan memahami additional boundary tersebut.
</InfoBox>
