# Devalltect Docs

Devalltect Docs adalah portal Docusaurus bersama untuk empat peralatan developer
Devalltect. Portal ini menyediakan satu tempat untuk menemukan proyek,
mempelajari penggunaan yang aman, mencari referensi perintah dan konfigurasi,
serta memahami alur pengembangan dan rilisnya.

## Dokumentasi yang Didukung

| Proyek                  | Rilis yang didokumentasikan | Fokus utama                                                 |
| ----------------------- | --------------------------- | ----------------------------------------------------------- |
| **Custy**               | v2.1.2                      | Alur Git, versioning, changelog, backup, cleanup, dan rilis |
| **Path Header Scanner** | v1.0.1                      | Pratinjau, validasi, dan penerapan path header repositori   |
| **Doc Gen**             | v1.0.2                      | Pembuatan, pencetakan, dan analisis struktur proyek         |
| **Reflow**              | v1.0.2                      | Konversi tag, pemulihan release, dan publikasi container    |

Bahasa Inggris adalah locale default dan Bahasa Indonesia menyediakan
dokumentasi yang selaras. Nama perintah, opsi, path, key konfigurasi, dan
identifier kode tetap literal jika penerjemahan mengurangi akurasi teknis.

## Struktur Portal

- Landing page proyek memperkenalkan setiap alat dan menyediakan pratinjau visual representatif.
- Panduan memulai menyediakan jalur aman terpendek menuju hasil yang berguna.
- Halaman perintah dan konfigurasi mendokumentasikan kontrak pengguna secara tepat.
- Halaman konsep dan arsitektur menjelaskan perilaku serta batas implementasi.
- Panduan developer dan pemecahan masalah mendukung pemeliharaan dan diagnosis.
- Halaman status berbasis release menunjukkan versi proyek yang diwakili dokumentasi.

## Lingkungan Pengembangan

Maintainer dapat bekerja langsung menggunakan runtime Yarn yang dipin atau
memakai lingkungan Docker dan Compose opsional. Kedua jalur menjalankan kontrak
formatting, freshness, type checking, dan build multilingual yang sama.
Container produksi merupakan pratinjau lokal atau self-hosted; GitHub Pages dan
GitLab Pages tetap melakukan deployment file statis secara langsung.

Lihat [Docker dan Compose](./devalltect-docs/docker) untuk stage image, perintah, port, perilaku
volume, dan batas CI.

## Untuk Maintainer

Baca [alur kerja maintainer](./devalltect-docs/maintainer-workflow) sebelum mengubah komponen
bersama, metadata proyek, terjemahan, atau screenshot. Gunakan
[versioning dan freshness](./devalltect-docs/versioning-and-freshness) saat memperbarui baseline
proyek atau menyiapkan rilis portal.
