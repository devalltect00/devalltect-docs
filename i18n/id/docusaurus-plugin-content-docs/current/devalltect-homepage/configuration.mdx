# Konfigurasi

Homepage dapat berjalan tanpa berkas lingkungan. Tujuan publik kanonis sudah
tersedia sebagai fallback yang aman.

Salin `.env.example` menjadi `.env` hanya ketika pratinjau lokal atau deployment
alternatif memerlukan entrypoint berbeda:

```dotenv
PUBLIC_PORTFOLIO_URL=https://devalltect-portfolio.vercel.app/
PUBLIC_DOCUMENTATION_URL=https://devalltect00.github.io/devalltect-docs/
```

Kedua variabel tersebut adalah nilai build-time publik Astro. Nilai kosong,
tidak valid, atau bukan HTTP(S) kembali ke URL kanonis agar navigasi tidak rusak.

## Metadata repositori

Deskripsi repositori dan topik khusus provider disimpan dalam `package.json`.
Tinjau permintaan sebelum menerapkannya:

```bash
pnpm repository:metadata:dry-run --provider github
pnpm repository:metadata:dry-run --provider gitlab
```

Sinkronisasi metadata memerlukan CLI provider yang sudah terautentikasi dan
izin eksplisit untuk mengubah repositori remote.
