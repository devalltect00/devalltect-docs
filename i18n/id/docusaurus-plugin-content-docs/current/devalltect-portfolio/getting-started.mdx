# Memulai

## Kunjungi portofolio

Buka [devalltect-portfolio.vercel.app](https://devalltect-portfolio.vercel.app/).
Situs dimulai dalam Bahasa Inggris dengan tema terang. Gunakan kontrol navigasi
untuk mengganti bahasa, tema, atau menyembunyikan lampu 3D interaktif.

Arsip proyek mendukung pencarian nama, filter teknologi atau status, serta
pengurutan tanggal mulai. Jika sebuah proyek memiliki beberapa screenshot,
gunakan kontrol galeri atau gesture drag untuk berpindah gambar.

## Jalankan source secara lokal

Persyaratan:

- Node.js 24
- Corepack
- pnpm 12.5.1

```bash
git clone https://github.com/devalltect00/devalltect-portfolio-v2.git
cd devalltect-portfolio-v2
corepack enable
pnpm install --frozen-lockfile
pnpm assets:stage
pnpm dev
```

Buka `http://localhost:3000/en/` atau `http://localhost:3000/id/`.

Untuk ponsel pada jaringan tepercaya yang sama, gunakan `pnpm dev:lan`. Helper
akan mendeteksi alamat privat saat ini tanpa memerlukan IP yang di-commit.

## Validasi checkout

```bash
pnpm validate
pnpm exec playwright install chromium
pnpm test:e2e
```

Docker dan Compose bersifat opsional. Vercel membangun static export Next.js
secara langsung dan tidak men-deploy container proyek.
