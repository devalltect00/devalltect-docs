# Portofolio Devalltect

Devalltect Portfolio v2 adalah presentasi interaktif dwibahasa mengenai proyek,
pengalaman teknis, dan karya rekayasa perangkat lunak kreatif. Pengunjung
dipandu melalui perjalanan pilihan tanpa kehilangan arsip proyek yang dapat
dicari untuk eksplorasi lebih lanjut.

**Buka portofolio:** [devalltect-portfolio.vercel.app](https://devalltect-portfolio.vercel.app/)
