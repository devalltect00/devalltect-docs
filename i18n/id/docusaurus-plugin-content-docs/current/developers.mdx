# Hub Developer

Pilih proyek yang ingin Anda kembangkan atau tinjau. Setiap panduan developer
mengikuti arsitektur dan alur kerja nyata proyek, bukan memaksa setiap alat ke
dalam struktur yang sama persis.

## Panduan Developer Proyek

| Proyek                  | Titik awal pengembangan                                                  | Arsitektur                                                               |
| ----------------------- | ------------------------------------------------------------------------ | ------------------------------------------------------------------------ |
| **Custy**               | [Buka panduan developer](./custy/developer-guide/overview)               | [Tinjau arsitektur Custy](./custy/architecture/overview)                 |
| **Path Header Scanner** | [Buka panduan developer](./path-header-scanner/developer-guide/overview) | [Tinjau arsitektur scanner](./path-header-scanner/architecture/overview) |
| **Doc Gen**             | [Buka panduan developer](./doc-gen/developer-guide/overview)             | [Tinjau arsitektur Doc Gen](./doc-gen/architecture/overview)             |
| **Reflow**              | [Buka panduan developer](./reflow/developer-guide/overview)              | [Tinjau arsitektur Reflow](./reflow/architecture/overview)               |

Panduan proyek membahas penyiapan source, pengujian, formatting, linting,
pre-commit, Docker, Compose, alur Make, ekspektasi kontribusi, dan extension
point yang relevan.

## Memelihara Portal Dokumentasi Ini

Gunakan [alur maintainer Devalltect Docs](./devalltect-docs/maintainer-workflow)
saat mengubah komponen bersama, metadata proyek, terjemahan, screenshot,
freshness dokumentasi, atau materi rilis.

Gunakan [panduan Docker dan Compose](./devalltect-docs/docker) saat Anda
memerlukan development server yang reproducible, validasi dalam container,
atau pratinjau produksi yang immutable.

Sebelum mengirim perubahan, jalankan pemeriksaan yang diwajibkan proyek terkait
dan validasi portal ini melalui pengujian freshness, pemeriksaan TypeScript,
serta build produksi untuk kedua locale.
