### 1. Preview

<Terminal language="bash">{`doc-gen init --dry-run`}</Terminal>

**Hasil:** Shows plan.

### 2. Initialize

<Terminal language="bash">{`doc-gen init`}</Terminal>

**Hasil:** Membuat `.config/doc_gen/config.toml` jika file tersebut belum ada.

### 3. Configuration only

<Terminal language="bash">{`doc-gen init --mode config`}</Terminal>

**Hasil:** Membuat file konfigurasi yang sama melalui mode `config` secara eksplisit.

### 4. Force

<Terminal language="bash">{`doc-gen init --mode all --force`}</Terminal>

**Hasil:** Mengganti file konfigurasi yang sudah ada tanpa meminta konfirmasi.
