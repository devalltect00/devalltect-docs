| Flag / nilai                      | Default | Efek                                                                                                        |
| --------------------------------- | ------- | ----------------------------------------------------------------------------------------------------------- |
| `--mode, -m`                      | `all`   | Pilih `all` atau `config`. Saat ini keduanya membuat konfigurasi proyek; `all` adalah mode gabungan bawaan. |
| `--force/--no-force, -f/-F`       | false   | Timpa file konfigurasi yang sudah ada.                                                                      |
| `--ask, -a`                       | false   | Minta konfirmasi sebelum mengganti file konfigurasi yang sudah ada.                                         |
| `--dry-run/--no-dry-run, -dr/-Dr` | false   | Pratinjau tanpa menulis perubahan.                                                                          |
