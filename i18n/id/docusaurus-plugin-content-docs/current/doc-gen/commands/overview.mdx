<Section title="Perintah yang didukung">

| Perintah                                                               | Hasil                     | Menulis dokumentasi proyek |
| ---------------------------------------------------------------------- | ------------------------- | -------------------------- |
| [`doc-gen init`](./init/overview)                                      | Konfigurasi proyek        | Ya, kecuali dry-run        |
| [`doc-gen structure generate [TARGET]`](./structure/generate/overview) | Dokumen struktur Markdown | Ya, kecuali dry-run        |
| [`doc-gen structure print [TARGET]`](./structure/print/overview)       | Pohon terminal            | Tidak                      |
| [`doc-gen structure analyze [TARGET]`](./structure/analyze/overview)   | Analisis terminal         | Tidak                      |

</Section>

Perintah struktur berbagi opsi profil, smart mode, kedalaman, visibilitas file,
collapse, jenis proyek, verbosity, dan dry-run.

<InfoBox variant="warning" title="Hanya generate yang menyimpan output struktur">

`print` dan `analyze` bersifat read-only. `generate --dry-run` menjalankan
discovery dan rendering di memori tanpa membuat direktori maupun file output.

</InfoBox>
