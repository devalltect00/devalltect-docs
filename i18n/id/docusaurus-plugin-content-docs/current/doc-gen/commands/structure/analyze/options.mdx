| Flag / nilai                      | Bawaan                | Efek                                                                   |
| --------------------------------- | --------------------- | ---------------------------------------------------------------------- |
| `TARGET_DIRECTORY`                | .                     | Direktori akar repositori yang akan dipindai.                          |
| `--profile`                       | custom                | Pilih `minimal`, `default`, `detailed`, atau `custom`.                 |
| `--smart/--no-smart`              | false                 | Aktifkan optimasi otomatis sesuai profil.                              |
| `--max-depth`                     | 5                     | Kedalaman direktori maksimum yang ditampilkan.                         |
| `--show-files/--hide-files`       | true                  | Tampilkan atau sembunyikan file.                                       |
| `--collapse`                      | daftar terkonfigurasi | Daftar direktori yang akan diringkas, dipisahkan dengan koma.          |
| `--project-type`                  | terdeteksi otomatis   | Ganti hasil deteksi jenis proyek.                                      |
| `--verbose, -v`                   | false                 | Tampilkan informasi tambahan tentang struktur yang dihasilkan.         |
| `--dry-run/--no-dry-run, -dr/-Dr` | false                 | Simulasikan output yang dapat berubah; proses penemuan tetap berjalan. |
