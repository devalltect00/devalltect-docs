<Section title="Purpose">
  Memindai repository, merender tree sebagai Markdown, dan menulis hanya output document
  hasil resolution.
</Section>

<InfoBox variant="warning" title="Batas keamanan">
  Hanya generate yang menulis output. Dry-run merender in-memory tanpa membuat direktori
  atau file.
</InfoBox>

- Resolve target/profile/output.
- Scan dengan ignore/collapse.
- Render Markdown in-memory.
- Dry-run berhenti sebelum write.
- Live mode menulis hanya output terpilih.
