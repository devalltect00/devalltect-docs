### 1. Print current project

<Terminal language="bash">{`doc-gen structure print .`}</Terminal>

**Hasil:** Displays tree.

### 2. Minimal

<Terminal language="bash">{`doc-gen structure print . --profile minimal`}</Terminal>

**Hasil:** Displays concise tree.

### 3. Directories only

<Terminal language="bash">{`doc-gen structure print . --hide-files`}</Terminal>

**Hasil:** Hides files.

### 4. Dry-run

<Terminal language="bash">{`doc-gen structure print . --dry-run`}</Terminal>

**Hasil:** Remains read-only.
