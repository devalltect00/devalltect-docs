title: Profile dan Smart Mode
description: Atur detail struktur dengan preset atau optimasi repository-aware.
sidebar_position: 8
sidebar_key: doc-gen-profiles
---

Profile tersedia sebagai `minimal`, `default`, `detailed`, dan `custom`. Smart mode menyesuaikan depth, file visibility, dan collapsed directory berdasarkan repository. Explicit CLI values tetap memiliki precedence lebih tinggi.
