## Overview

Pertahankan CLI interaction di `app/doc_gen/cli`, reusable structure behavior
di `app/doc_gen/core/structure`, Markdown construction dalam renderers, dan file
persistence dalam writers. Nyatakan selected targets dan outputs dengan jelas.

<Section title="Quality Gates">

<Terminal title="Contributor validation" language="bash">

{`# Focused examples
python -m pytest tests/cli
python -m pytest tests/test_dry_run.py

# Complete validation

python -m pytest
make check

# Hook validation

make pre-commit-validate
make pre-commit-run-staged
make pre-commit-run`}

</Terminal>

<InfoBox variant="warning" title="Refresh adalah maintainer operation">

Gunakan `make pre-commit-refresh` hanya untuk intentional hook upgrades. Command
ini dapat mengakses network serta mengubah `.pre-commit-config.yaml` dan active
files. Review seluruh hasil sebelum menyimpan perubahan apa pun.

</InfoBox>

</Section>
