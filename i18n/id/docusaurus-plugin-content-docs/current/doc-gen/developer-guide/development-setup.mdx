## Tujuan

Gunakan isolated environment dengan command `doc-gen` yang memuat active
checkout. Install `.[dev]`; runtime-only editable installation tidak menyertakan
pytest, Ruff, Black, atau pre-commit.

<Section title="Manual Setup">

<Terminal title="Create and install" language="bash">

{`python -m venv venv

# Windows PowerShell

venv\\Scripts\\Activate.ps1

# Linux or macOS

# source venv/bin/activate

python -m pip install --upgrade pip
python -m pip install -e ".[dev]"`}

</Terminal>

Gunakan `python -m pip install -e ".[dev,docs]"` hanya ketika mengerjakan
MkDocs source milik repository.

</Section>

---

<Section title="Makefile Setup">

<Terminal title="Setup helpers" language="bash">

{`make venv
make upgrade-pip
make install-dev

# Combined environment setup and Git-hook installation

make setup`}

</Terminal>

Make workflow menggunakan Python interpreter dalam directory konvensional
`venv/`.

</Section>

<Section title="Pre-Commit Workflow">

Hook configuration Doc Gen menjalankan Ruff fixes, Ruff formatting, Black,
trailing-whitespace cleanup, dan final-newline correction. Ruff dan Black
membaca project policy dari `pyproject.toml`.

<Terminal title="Install and run hooks" language="bash">

{`make pre-commit-install-hooks
make pre-commit-validate
make pre-commit-run-staged
make pre-commit-run`}

</Terminal>

<InfoBox variant="warning" title="Refresh adalah intentional hook upgrade">

`make pre-commit-refresh` memperbarui hook revisions, membersihkan dan
meng-install ulang hook environments, serta menjalankan setiap hook terhadap
semua files. Command ini mungkin memerlukan network access dan dapat mengubah
configuration maupun source files. Review seluruh diff.

</InfoBox>

</Section>
