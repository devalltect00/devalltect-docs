<Section title="Pemeriksaan read-only">

<Terminal language="bash">{`doc-gen structure print . --max-depth 3
doc-gen structure analyze . --smart

# Tampilkan direktori saja

doc-gen structure print . --hide-files`}</Terminal>

</Section>

<Section title="Pratinjau, lalu generate">

<Terminal language="bash">{`# Render di memori dan tampilkan rencana yang diselesaikan
doc-gen structure generate . --profile detailed --output docs/project_structure.md --dry-run

# Tulis output yang dipilih hanya setelah ditinjau

doc-gen structure generate . --profile detailed --output docs/project_structure.md`}</Terminal>

</Section>

<InfoBox variant="warning" title="Dry-run tidak membuat path output">

Dry-run untuk generate dapat memindai dan merender, tetapi tidak membuat
direktori maupun file output. `print` dan `analyze` bersifat read-only pada
kedua mode.

</InfoBox>
