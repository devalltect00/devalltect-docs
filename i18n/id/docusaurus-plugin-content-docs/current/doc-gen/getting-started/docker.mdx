<Section title="Tag Image yang Dipublikasikan">

| Tag    | Contoh   | Perilaku                                                                |
| ------ | -------- | ----------------------------------------------------------------------- |
| Eksak  | `v1.0.2` | Immutable dan disarankan untuk CI atau otomasi yang dapat direproduksi. |
| Minor  | `v1.0`   | Bergerak ke patch stabil terbaru dalam lini 1.0.                        |
| Major  | `v1`     | Bergerak ke rilis stabil terbaru dalam lini 1.x.                        |
| Latest | `latest` | Bergerak ke rilis stabil Doc Gen terbaru.                               |

<Terminal title="Pull dan verifikasi Doc Gen" language="bash">

{`docker pull ghcr.io/devalltect00/doc-gen:v1.0.2
docker run --rm ghcr.io/devalltect00/doc-gen:v1.0.2 --help`}

</Terminal>

<InfoBox variant="warning" title="Prerelease tidak menggeser alias stabil">

`v1.0.0-rc.1` hanya memublikasikan tag eksaknya. Alias stabil hanya diperbarui
oleh rilis stabil.

</InfoBox>

</Section>

<Section title="Pilih Tag Secara Terencana">

Gunakan versi eksak untuk generation yang dapat diulang dalam CI. Gunakan
`v1.0`, `v1`, atau `latest` hanya jika upgrade otomatis yang terkontrol dapat
diterima. Mount hanya proyek yang dituju dan gunakan
`structure generate --dry-run` sebelum mengizinkan penulisan dokumen.

</Section>
