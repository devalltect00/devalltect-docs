<CommandHero

  title="Instalasi dan Alur Kerja Pertama"
  description="Gunakan environment khusus, periksa repositori, dan pratinjau output yang diselesaikan sebelum generate."

  syntax="doc-gen structure generate . --dry-run"

<Terminal title="Environment" language="bash">{`python -m venv venv
python -m pip install -e .
doc-gen --version`}</Terminal>

<Terminal title="Alur kerja pertama yang aman" language="bash">{`cd /path/to/project
doc-gen init --dry-run
doc-gen init

# Pemeriksaan read-only

doc-gen structure print .
doc-gen structure analyze .

# Pratinjau target dan path output yang diselesaikan

doc-gen structure generate . --output docs/project_structure.md --dry-run

# Generate hanya setelah meninjau pratinjau

doc-gen structure generate . --output docs/project_structure.md`}</Terminal>

<InfoBox variant="warning" title="Satu output yang dipilih">

`structure generate` dalam mode live hanya menulis output Markdown yang sudah
diselesaikan. Dokumentasi lain yang tidak terkait berada di luar cakupan
penulisan perintah.

</InfoBox>

<InfoBox variant="note" title="Runtime">
  Kompatibel dengan Python 3.9+; runtime standar menggunakan Python 3.14
</InfoBox>
