| Command                               | Efek                                              |
| ------------------------------------- | ------------------------------------------------- |
| `doc-gen init`                        | Menyiapkan konfigurasi proyek                     |
| `doc-gen structure generate [TARGET]` | Membuat dokumen Markdown yang ditentukan          |
| `doc-gen structure print [TARGET]`    | Menampilkan pohon proyek tanpa menulis file       |
| `doc-gen structure analyze [TARGET]`  | Menampilkan ringkasan analisis tanpa menulis file |

<InfoBox variant="tip" title="Preview">
  Generate hanya menulis output Markdown hasil resolution; print dan analyze read-only.
  Generate dry-run tidak membuat direktori atau file.
</InfoBox>
