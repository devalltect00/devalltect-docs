# Foksiku

Foksiku v0.2.0 adalah pelacak pengeluaran Telegram privat yang dibuat dengan
TypeScript, Google Apps Script, dan Google Sheets. Pengguna yang diundang dapat
mencatat pembelian, menggunakan kembali produk tersimpan, mengonfirmasi
perubahan, dan meminta laporan tanpa memberi chatbot umum wewenang atas data
keuangan.

**Bot Telegram:** [@foksikubot](https://t.me/foksikubot)

## Privasi dan akses

Foksiku menerima operasi keuangan dan administrasi hanya dalam chat Telegram
privat. Akses ditentukan oleh ID pengguna Telegram numerik dan peran eksplisit.
Username dan nama tampilan tidak pernah memberikan izin.

Gunakan [Memulai](./getting-started.mdx) atau buka
[Panduan Pengguna](./user-guide/overview.mdx).
