# Referensi Perintah

| Grup         | Perintah                                                                    |
| ------------ | --------------------------------------------------------------------------- |
| Umum         | `/start`, `/help`, `/menu`, `/language`, `/whoami`, `/my_access`, `/cancel` |
| Laporan      | `/today`, `/week`, `/month`, `/year`, `/range`, `/category`, `/top`         |
| Riwayat      | `/transactions`, `/correct`, `/void`                                        |
| Produk       | `/add_product`, `/products`, `/archive_product`                             |
| Pendaftaran  | `/join`                                                                     |
| Administrasi | `/members`, `/invite`, `/revoke_invite`, `/block`, `/unblock`, `/set_role`  |

Help menyesuaikan peran dan tidak menampilkan perintah yang tidak dapat
digunakan akun tersebut. Ejaan lama `/product`, `/archiveproduct`,
`/setrole`, dan `/revokeinvite` tetap didukung sebagai alias.

Alias Bahasa Indonesia yang umum adalah `/bantuan`, `/hariini`, `/minggu`,
`/bulan`, `/tahun`, `/produk`, `/transaksi`, dan `/bahasa`. `/menu` menampilkan
tombol tindakan yang dilokalkan tanpa mengubah aturan otorisasi di belakangnya.
