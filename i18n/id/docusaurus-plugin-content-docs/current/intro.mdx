# Dokumentasi Devalltect

Selamat datang di portal dokumentasi bersama untuk peralatan developer dan
DevOps Devalltect. Gunakan portal ini untuk mempelajari proyek, menemukan
referensi perintah dan konfigurasi, memahami keputusan implementasi, atau
menyiapkan kontribusi.

## Jelajahi Proyek

| Proyek                  | Fokus                                                                        | Dokumentasi                               |
| ----------------------- | ---------------------------------------------------------------------------- | ----------------------------------------- |
| **Path Header Scanner** | Alur inspeksi path dan header sumber                                         | [Buka dokumentasi](./path-header-scanner) |
| **Doc Gen**             | Pembuatan struktur proyek dan dokumentasi                                    | [Buka dokumentasi](./doc-gen)             |
| **Reflow**              | Konversi tag berbasis repositori, pemulihan release, dan publikasi container | [Buka dokumentasi](./reflow)              |
| **Custy**               | Alur Git, versi, changelog, backup, cleanup, dan otomatisasi rilis           | [Buka dokumentasi](./custy)               |

Lihat [Ringkasan Proyek](./projects-overview) untuk penjelasan lebih luas tentang
setiap proyek dan cakupan dokumentasinya saat ini.

## Bahasa

Bahasa Inggris adalah locale default. Bahasa Indonesia tersedia melalui
pemilih bahasa. Portal memelihara dokumentasi Bahasa Inggris dan Bahasa
Indonesia yang selaras untuk Custy, Path Header Scanner, Doc Gen, dan Reflow.

## Menggunakan Portal Ini

- Mulai dari ringkasan proyek atau bagian memulai.
- Gunakan halaman perintah untuk sintaks, opsi, contoh, output, dan pemecahan masalah.
- Gunakan halaman konsep serta arsitektur untuk memahami perilaku dan batas internal.
- Periksa referensi yang selaras dengan sumber sebelum mengandalkan detail konfigurasi atau alur kerja.
- Gunakan [panduan Devalltect Docs](./devalltect-docs) untuk memahami cara memelihara portal.
