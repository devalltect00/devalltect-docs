### 1. Preview

<Terminal language="bash">{`path-header-scanner init --dry-run`}</Terminal>

**Hasil:** Shows planned resources.

### 2. Initialize

<Terminal language="bash">{`path-header-scanner init`}</Terminal>

**Hasil:** Creates resolved resources.

### 3. Configuration only

<Terminal language="bash">{`path-header-scanner init --mode config`}</Terminal>

**Hasil:** Creates configuration.

### 4. Force

<Terminal language="bash">{`path-header-scanner init --mode all --force`}</Terminal>

**Hasil:** Replaces selected files.
