| Flag / nilai                      | Default                         | Efek                                                                                |
| --------------------------------- | ------------------------------- | ----------------------------------------------------------------------------------- |
| `--mode, -m`                      | `all`                           | Pilih `all` atau `config`. Keduanya saat ini menginisialisasi resource konfigurasi. |
| `--force/--no-force, -f/-F`       | `false`                         | Timpa resource terpilih yang sudah ada tanpa prompt.                                |
| `--ask, -a`                       | `false`                         | Minta keputusan sebelum membuat atau mengganti resource bila diperlukan.            |
| `--dry-run/--no-dry-run, -dr/-Dr` | nilai konfigurasi, lalu `false` | Tampilkan rencana tanpa membuat direktori, menulis file, atau meminta konfirmasi.   |

<InfoBox variant="note" title="Cakupan mode pada v1.0.1">

Enum yang terpasang hanya menyediakan `all` dan `config`. Nama seperti
`templates` dan `examples` bukan mode inisialisasi yang diterima pada rilis ini.

</InfoBox>
