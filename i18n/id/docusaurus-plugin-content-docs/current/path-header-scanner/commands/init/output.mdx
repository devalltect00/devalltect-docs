- Dry-run menampilkan setiap direktori yang akan dipastikan dan file yang akan dibuat atau diperbarui.
- Eksekusi live melaporkan mode terpilih dan jumlah resource.
- Panel terakhir membedakan penyelesaian normal dari penyelesaian dry-run.

<Terminal title="Ringkasan inisialisasi" language="text">{`Initialization Summary
Mode                <all atau config>
Created Files       <jumlah>
Copied Files        <jumlah>
Skipped Files       <jumlah>
Created Directories <jumlah>`}</Terminal>

<InfoBox variant="note" title="File yang dilewati bukan kegagalan pemindaian">

Inisialisasi mempertahankan resource milik proyek yang sudah ada kecuali
penggantian disetujui. Status header seperti valid, inserted, dan updated adalah
milik perintah `scan`, bukan `init`.

</InfoBox>
