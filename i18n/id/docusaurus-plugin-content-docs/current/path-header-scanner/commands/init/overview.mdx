## Ringkasan

`path-header-scanner init` menyiapkan proyek yang sudah ada dengan membuat
direktori dan file konfigurasi. CLI v1.0.0 saat ini menyediakan dua mode,
`all` dan `config`; keduanya merencanakan resource konfigurasi yang sama.

<InfoBox variant="warning" title="Tinjau sebelum mengganti">

Resource yang sudah ada dilewati secara default. Gunakan `--ask` untuk memilih
secara interaktif atau `--force` hanya setelah meninjau file milik proyek.
`--dry-run` tidak membuat direktori, menulis file, mengganti konten, atau
meminta konfirmasi.

</InfoBox>

<Section title="Yang dilakukan perintah">

1. Menyelesaikan mode dan pengaturan inisialisasi.
2. Menyusun rencana untuk `.config/path_header_scanner/config.toml`.
3. Menampilkan rencana dan berhenti jika dry-run aktif.
4. Dalam mode live, membuat atau melewati resource sesuai `--ask` dan `--force`.
5. Menampilkan jumlah file dibuat, disalin, dilewati, dan direktori dibuat.

</Section>
