<Section title="Perintah yang didukung">

| Perintah | Tujuan | Menulis secara default |
| --- | --- | --- |
| [`path-header-scanner init`](./init/overview) | Membuat konfigurasi proyek | Ya, kecuali dry-run |
| [`path-header-scanner scan TARGET`](./scan/overview) | Menemukan dan menampilkan pratinjau perubahan header | Tidak |
| `path-header-scanner scan TARGET --apply` | Menerapkan penyisipan atau pembaruan yang sudah ditinjau | Ya |

</Section>

<InfoBox variant="warning" title="Pratinjau sebelum apply">

`scan` menampilkan pratinjau secara default. `--apply` mengaktifkan penulisan
file target, sedangkan `--dry-run` dari CLI atau konfigurasi mengungguli mode
apply. Inisialisasi memiliki dry-run terpisah untuk meninjau rencana konfigurasi.

</InfoBox>

Gunakan `--help` pada setiap perintah untuk melihat opsi yang tepat pada versi
yang terpasang.
