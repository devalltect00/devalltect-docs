| Key                                                          | Default | Efek                                                      |
| ------------------------------------------------------------ | ------- | --------------------------------------------------------- |
| `tool.path-header-scanner.cli.execution.dry_run`             | false   | Default simulasi bersama.                                 |
| `tool.path-header-scanner.cli.execution.debug`               | false   | Aktifkan logging diagnostik.                              |
| `tool.path-header-scanner.cli.scan.target_directory`         | app     | Target pemindaian default.                                |
| `tool.path-header-scanner.cli.scan.apply`                    | false   | Aktifkan penulisan secara eksplisit.                      |
| `tool.path-header-scanner.cli.scan.include_target_directory` | true    | Tentukan apakah nama target disertakan dalam path header. |

```toml
[tool.path-header-scanner.cli.execution]
dry_run = false
debug = false

[tool.path-header-scanner.cli.scan]
target_directory = "app"
apply = false
include_target_directory = true
```
