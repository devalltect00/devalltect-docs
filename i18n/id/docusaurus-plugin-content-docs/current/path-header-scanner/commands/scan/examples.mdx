### 1. Preview default

<Terminal language="bash">{`path-header-scanner scan app`}</Terminal>

**Hasil:** Scans without writing.

### 2. Apply

<Terminal language="bash">{`path-header-scanner scan app --apply`}</Terminal>

**Hasil:** Writes approved header corrections.

### 3. Dry-run overrides apply

<Terminal language="bash">{`path-header-scanner scan app --apply --dry-run`}</Terminal>

**Hasil:** Simulates and writes nothing.

### 4. Resolve from workdir

<Terminal language="bash">{`path-header-scanner scan src --workdir ../project`}</Terminal>

**Hasil:** Scans ../project/src.
