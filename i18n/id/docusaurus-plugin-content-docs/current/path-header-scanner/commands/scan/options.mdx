| Flag / nilai                                            | Default                | Efek                                          |
| ------------------------------------------------------- | ---------------------- | --------------------------------------------- |
| `TARGET_DIRECTORY`                                      | `app` dari konfigurasi | Direktori yang dipindai.                      |
| `--workdir`                                             | tidak diset            | Basis untuk menyelesaikan target relatif.     |
| `--apply`                                               | false                  | Tulis header yang disisipkan atau diperbarui. |
| `--dry-run/--no-dry-run, -dr/-Dr`                       | false                  | Paksa simulasi dan ungguli mode apply.        |
| `--include-target-directory/--exclude-target-directory` | true                   | Atur apakah nama target tampil dalam header.  |
| `--debug`                                               | false                  | Aktifkan diagnostik pemindaian.               |
