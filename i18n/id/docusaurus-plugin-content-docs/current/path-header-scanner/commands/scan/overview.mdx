## Ringkasan

Perintah ini menyelesaikan target, menemukan file dengan ekstensi yang didukung,
memilih strategi bahasa, dan membandingkan header yang ada dengan path relatif
proyek yang diharapkan. Target opsional mengikuti `target_directory` dalam
konfigurasi, yang bernilai `app` pada konfigurasi hasil inisialisasi.

<InfoBox variant="warning" title="Preview adalah default">

`scan` tidak menulis file target kecuali mode apply efektif aktif. `--dry-run`
mengungguli `--apply` maupun `apply = true` dari konfigurasi.

</InfoBox>

<Section title="Status hasil">

- **Valid:** header yang ada sudah sesuai.
- **Inserted:** header yang hilang akan ditambahkan, atau telah ditambahkan dalam mode apply.
- **Updated:** header usang akan diganti, atau telah diganti dalam mode apply.
- **Failed:** file tidak dapat diproses dengan aman.

</Section>
