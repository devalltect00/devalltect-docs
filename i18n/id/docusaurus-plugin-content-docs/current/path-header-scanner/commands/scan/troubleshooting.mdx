| Gejala                                       | Kemungkinan penyebab                                    | Solusi                                   |
| -------------------------------------------- | ------------------------------------------------------- | ---------------------------------------- |
| Target tidak ditemukan.                      | Resolution workdir/target salah.                        | Periksa hasil path dan ulangi preview.   |
| Tidak ada file didukung.                     | Target kosong, excluded, atau extension tidak didukung. | Tinjau target/language.                  |
