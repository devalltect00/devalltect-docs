---
title: Path Header
description: Cara language strategy membaca dan merender path file.
sidebar_position: 2
sidebar_key: phs-path-headers
---

Setiap language strategy memakai comment syntax yang valid. Markdown memakai HTML comment. Scanner mempertahankan shebang, encoding declaration, dan PHP opening tag. File unsupported dilewati, bukan diubah dengan syntax tebakan.
