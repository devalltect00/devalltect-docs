---
title: Keamanan dan Dry-run
description: Bedakan preview, apply, dan explicit dry-run.
sidebar_position: 3
sidebar_key: phs-dry-run
---

Scan default adalah preview. `--apply` mengaktifkan write. `--dry-run` adalah simulasi eksplisit dan selalu mengalahkan CLI atau configured apply. Dry-run init juga mencegah scaffolding. Diagnostic logging dapat tetap menulis log.
