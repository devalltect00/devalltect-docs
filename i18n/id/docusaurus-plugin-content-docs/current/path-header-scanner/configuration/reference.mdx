<Section title="Bagian yang didukung">

| Bagian TOML                                 | Key yang didukung                                       | Digunakan oleh                                                    |
| ------------------------------------------- | ------------------------------------------------------- | ----------------------------------------------------------------- |
| `[tool.path-header-scanner.cli.execution]`  | `dry_run`, `debug`                                      | Default eksekusi bersama; `dry_run` memengaruhi `init` dan `scan` |
| `[tool.path-header-scanner.initialization]` | `force`, `ask`                                          | `path-header-scanner init`                                        |
| `[tool.path-header-scanner.cli.scan]`       | `target_directory`, `apply`, `include_target_directory` | `path-header-scanner scan`                                        |
| `[tool.path-header-scanner.logging]`        | `level`, flag tampilan Rich, `console_format`           | Diagnostik konsol                                                 |
| `[tool.path-header-scanner.logging.file]`   | level/path file, rotasi, dan `file_format`              | Diagnostik persisten                                              |

</Section>

<Terminal title="Default pemindaian yang aman" language="toml">{`[tool.path-header-scanner.cli.execution]
dry_run = false

[tool.path-header-scanner.cli.scan]
target_directory = "app"
apply = false
include_target_directory = true`}</Terminal>

<InfoBox variant="warning" title="Dry-run mengungguli apply">

Dry-run yang diaktifkan melalui CLI atau konfigurasi menonaktifkan mode apply
efektif. Pemindaian tetap dapat menemukan dan memvalidasi file, tetapi tidak
mengubahnya.

</InfoBox>

<InfoBox variant="note" title="Working directory hanya melalui CLI">

`--workdir` mengubah basis untuk menyelesaikan target pemindaian relatif. Pada
v1.0.0, opsi ini bukan key konfigurasi persisten yang didukung.

</InfoBox>

Key yang tidak dikenal tidak otomatis menjadi opsi perintah. Bandingkan nama
konfigurasi dengan [opsi scan](../commands/scan/options) dan
[opsi init](../commands/init/options) sebelum menggunakannya dalam otomasi.
