## Overview

Pertahankan CLI interaction di `app/cli`, reusable scanning di `app/core/scan`,
dan language syntax di `app/languages`. Contribution tidak boleh secara diam-diam
mengubah preview menjadi apply behavior atau mengizinkan configuration melewati
dry-run.

<Section title="Quality Gates">

<Terminal title="Contributor validation" language="bash">

{`# Focused examples
python -m pytest tests/core/scan
python -m pytest tests/languages

# Complete validation

python -m pytest
make check

# Hook validation

make pre-commit-validate
make pre-commit-run-staged
make pre-commit-run`}

</Terminal>

<InfoBox variant="warning" title="Refresh adalah maintainer operation">

Jalankan `make pre-commit-refresh` hanya untuk intentional hook upgrades.
Command ini dapat mengubah hook configuration dan active files serta mungkin
memerlukan network access. Review seluruh diff sebelum menyimpan hasilnya.

</InfoBox>

</Section>
