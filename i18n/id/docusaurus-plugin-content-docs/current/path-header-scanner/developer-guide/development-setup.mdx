## Tujuan

Install active checkout bersama dependency group `dev`. Runtime-only command
`pip install -e .` tidak meng-install quality tools yang digunakan contributor
workflow ini.

<Section title="Manual Setup">

<Terminal title="Create and install" language="bash">

{`python -m venv venv

# Windows PowerShell

venv\\Scripts\\Activate.ps1

# Linux or macOS

# source venv/bin/activate

python -m pip install --upgrade pip
python -m pip install -e ".[dev]"`}

</Terminal>

Tambahkan extra `docs` hanya ketika mengerjakan MkDocs source milik repository:
`python -m pip install -e ".[dev,docs]"`.

</Section>

---

<Section title="Makefile Setup">

<Terminal title="Setup helpers" language="bash">

{`make venv
make upgrade-pip
make install-dev

# Combined environment setup and Git-hook installation

make setup`}

</Terminal>

Make workflow mengharapkan directory konvensional `venv/` milik repository.

</Section>

<Section title="Pre-Commit Workflow">

Scanner hook configuration menjalankan Ruff fixes, Ruff formatting, Black,
trailing-whitespace cleanup, dan final-newline correction. Ruff dan Black
menggunakan project policy dari `pyproject.toml`.

<Terminal title="Install and run hooks" language="bash">

{`make pre-commit-install-hooks
make pre-commit-validate
make pre-commit-run-staged
make pre-commit-run`}

</Terminal>

<InfoBox variant="warning" title="Refresh dapat mengubah configuration dan source">

Gunakan `make pre-commit-refresh` hanya ketika sengaja meng-upgrade hook
revisions. Command ini memperbarui configuration, membersihkan dan meng-install
ulang hook environments, serta menjalankan seluruh hooks terhadap semua files.
Review resulting diff sebelum menyimpannya.

</InfoBox>

</Section>
