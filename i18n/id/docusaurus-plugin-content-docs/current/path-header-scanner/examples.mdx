<Section title="Pratinjau dan selesaikan target">

<Terminal language="bash">{`# Pratinjau target aplikasi yang dikonfigurasi
path-header-scanner scan app

# Selesaikan app dari basis proyek lain
path-header-scanner scan app --workdir ../project

# Simulasi eksplisit mengungguli apply
path-header-scanner scan app --apply --dry-run`}</Terminal>

</Section>

<Section title="Terapkan setelah ditinjau">

<Terminal language="bash">{`# Jalankan ulang dengan penulisan hanya setelah meninjau pratinjau
path-header-scanner scan app --apply`}</Terminal>

</Section>

<InfoBox variant="warning" title="Pahami mode efektif">

Pratinjau adalah default. `--apply` mengaktifkan penulisan, tetapi `--dry-run`
dari CLI atau konfigurasi proyek menonaktifkan mode apply efektif.

</InfoBox>
