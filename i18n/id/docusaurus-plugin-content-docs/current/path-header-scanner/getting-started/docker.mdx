<Section title="Tag Image yang Dipublikasikan">

| Tag    | Contoh   | Perilaku                                                                |
| ------ | -------- | ----------------------------------------------------------------------- |
| Eksak  | `v1.0.0` | Immutable dan disarankan untuk CI atau otomasi yang dapat direproduksi. |
| Minor  | `v1.0`   | Bergerak ke patch stabil terbaru dalam lini 1.0.                        |
| Major  | `v1`     | Bergerak ke rilis stabil terbaru dalam lini 1.x.                        |
| Latest | `latest` | Bergerak ke rilis stabil Path Header Scanner terbaru.                   |

<Terminal title="Pull dan verifikasi Path Header Scanner" language="bash">

{`docker pull ghcr.io/devalltect00/path-header-scanner:v1.0.0
docker run --rm ghcr.io/devalltect00/path-header-scanner:v1.0.0 --help`}

</Terminal>

<InfoBox variant="warning" title="Prerelease tidak menggeser alias stabil">

`v1.0.0-rc.1` hanya memublikasikan tag eksaknya. Alias stabil hanya diperbarui
oleh rilis stabil.

</InfoBox>

</Section>

<Section title="Pertahankan Keamanan Preview-first">

Tag image tidak mengubah keamanan scanner. Scan normal tetap berupa pratinjau;
`--apply` diperlukan untuk memperbarui file yang di-mount dan `--dry-run`
mengalahkan apply mode. Pin otomasi ke versi image eksak dan mount hanya
direktori proyek yang dituju.

</Section>
