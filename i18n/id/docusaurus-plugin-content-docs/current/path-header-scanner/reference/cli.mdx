## Commands

- `path-header-scanner init`
- `path-header-scanner scan TARGET`
- `path-header-scanner scan TARGET --apply`
- `path-header-scanner scan TARGET --dry-run`

## Global options

- `--no-banner`
- `--version / -v`
- `--help / -h`

<InfoBox variant="warning" title="Safety">
  Scan hanya preview secara default. Effective --apply mengaktifkan write, sedangkan
  --dry-run mengungguli apply dari CLI dan configuration.
</InfoBox>
