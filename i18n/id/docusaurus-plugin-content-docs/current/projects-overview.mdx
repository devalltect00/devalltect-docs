# Ringkasan Proyek

Portal saat ini menyatukan lima proyek Devalltect. Setiap proyek
mempertahankan domain dan struktur dokumentasinya sendiri sambil berbagi
navigasi, komponen desain, validasi build, dan deployment.

## Direktori Proyek

| Proyek                   | Versi terdokumentasi | Tujuan utama                                                                                                     | Dokumentasi                                           |
| ------------------------ | -------------------- | ---------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------- |
| **Path Header Scanner**  | `v1.0.1`             | Pratinjau, validasi, dan terapkan path header yang konsisten pada bahasa yang didukung.                          | [Jelajahi Path Header Scanner](./path-header-scanner) |
| **Doc Gen**              | `v1.0.2`             | Generate, print, dan analyze dokumentasi struktur proyek.                                                        | [Jelajahi Doc Gen](./doc-gen)                         |
| **Reflow**               | `v1.0.2`             | Konversi tag, pulihkan release berbasis tag, dan publikasikan tagged container image.                            | [Jelajahi Reflow](./reflow)                           |
| **Custy**                | `v2.1.2`             | Koordinasikan alur Git, validasi, versioning, changelog, commit, tag, push, backup, cleanup, dan pipeline rilis. | [Jelajahi Custy](./custy)                             |
| **Devalltect Portfolio** | `v2.0.0`             | Sajikan proyek, pengalaman, dan perkembangan teknis melalui portofolio interaktif dwibahasa.                     | [Jelajahi portofolio](./devalltect-portfolio)         |

## Devalltect Portfolio

Dokumentasi v2.0.0 memperkenalkan pengalaman portofolio publik, navigasi
dwibahasa, penemuan proyek, galeri aksesibel, preferensi tema dan motion,
deployment statis Vercel, serta alur Docker opsional. Detail pemeliharaan
internal tetap berada di repositori sumber.

## Cakupan Dokumentasi

Kelima proyek menyediakan panduan Bahasa Inggris dan Bahasa Indonesia yang
selaras untuk baseline rilis yang dicatat. Kedalaman dokumentasi dapat berbeda
karena setiap proyek berkembang secara mandiri. Periksa label status, peringatan,
dan referensi yang selaras dengan sumber sebelum memperlakukan fitur sebagai
kontrak stabil.

## Menambahkan Proyek Lain

1. Buat direktori tingkat atas `docs/<project-name>/`.
2. Tambahkan ringkasan yang jelas dan metadata navigasi `_category_.json`.
3. Atur materi pengguna, perintah, referensi, developer, serta arsitektur sesuai kebutuhan nyata proyek.
4. Tambahkan metadata proyek dan navigasi lintas proyek.
5. Tambahkan dokumentasi Bahasa Indonesia yang setara.
6. Jalankan type checking, pengujian freshness, dan build kedua locale.
