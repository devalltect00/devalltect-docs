| Kunci konfigurasi                      | Bawaan      | Efek                                   |
| -------------------------------------- | ----------- | -------------------------------------- |
| `tool.reflow.docker.provider`          | github      | Pilih `github`, `gitlab`, atau `both`. |
| `tool.reflow.docker.keep_local_images` | false       | Pertahankan image lokal setelah push.  |
| `tool.reflow.github.image`             | placeholder | Tujuan GHCR.                           |
| `tool.reflow.gitlab.image`             | placeholder | Tujuan GitLab Container Registry.      |

```toml
[tool.reflow.docker]
provider = "github"
keep_local_images = false

[tool.reflow.github]
image = "ghcr.io/acme/project"

[tool.reflow.gitlab]
image = "registry.gitlab.com/acme/project"
```
