| Flag / nilai                      | Bawaan               | Efek                                            |
| --------------------------------- | -------------------- | ----------------------------------------------- |
| `--repository, --repo, -C`        | path yang ditentukan | Pilih build context.                            |
| `--repository-url`                | URL terkonfigurasi   | Gunakan clone sementara yang dikelola.          |
