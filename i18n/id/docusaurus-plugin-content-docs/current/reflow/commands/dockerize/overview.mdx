<Section title="Tujuan">

Build image untuk setiap tag lalu publish ke GitHub dan/atau GitLab registry.

</Section>

<InfoBox variant="warning" title="Batas keamanan">Live mode melakukan build/push dan dapat menghapus local image. Dry-run hanya simulasi.</InfoBox>

- Resolve repository.
- Validasi Git/tag/registry.
- Build, tag, dan push image.
- Tandai latest.
- Hapus non-latest jika tidak dipertahankan; tampilkan total.
