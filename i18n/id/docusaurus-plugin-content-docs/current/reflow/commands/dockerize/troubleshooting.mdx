| Gejala               | Kemungkinan penyebab                               | Solusi                                           |
| -------------------- | -------------------------------------------------- | ------------------------------------------------ |
| Build gagal.         | Docker tidak aktif atau build context tidak valid. | Jalankan Docker dan uji `docker build`.          |
| Push ditolak.        | Autentikasi atau izin tidak tersedia.              | Login ke registry dan periksa kepemilikan image. |
| Tag tidak ditemukan. | Repositori target tidak memiliki tag lokal.        | Buat atau fetch tag yang diperlukan.             |

<InfoBox variant="tip" title="Diagnostik">
  Gunakan `--debug` sebelum mengulangi perubahan mode langsung.
</InfoBox>
