<InfoBox variant="warning" title="Batas keamanan">

Mode live hanya menulis resource inisialisasi yang dipilih. Dry-run tidak
membuat direktori, menulis atau mengganti file, maupun meminta konfirmasi
overwrite. Perintah ini tidak membuat commit, tag, push, release, atau image
registry.

</InfoBox>

<InfoBox variant="note" title="Mode yang didukung pada Reflow 1.0.0">

CLI publik menerima `all` dan `config`. Keduanya saat ini menyiapkan workspace
konfigurasi Reflow; nilai `templates`, `examples`, dan `all_no_examples` tidak
diterima oleh enum `InitMode` yang aktif.

</InfoBox>
