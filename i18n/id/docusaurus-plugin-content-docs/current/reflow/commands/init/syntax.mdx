<InfoBox variant="note" title="Target dan opsi global">

Letakkan `--repository`/`--repo`/`-C`, `--dry-run`, `--debug`, dan `--log-level`
sebelum `init`. Walaupun `--repository-url` adalah opsi global, `reflow init`
menolak target URL karena file hasil inisialisasi harus dimiliki direktori lokal
persisten.
