<Section title="Perintah yang Didukung">

| Perintah                                                       | Target dan tujuan                                              | Efek persisten mode live                            |
| -------------------------------------------------------------- | -------------------------------------------------------------- | --------------------------------------------------- |
| [`reflow init`](./init/overview)                               | Direktori lokal persisten; buat konfigurasi milik proyek       | File konfigurasi lokal                              |
| [`reflow tags convert local`](./tags/convert/local/overview)   | Checkout lokal persisten; ganti nama tag yang didukung         | Tag ref lokal saja; tidak melakukan push            |
| [`reflow tags convert remote`](./tags/convert/remote/overview) | Remote checkout atau URL Git; ganti nama tag remote            | Satu atomic push remote yang dijaga                 |
| [`reflow releases recover`](./releases/recover/overview)       | Repositori GitHub; picu ulang automasi untuk tag tanpa release | Hapus/push ulang tag remote dan picu CI             |
| [`reflow dockerize`](./dockerize/overview)                     | Tag repositori dan tujuan image terkonfigurasi                 | Build Docker, push registry, cleanup lokal opsional |

</Section>

<InfoBox variant="warning" title="Alias kompatibilitas yang deprecated">

`reflow tags replay` mendelegasikan ke `reflow releases recover` dan
menampilkan peringatan deprecation. Gunakan
[panduan recovery kanonis](./releases/recover/overview) untuk dokumentasi,
script, dan automasi baru.

</InfoBox>

Opsi target dan keamanan global harus ditulis sebelum path perintah:
`--repository`/`--repo`/`-C`, `--repository-url`, dan `--dry-run`.
