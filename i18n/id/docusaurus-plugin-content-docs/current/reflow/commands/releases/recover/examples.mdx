### 1. Preview

<Terminal language="bash">{`reflow --dry-run --repository-url https://github.com/acme/project.git releases recover`}</Terminal>

**Hasil:** Shows selections.

### 2. Recover

<Terminal language="bash">{`reflow --repository-url https://github.com/acme/project.git releases recover --yes`}</Terminal>

**Hasil:** Re-pushes tags.

### 3. Stable limit

<Terminal language="bash">{`reflow --repository-url https://github.com/acme/project.git releases recover --only-stable --limit 5 --yes`}</Terminal>

**Hasil:** Processes five stable tags maximum.
