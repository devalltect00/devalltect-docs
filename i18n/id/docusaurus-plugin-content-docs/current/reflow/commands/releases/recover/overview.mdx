<Section title="Tujuan">

Menemukan version tag tanpa GitHub release lalu melakukan re-push untuk memicu ulang CI/CD berbasis tag.

</Section>

<InfoBox variant="warning" title="Batas keamanan">
  Menghapus dan re-push tag; tidak membuat release record melalui website atau API.
</InfoBox>

- Baca tag dan release.
- Pilih tag tanpa release.
- Terapkan stable/limit.
- Tampilkan target/rencana.
- Hapus dan re-push dengan delay setelah konfirmasi.
