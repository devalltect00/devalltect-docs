| Gejala                      | Kemungkinan penyebab                                | Solusi                                             |
| --------------------------- | --------------------------------------------------- | -------------------------------------------------- |
| Penemuan gagal.             | Autentikasi atau identitas GitHub tidak tersedia.   | Autentikasikan `gh` dan periksa target repositori. |
| Push ulang ditolak.         | Kebijakan remote atau kredensial memblokir operasi. | Tinjau kebijakan dan jalankan kembali dry-run.     |
| Rilis tetap tidak tersedia. | Alur kerja gagal atau tidak berjalan.               | Periksa log CI/CD.                                 |

<InfoBox variant="tip" title="Diagnostik">
  Gunakan `--debug` sebelum mengulangi perubahan mode langsung.
</InfoBox>
