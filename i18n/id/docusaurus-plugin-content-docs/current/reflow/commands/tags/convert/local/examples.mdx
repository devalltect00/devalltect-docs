### 1. Preview

<Terminal language="bash">{`reflow --dry-run -C ../project tags convert local`}</Terminal>

**Hasil:** Shows replacements only.

### 2. SemVer

<Terminal language="bash">{`reflow -C ../project tags convert local --yes`}</Terminal>

**Hasil:** Replaces local tag names.

### 3. PEP 440

<Terminal language="bash">{`reflow -C ../project tags convert local --to pep440 --yes`}</Terminal>

**Hasil:** Uses PEP 440 names.
