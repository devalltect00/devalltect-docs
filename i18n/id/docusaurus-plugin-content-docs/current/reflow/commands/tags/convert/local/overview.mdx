<Section title="Tujuan">

Mengganti nama tag pada checkout lokal persisten sambil mempertahankan tipe dan metadata annotated jika memungkinkan.

</Section>

<InfoBox variant="warning" title="Batas keamanan">
  Hanya mengubah ref lokal, menolak URL, dan tidak melakukan push.
</InfoBox>

- Resolve checkout dan baca objek tag.
- Susun rencana penggantian lengkap.
- Tolak URL, collision, signed tag, dan destination tidak valid.
- Tampilkan target dan konfirmasi.
- Buat destination lalu hapus source ref lokal.
