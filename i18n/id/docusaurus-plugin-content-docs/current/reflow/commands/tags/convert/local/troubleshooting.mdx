| Gejala                       | Kemungkinan penyebab                               | Solusi                                         |
| ---------------------------- | -------------------------------------------------- | ---------------------------------------------- |
| URL ditolak.                 | Cakupan lokal memerlukan checkout persisten.       | Clone repositori atau gunakan konversi remote. |
| Tag tujuan sudah ada.        | Ref yang berbeda berisiko tertimpa.                | Selesaikan konflik secara manual.              |
| Tag bertanda tangan dipilih. | Penggantian nama membuat tanda tangan tidak valid. | Buat ulang tanda tangan di luar Reflow.        |
