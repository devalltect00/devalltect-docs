| Kunci konfigurasi                            | Bawaan             | Efek                                                           |
| -------------------------------------------- | ------------------ | -------------------------------------------------------------- |
| `tool.reflow.repository.url`                 | tidak diatur       | Pilih target melalui clone sementara yang dikelola.            |
| `tool.reflow.repository.path`                | direktori saat ini | Pilih checkout lokal sebagai alternatif yang saling eksklusif. |
| `tool.reflow.cli.tags.convert.target_format` | semver             | Tentukan format tag tujuan.                                    |
| `tool.reflow.cli.tags.convert.yes`           | false              | Lewati prompt konfirmasi mode langsung.                        |

```toml
[tool.reflow.repository]
url = "https://github.com/acme/project.git"

[tool.reflow.cli.tags.convert]
target_format = "semver"
yes = false
```
