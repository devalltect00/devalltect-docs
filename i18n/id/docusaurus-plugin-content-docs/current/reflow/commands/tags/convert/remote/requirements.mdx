## Sebelum menjalankannya

- URL atau checkout dengan remote push.
- Izin membuat dan menghapus tag ref.
- Tidak ada collision, signed tag, atau konversi tidak didukung.

<InfoBox variant="tip" title="Dry run">
  Dry-run menjalankan discovery dan validation tanpa mutasi persisten.
</InfoBox>
