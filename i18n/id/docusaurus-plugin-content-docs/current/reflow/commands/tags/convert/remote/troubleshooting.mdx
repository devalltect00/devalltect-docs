| Gejala                                | Kemungkinan penyebab                              | Solusi                                                             |
| ------------------------------------- | ------------------------------------------------- | ------------------------------------------------------------------ |
| Path dan URL dikonfigurasi bersamaan. | Kedua bentuk target saling eksklusif.             | Pertahankan hanya salah satu target.                               |
| Push atomik ditolak.                  | Kebijakan, autentikasi, atau penghapusan ditolak. | Tinjau kebijakan dan kredensial, lalu jalankan kembali dry-run.    |
| Clone berhasil, tetapi push gagal.    | Izin baca dan tulis berbeda.                      | Konfigurasikan autentikasi Git tanpa menaruh token di konfigurasi. |
