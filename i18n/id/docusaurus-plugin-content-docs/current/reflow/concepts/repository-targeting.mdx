---
title: Target Repositori
description: Cara Reflow memilih checkout lokal atau Git URL.
sidebar_position: 9
sidebar_key: reflow-repository-targeting
---

Urutan target adalah explicit CLI, konfigurasi `[tool.reflow.repository]`, lalu current working directory. `path` dan `url` saling eksklusif. Path menggunakan checkout yang sudah ada; URL menggunakan temporary clone. Image registry bukan target repositori.
