## Resolusi dan kepemilikan

Jika sebuah pengaturan memiliki opsi CLI yang sesuai, Reflow menentukan
nilainya dalam urutan berikut:

1. Argumen CLI eksplisit
2. `.config/reflow/config.toml`
3. Default internal

File yang dibuat oleh `reflow init` dimiliki proyek target. Tinjau sebelum
melakukan commit, dan jangan menaruh kredensial atau token di URL repositori
atau nama image.

<InfoBox variant="warning" title="Pilih path atau URL—jangan keduanya">

Di dalam `[tool.reflow.repository]`, aktifkan hanya satu bentuk target. Jika
`path` dan `url` ada bersamaan, Reflow melaporkan configuration error. Jika
keduanya tidak ada, target kembali ke direktori kerja saat ini kecuali target
CLI eksplisit diberikan.

</InfoBox>

| Perintah                     | Target `path`                   | Target `url`                           | Cakupan persisten                        |
| ---------------------------- | ------------------------------- | -------------------------------------- | ---------------------------------------- |
| `reflow init`                | Didukung                        | Ditolak                                | File konfigurasi proyek                  |
| `reflow tags convert local`  | Didukung                        | Ditolak                                | Tag ref lokal saja                       |
| `reflow tags convert remote` | Memakai remote checkout         | Memakai clone sementara                | Atomic push remote yang dijaga           |
| `reflow releases recover`    | Memakai remote checkout         | Memakai clone sementara                | Hapus dan push ulang tag remote terpilih |
| `reflow dockerize`           | Memakai checkout sebagai sumber | Memakai clone sementara sebagai sumber | Operasi Docker dan registry              |

Nilai registry seperti `github.image` dan `gitlab.image` tidak pernah memilih
repositori Git.

</Section>

Discovery Git atau provider yang read-only serta penyiapan clone sementara

melalui API.

<Section title="Contoh Target Minimal">

<Terminal title="Target lokal" language="toml">

{`[tool.reflow.repository]
path = "../project"

[tool.reflow.cli.tags.convert]
target_format = "semver"
yes = false`}

</Terminal>

<Terminal title="Target URL remote" language="toml">

{`[tool.reflow.repository]
url = "https://github.com/acme/project.git"

[tool.reflow.git]
default_remote = "origin"`}

</Terminal>

Jangan gabungkan contoh `path` dan `url` dalam satu konfigurasi aktif.

</Section>

<InfoBox variant="note" title="Gunakan key yang didukung secara tepat">

Key yang tidak dikenal atau salah eja tidak menggantikan opsi CLI atau default
yang didukung. Bandingkan file hasil inisialisasi dengan template Reflow 1.0.2
bawaan saat memperbarui konfigurasi proyek yang sudah ada.

</InfoBox>
