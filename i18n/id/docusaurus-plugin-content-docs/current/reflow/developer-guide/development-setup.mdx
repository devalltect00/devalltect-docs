## Tujuan

Gunakan environment dengan executable `reflow` yang mengarah ke active source
checkout. Dependency group `dev` diperlukan untuk pytest, coverage, Ruff,
Black, pre-commit, packaging, dan contributor commands lainnya.

<Section title="Manual Setup">

<Terminal title="Create and install" language="bash">

{`python -m venv venv

# Windows PowerShell

venv\\Scripts\\Activate.ps1

# Linux or macOS

# source venv/bin/activate

python -m pip install --upgrade pip
python -m pip install -e ".[dev]"`}

</Terminal>

Gunakan `python -m pip install -e ".[dev,docs]"` hanya ketika Anda juga
memerlukan MkDocs toolchain milik repository.

</Section>

---

<Section title="Makefile Setup">

Make workflow mengharapkan directory konvensional `venv/` dan memanggil Python
interpreter di dalamnya secara langsung.

<Terminal title="Setup helpers" language="bash">

{`make venv
make upgrade-pip
make install-dev

# Combined environment setup and Git-hook installation

make setup`}

</Terminal>

Jalankan `make help-local` untuk melihat seluruh local command groups.

</Section>

<Section title="Pre-Commit Workflow">

Hook configuration Reflow menjalankan Ruff safe fixes, Black formatting,
trailing-whitespace cleanup, dan final-newline correction. Ruff dan Black
menggunakan policy dalam `pyproject.toml`.

<Terminal title="Install and run hooks" language="bash">

{`# Install Git hook and isolated hook environments
make pre-commit-install-hooks

# Validate .pre-commit-config.yaml

make pre-commit-validate

# Check files currently staged for commit

make pre-commit-run-staged

# Check every tracked repository file

make pre-commit-run`}

</Terminal>

<InfoBox variant="warning" title="Refresh adalah tindakan maintainer yang disengaja">

`make pre-commit-refresh` memperbarui hook revisions, membersihkan cached hook
environments, meng-install ulang environments tersebut, dan menjalankan setiap
hook terhadap semua files. Command ini dapat memerlukan network access serta
mengubah `.pre-commit-config.yaml` dan active source files. Review seluruh diff
sebelum menyimpan hasilnya.

</InfoBox>

</Section>
