<Section title="Ganti format tag">

<Terminal title="PEP 440 ke SemVer secara lokal" language="bash">{`# Pratinjau penggantian ref tag lokal
reflow --dry-run -C ../project tags convert local --to semver

# Terapkan setelah meninjau rencana
reflow -C ../project tags convert local --to semver --yes`}</Terminal>

<Terminal title="SemVer ke PEP 440 secara remote" language="bash">{`# URL diklon ke workspace sementara terkelola untuk discovery
reflow --dry-run --repository-url https://github.com/acme/project.git tags convert remote --to pep440

# Scope remote menjalankan push terlindungi; --push tidak digunakan
reflow --repository-url https://github.com/acme/project.git tags convert remote --to pep440 --yes`}</Terminal>

</Section>

<Section title="Pratinjau alur eksternal">

<Terminal language="bash">{`# Temukan tag tanpa GitHub release; jangan re-push
reflow --dry-run -C ../project releases recover

# Selesaikan tagged image; jangan build, push, atau membersihkan image
reflow --dry-run -C ../project dockerize`}</Terminal>

</Section>

<InfoBox variant="warning" title="Dry-run bukan otorisasi">

Hapus `--dry-run` hanya setelah memverifikasi repositori, rencana konversi,
remote, registry image, dan perilaku konfirmasi yang ditampilkan.

</InfoBox>
