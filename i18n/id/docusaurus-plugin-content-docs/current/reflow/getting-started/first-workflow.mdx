<InfoBox variant="note" title="Persyaratan runtime">

Reflow memerlukan Python 3.14 atau lebih baru. Pisahkan instalasi Reflow dari
repositori yang akan dioperasikan; pilih target secara eksplisit ketika
direktori saat ini dapat menimbulkan ambiguitas.

</InfoBox>

<Section title="Instal dari Source Checkout yang Telah Ditinjau">

<Terminal title="Buat environment terisolasi" language="bash">

{`python -m venv venv

# Aktifkan dengan perintah yang sesuai untuk shell Anda:

# Windows PowerShell: .\\venv\\Scripts\\Activate.ps1

# POSIX shell: source venv/bin/activate

python -m pip install .
reflow --version`}

</Terminal>

</Section>

<Terminal title="Inisialisasi dan pratinjau" language="bash">

{`reflow -C /path/to/project init
git -C /path/to/project tag --list
reflow --dry-run -C /path/to/project tags convert local --to semver`}

</Terminal>

<InfoBox variant="warning" title="Jangan tambahkan --yes sebelum memahami rencana">

Dry-run tidak pernah meminta konfirmasi. Pada mode live, pertahankan prompt
konfirmasi untuk penggunaan interaktif. Gunakan `--yes` hanya untuk automasi
yang telah ditinjau atau rencana penggantian yang sudah diperiksa.

</InfoBox>
