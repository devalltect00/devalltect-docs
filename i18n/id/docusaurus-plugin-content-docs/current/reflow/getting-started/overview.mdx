<InfoBox variant="info" title="URL tidak memerlukan clone permanen">

Perintah operasional yang didukung mematerialisasi URL repositori dalam
workspace sementara yang dikelola. `reflow init` dan
`reflow tags convert local` memerlukan checkout lokal persisten dan menolak
target URL.

</InfoBox>

<Terminal title="Urutan orientasi yang aman" language="bash">

{`# Siapkan konfigurasi milik proyek pada checkout lokal
reflow -C /path/to/project init

# Tinjau konfigurasi yang dibuat dan status Git
git -C /path/to/project status --short

# Pratinjau konversi tag lokal tanpa mengubah ref
reflow --dry-run -C /path/to/project tags convert local --to semver`}

</Terminal>
