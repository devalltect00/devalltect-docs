## Ringkasan

Reflow adalah CLI pemeliharaan release yang memahami repositori. Reflow selalu
menampilkan target, memisahkan penggantian tag lokal dan remote, serta
menerapkan batas dry-run dan konfirmasi sebelum operasi yang berdampak besar.

<InfoBox variant="warning" title="Target repositori dan image berbeda">

Path atau URL repositori memilih repositori Git. `github.image` dan
`gitlab.image` memilih tujuan container; keduanya tidak pernah memilih
repositori yang dioperasikan Reflow.

</InfoBox>

<Section title="Mulai dari Target dan Pratinjau">

<Terminal title="Titik awal yang aman" language="bash">

{`# Periksa struktur perintah
reflow --help

# Pratinjau penggantian tag lokal

reflow --dry-run -C ../project tags convert local --to semver

# Pratinjau penggantian remote dari URL Git

reflow --dry-run --repository-url https://github.com/acme/project.git tags convert remote --to semver`}

</Terminal>
